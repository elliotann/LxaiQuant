# 机器学习子系统操作手册

## 一、概述

机器学习子系统提供以下核心能力：

| 功能 | 算法 | 用途 |
|------|------|------|
| 方向预测 | RandomForest 二分类 | 预测未来 N 根 K 线的涨跌方向 |
| 波动率预测 | ATR + 年化波动率 | 识别当前波动率级别（高/中/低） |
| 市场状态聚类 | KMeans | 聚类识别市场状态（趋势上涨/震荡/趋势下跌） |
| 自动特征搜索 | RandomForest + 随机组合搜索 | 自动搜索最优特征组合 |
| 因子自动挖掘 | 遗传规划 (Genetic Programming) | 自动生成候选因子表达式 |

系统架构：所有机器学习组件位于 `ai-quant` 模块的 `com.chain.ai.trade.engine.service.ml` 包中，通过 `FeatureEngineeringService` 提取 4 维基础特征（RSI、MACD、MACD_Signal、EMADiff），在此基础上进行训练、推理和因子挖掘。

## 二、配置属性

配置文件：`application.yml`，前缀 `ml`。

```yaml
ml:
  model:
    storage-dir: ./models                # 模型文件存储目录
    lookahead-bars: 12                   # 预测未来 K 线数
    num-trees: 500                       # 随机森林树数
    max-depth: 4                         # 树最大深度
    min-samples: 40                      # 叶子节点最小样本数
    max-versions-per-symbol: 5           # 每品种保留的最大模型版本数
  label:
    horizon: 24                          # 标签计算周期数
    threshold-pct: 0.001                 # 标签阈值
  training:
    progress-polling-interval-ms: 2000   # 训练进度轮询间隔
    default-lookback-bars: 2000          # 默认回溯 K 线数
  inference:
    probability-threshold: 0.65          # 推理概率阈值
  volatility:
    atr-period: 14                       # ATR 计算周期
    lookback-days: 30                    # 波动率回溯天数
    clustering:
      n-clusters: 3                      # 市场状态聚类数
  factor-mining:
    default-population-size: 500         # GP 种群大小
    default-generations: 20              # GP 进化代数
    default-tournament-size: 5           # GP 锦标赛大小
    default-crossover-prob: 0.8          # GP 交叉概率
    default-mutation-prob: 0.1           # GP 变异概率
    default-parsimony-coefficient: 0.001 # GP 简约系数
    default-lookback-bars: 500           # 因子挖掘回溯 K 线数
    top-k: 20                            # 保留 Top K 候选因子
    max-threads: 4                       # 并行评估最大线程数
    default-fitness-metric: RANK_IC      # 默认适应度指标
```

## 三、4 维基础特征提取

### 3.1 特征维度

`FeatureEngineeringService` 提取的 4 维基础特征：

| 索引 | 特征 | 计算公式 | 含义 |
|------|------|----------|------|
| 0 | RSI | RSI(14) | 相对强弱指标，超买超卖判断 |
| 1 | MACD | MACD(12,26) | 指数平滑异同平均线 |
| 2 | MACD_Signal | MACD 信号线(9) | MACD 的 EMA 平滑线 |
| 3 | EMADiff | (EMA20 - EMA60) / EMA60 * 100 | 均线偏离度 |

### 3.2 标签生成

训练标签基于未来收益率与过去均值的比较：

```
futureReturn = (close[t+horizon] - close[t]) / close[t] * 100
pastMeanReturn = meanReturn[t-20, t)
label = futureReturn > pastMeanReturn ? 1 : 0
```

### 3.3 关键常量

- `MIN_BARS = 60`：至少需要 60 根 K 线才能提取特征
- 训练集/测试集划分：80% / 20%（按时间顺序排序）

## 四、方向预测模型

### 4.1 训练流程

```
用户请求 → MLTrainingService.trainDirectionModel(symbol)
  ├── 获取 K 线数据（默认 2000 根 1h K 线）
  ├── 通过 IndicatorWrapHelper.buildSeries() 构建 BarSeries
  ├── FeatureEngineeringService.extractTrainingData() 提取训练样本
  ├── DirectionModelTrainer.train() 训练 RandomForest
  │     ├── 80% 训练集 / 20% 测试集
  │     ├── 树数 500，最大深度 4，最小样本 40
  │     ├── 支持 ProgressCallback 实时回调
  │     └── 输出 TrainingResult（含准确率、精确率、召回率、F1）
  ├── ModelStorageService.saveModel() 保存模型
  │     ├── 序列化 RandomForest 为 .ser 文件
  │     ├── 入库 MlModel 记录（版本号自增）
  │     └── 自动清理过期版本（保留最近 5 个）
  └── 返回训练报告
```

### 4.2 推理流程

```
用户请求 → MLInferenceService.predictDirection(series, symbol)
  ├── 提取最新 K 线的 4 维特征
  ├── 加载已训练的 RandomForest 模型（内存缓存）
  ├── 计算上涨概率 posteriori[1]
  ├── 根据阈值判定方向
  │     ├── probUp > 0.65 → BUY (置信度归一化)
  │     ├── probUp < 0.35 → SELL
  │     └── 否则 → HOLD
  └── 返回 PredictionResult
```

### 4.3 模型管理

- 每个品种+模型类型维护版本链，版本号从 1 开始递增
- 新模型保存后自动设置为活跃状态（isActive=true）
- 模型文件存储为 `.ser` 序列化文件
- 内存缓存：MLInferenceService 维护 ConcurrentHashMap，过期自动重新加载
- 切换活跃模型时自动清除缓存

## 五、波动率预测

### 5.1 计算逻辑

基于 ATR 和年化波动率的计算：

```
ATR = mean(TrueRange[i]) over lookback_days
annualizedVol = stdDev(dailyReturns) * sqrt(365)

波动率分级（基于 ATR 百分比）：
  - HIGH:   atrPercent > 2.0%
  - MEDIUM: atrPercent > 0.8%
  - LOW:    atrPercent <= 0.8%
```

### 5.2 API

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/ml/predict/volatility?symbol=xxx | 查询波动率预测 |

### 5.3 返回结构

```json
{
  "predictedVolatility": 0.4532,
  "regime": "MEDIUM",
  "atr": 125.67,
  "suggestion": "正常交易，注意风险"
}
```

## 六、市场状态聚类

### 6.1 计算逻辑

基于 KMeans 聚类，输入 3 维数据：

```
维度：
  - returns: (close - prevClose) / prevClose  日内收益率
  - range: (high - low) / close               日内波动范围
  - volume: 成交量

聚类数：默认 3（可通过 ml.volatility.clustering.n-clusters 配置）
```

典型聚类结果：

| 类别 | 标签 | 描述 |
|------|------|------|
| 类 0 | 趋势上涨 | 涨幅较大，波动中等，适合持仓 |
| 类 1 | 震荡整理 | 涨跌幅小，波动低，适合高抛低吸 |
| 类 2 | 趋势下跌 | 跌幅较大，波动高，建议观望或做空 |

### 6.2 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/ml/market/state?symbol=xxx | 查询市场状态 |

## 七、自动特征搜索

### 7.1 功能说明

自动特征搜索通过 RandomForest + 随机组合搜索，从预定义的特征变体池中自动搜索最优特征组合。

### 7.2 特征池（40+ 变体）

| 特征类型 | 变体参数 |
|----------|----------|
| RSI | 7, 14, 21, 28 |
| MACD | (5,13,5), (12,26,9), (19,39,13) |
| MACD_Signal | (5,13,5), (12,26,9), (19,39,13) |
| EMADiff | (5,20), (10,30), (20,60), (30,90), (50,200) |
| ATR | 7, 14, 21 |
| VolumeRatio | (5,20), (10,30) |
| PriceChange | 1, 3, 5 |
| StochasticK | 7, 14, 21 |
| BollingerB | 14, 20, 26 |
| LinearRegSlope | 5, 10, 20 |

### 7.3 请求参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| symbol | 交易标的 | 必填 |
| maxCombinations | 最大组合数 | 100 |
| minFeatures | 最小特征数 | 2 |
| maxFeatures | 最大特征数 | 5 |
| featurePool | 自定义特征池（可选） | 默认池 |
| thresholdScan.start | 阈值扫描起始 | 0.5 |
| thresholdScan.end | 阈值扫描结束 | 0.8 |
| thresholdScan.step | 阈值扫描步长 | 0.05 |
| weights.f1 | F1 权重 | 0.4 |
| weights.precision | 精确率权重 | 0.3 |
| weights.signalCount | 信号数权重 | 0.3 |
| modelParams.numTrees | 评估用树数 | 100 |
| modelParams.maxDepth | 树最大深度 | 6 |
| modelParams.minSamples | 最小样本数 | 5 |

### 7.4 评估指标

搜索完成后，依据以下指标排序：

- **Score** = F1 * w1 + Precision * w2 + normSignal * w3
- 遍历最佳概率阈值（0.5 ~ 0.8，步长 0.05）
- 输出 Top 20 特征组合

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/ml/auto-search/feature-pool | 获取特征池信息 |
| POST | /api/ml/auto-search | 启动自动搜索 |
| GET | /api/ml/auto-search/{searchId} | 查询搜索进度/结果 |

## 八、因子自动挖掘（GP）

### 8.1 功能说明

基于遗传规划（Genetic Programming）自动组合基础算子，生成可解释的因子表达式。支持自定义算子集、终端集和适应度指标。

### 8.2 算子库（18 个）

**算术运算（5 个）**：ADD(+), SUB(-), MUL(\*), DIV(/), NEG(neg)

**数学函数（4 个）**：SQRT(sqrt), LOG(log), ABS(abs), SIGN(sign)

**比较函数（2 个）**：MAX(max), MIN(min)

**时间序列（7 个）**：TS_SUM(ts_sum), TS_MEAN(ts_mean), TS_STD(ts_std), TS_MAX(ts_max), TS_MIN(ts_min), TS_MEDIAN(ts_median)

时间序列算子为二阶算子：第一个参数为序列特征（TerminalNode），第二个参数为窗口大小（ConstantNode）。

### 8.3 终端集

终端集 = 特征工厂（FeatureFactory）生成的所有可用特征变体，包括 RSI_14、MACD_12_26、ATR_14 等 40+ 变体。具体列表可通过 API 查询。

### 8.4 适应度指标

| 指标 | 说明 | 取值 |
|------|------|------|
| RANK_IC | Spearman 秩相关系数 | [-1, 1] |
| SHARPE | 因子值夏普比率 | 无上限 |
| IC_SHARPE_COMBO | 0.6\*\|IC\| + 0.4\*min(Sharpe/3, 1) | [0, 1] |

### 8.5 遗传规划参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| populationSize | 500 | 种群大小 |
| generations | 20 | 进化代数 |
| tournamentSize | 5 | 锦标赛选择大小 |
| crossoverProb | 0.8 | 子树交叉概率 |
| mutationProb | 0.1 | 点变异概率 |
| parsimonyCoefficient | 0.001 | 简约系数（惩罚大树） |

### 8.6 评估结果字段

每个候选因子包含：

| 字段 | 说明 |
|------|------|
| expression | 表达式字符串 |
| expressionLatex | LaTeX 格式表达式 |
| fitness | 适应度值 |
| rankIc | Rank IC |
| sharpe | 夏普比率 |
| turnover | 换手率 |
| treeDepth | 树深度 |
| nodeCount | 节点数 |
| corrWithLabel | 与标签的相关性 |
| topRet | 分组收益 |

### 8.7 与特征池的整合

选中因子可通过 `FeatureFactory.createFromExpression(name, expression, data)` 注册为 `DynamicFeature`，在训练和推理时与 4 维基础特征并行计算。

## 十一、常见问题

**Q: 训练失败 "样本不足"？**

A: 需要至少 100 个有效样本。可增加 `default-lookback-bars`（默认 2000）或降低 `lookahead-bars`（默认 12）。

**Q: 预测结果总是 BUY/SELL？**

A: 检查 `probability-threshold`（默认 0.65）。阈值越低，BUY/SELL 信号越多；阈值越高，HOLD 信号越多。

**Q: 如何查看当前使用哪个模型版本？**

A: 调用 `GET /api/ml/models/active/{symbol}` 查看活跃模型及其版本号。

**Q: 因子挖掘任务不启动？**

A: 确保 XXL-JOB 正确配置，`FactorMiningJobHandler` 的调度已启用。也可直接调用 `POST /api/ml/factor-mining/tasks/{taskId}/start` 手动启动。

**Q: GP 进化时间太长？**

A: 降低 `populationSize`（如 200）或 `generations`（如 10），或减少 `max-threads` 限制资源占用。
