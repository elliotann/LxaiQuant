SMC 多时间框架交易决策逻辑（最终版）
基于全部对话总结，适用于手动交易与自动化策略开发。
强度字段完全忽略。所有判断以 SMC（Smart Money Concepts）原理为核心，结合 1h / 15m 多时间框架。

一、核心优先级
趋势（分层） > 位置 > 形态

趋势决定主方向，位置决定入场区域，形态提供额外确认。

允许逆小周期趋势的“反弹/回调单”，但必须顺大周期摆动趋势。

三、位置判断（在趋势方向内使用）
关键区域定义
需求区（OB）：买盘聚集区，价格在此区域内或略下方（缓冲 ≤ 0.2%）可考虑做多。

供给区（OB）：卖盘聚集区，价格在此区域内或略上方（缓冲 ≤ 0.2%）可考虑做空。

Premium 区：溢价区，做空有利，不做多。

Discount 区：折价区，做多有利，不做空。

中性区：两区之间，标准规则不开仓。

位置与趋势结合（允许回调/反弹单）
1h摆动	小周期同向？	当前位置	操作建议	仓位权重参考
看涨	是	需求区	✅ 标准做多	2~3
看涨	否	需求区	✅ 回调做多	1~2
看涨	是	供给区	⚠️ 谨慎做多（突破或回调）	0~1
看跌	是	供给区	✅ 标准做空	2~3
看跌	否	供给区	✅ 反弹做空	1~2
看跌	是	需求区	⚠️ 谨慎做空（跌破或反弹）	0~1
任何	任何	中性区	❌ 不开仓（标准）	0
“小周期同向”：15m 摆动与 15m 内部均与 1h 摆动方向一致。若不一致，仍可开仓，但权重降低，目标使用更近区域。

四、形态确认（辅助验证）
形态	含义	操作影响
CHoCH↑	小周期趋势向上转折	确认回调结束，可顺势做多
CHoCH↓	小周期趋势向下转折	确认反弹结束，可顺势做空
BOS↑	突破前高，趋势延续	持仓信号，不加反向
BOS↓	跌破前低，趋势延续	持仓信号，不加反向
EQH（相等高点）	上方强阻力	做多需谨慎
EQL（相等低点）	下方强支撑	做空需谨慎
形态不能单独决定开仓，但当出现≥2个顺向形态（如 CHoCH + BOS + EQL）且大小周期共振时，可升级目标至更高时间框架对立区，并适当增加权重。

五、盈亏比计算（含手续费）
手续费
双边合计 0.1%（开仓 0.05% + 平仓 0.05%）。

折算为点数：feePoints = currentPrice × 0.001。

公式（净盈亏比）
text
净盈亏比 = (目标价 - 入场价 - feePoints) / (入场价 - 止损价 + feePoints)   // 多单
净盈亏比 = (入场价 - 目标价 - feePoints) / (止损价 - 入场价 + feePoints)   // 空单
可接受标准
≥ 1.5 → 及格，正常开仓。

1.3 ~ 1.5 → 轻仓尝试（权重 ≤ 1）。

< 1.3 → 放弃。

盈利空间折算后必须 > 0.1%，且盈利点数 ≥ 10（避免手续费侵蚀）。

止损设置（稳妥止损）
做多：止损设在需求区下沿下方 2~3 点（或 0.05% 缓冲）。

做空：止损设在供给区上沿上方 2~3 点（或 0.05% 缓冲）。

激进跟踪：止损设在近期结构低点/高点下方 2~3 点。

目标选择
默认：最近对立区域边界（做多：15m 供给区下沿；做空：15m 需求区上沿）。

升级（趋势形态共振）：当大小周期全部同向（4个趋势一致）且 ≥2个顺向形态时，目标使用更高时间框架对立区（1h 供给区下沿 / 1h 需求区上沿），以改善盈亏比。

回调/反弹单（小周期逆向）：目标仅使用最近对立区域，不升级。

六、仓位权重（0 ~ 3）
最终仓位 = 权重 × 基础仓位（基础仓位用户自定）。

权重建议表
条件	权重
趋势、位置、形态完美共振（大小周期全同向 + 订单块内 + ≥2形态 + 净盈亏比≥2）	3
趋势一致、位置正确，净盈亏比≥1.5，形态无明显反向	2
趋势部分支持（大周期中性）、位置正确，净盈亏比 1.3~1.5	1
回调/反弹单（小周期逆向）且位置正确，净盈亏比≥1.5	1
激进趋势跟踪（大小周期全共振但中性区）	0.5~1
任何不满足开仓条件	0
权重调整因子
大周期内部趋势匹配：+0.4

15m 摆动匹配：+0.2

15m 内部匹配：+0.1

形态共振（≥2个）：+0.2（仅当使用升级目标时）

精确位于订单块内：+0.1

最终权重限幅 0.5 ~ 3.0，激进跟踪限幅 ≤1.0。

七、开仓与加仓区别
操作	位置要求	成本要求	盈亏比要求	仓位权重
新开仓	顺势 OB 内/边界	无	≥1.5（或1.3轻仓）	按标准
加多仓	需求区内，价格低于首仓	拉低均价	整体≥1.5	≤首仓权重
加空仓	供给区内，价格高于首仓	拉高均价	整体≥1.5	≤首仓权重
严禁：追高加多、追低加空、脱离 OB 加仓。

八、激进趋势跟踪（特例）
适用条件
大小周期全面共振（1h 摆动+内部、15m 摆动+内部 全部同向）。

价格处于中性区（不在订单块内）。

趋势强劲，缺乏回调入场机会。

策略规则（以做多为例）
入场：现价或小幅回调。

止损：近期结构低点下方 2~3 点（如 trailingLow、weakLow）。

目标：更高时间框架对立区（1h 供给区下沿）或移动止盈。

仓位权重：0.5 ~ 1。

盈亏比：仍须 ≥ 1.5（用小止损计算）。

若价格反向突破止损，立即离场。随后可移动止损保本。

九、完整决策流程（标准SMC）
text
1. 根据四指标确定当前趋势类型（参考趋势类型划分表）。
2. 若类型为“矛盾混乱”或“横盘震荡（且不交易）”，则放弃。
3. 确定交易方向（只顺大周期摆动方向，除非是潜在反转特例）。
4. 检查价格位置 → 是否在需求区/供给区/中性区。
   - 位置必须与趋势方向匹配（多：需求区；空：供给区），否则放弃。
5. 判断是否满足“回调/反弹单”：小周期与1h摆动反向，但仍位置正确 → 目标用最近对立区，权重降低。
6. 判断是否满足“激进跟踪”：大小周期全共振 + 中性区 → 用小损，目标用1h对立区，权重0.5~1。
7. 计算净盈亏比（含手续费）：
   - ≥1.5 → 进入下一步；
   - 1.3~1.5 → 轻仓；
   - <1.3 或盈利<10点 → 放弃。
8. 检查形态（CHoCH/BOS/EQL/EQH）→ 若≥2个顺向形态且大小周期全同向，可升级目标至1h对立区。
9. 确定仓位权重（0~3），设置稳妥止损，执行开仓。
10. （可选）分批止盈：中间订单块平仓部分，剩余移动止损。
    十、典型禁止情形
    ❌ 1h 摆动看涨，却在供给区做空。

❌ 1h 摆动看跌，却在需求区做多。

❌ 价格在中性区开仓（除非使用激进跟踪特例）。

❌ 净盈亏比 < 1.3 的任何开仓。

❌ 盈利空间 < 10 点。

❌ 加仓导致均价恶化。
