# 权重规则引擎配置操作指南

## 1. 概述

权重规则引擎允许用户在**不修改代码**的情况下，通过配置规则来精确控制信号输出的最终权重。

引擎采用**两阶段评估**策略：

- **VETO 规则（门卫模式）**：按 order 升序执行。条件不匹配 → 立即否决信号；条件匹配 → 累加 vetoWeight
- **SCORING 规则（评分累加）**：按 order 升序执行。条件匹配 → 累加 score；条件不匹配 → 跳过

引擎输出最终权重 `{0, 0.5, 1.0, 1.5, 2.0}`，通过 `scoreToWeight()` 映射。

---

## 2. 规则配置结构

### 2.1 JSON 结构

```json
{
  "enabled": true,
  "rules": [
    {
      "name": "规则名称",
      "type": "SCORING",
      "score": 1.0,
      "vetoWeight": 0.2,
      "order": 1,
      "enabled": true,
      "conditionOperator": "AND",
      "conditions": [
        {
          "indicator": "SMC_DIRECTION_ALIGNED",
          "operator": "EQ",
          "value": "1",
          "direction": "BOTH",
          "params": {}
        }
      ]
    }
  ]
}
```

### 2.2 字段说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `enabled` | boolean | 是 | 引擎总开关 |
| `version` | int | 否 | 版本号，后端自动管理 |
| `status` | string | 否 | ACTIVE / INACTIVE |

### 2.3 规则字段说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | string | 是 | 规则名称 |
| `type` | string | 是 | `SCORING` 或 `VETO` |
| `score` | number | SCORING 必填 | 评分累加值（建议 0.5～2.0） |
| `vetoWeight` | number | VETO 选填 | 否决通过后的加分（默认 0.2） |
| `order` | int | 是 | 执行顺序（升序），VETO 优先执行 |
| `enabled` | boolean | 是 | 单条规则开关 |
| `conditionOperator` | string | 否 | `AND`（默认）或 `OR`，条件匹配模式 |
| `conditions` | array | 否 | 条件列表（扁平结构） |

### 2.4 条件字段说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `indicator` | string | 是 | 指标 ID，见第 4 节 |
| `operator` | string | 是 | `GT` / `GTE` / `LT` / `LTE` / `EQ` / `NEQ` / `BETWEEN` |
| `value` | string | 是 | 预期值（字符串，引擎会自动解析为 double） |
| `direction` | string | 否 | `BOTH`（默认）/ `LONG` / `SHORT`，条件作用方向 |
| `params` | object | 否 | 指标参数，`{ "key": "value" }` 格式 |

### 2.5 运算符说明

| 运算符 | 含义 | 适用值类型 |
|---|---|---|
| `GT` | 大于 | SCORE, RATIO, ABSOLUTE |
| `GTE` | 大于等于 | SCORE, RATIO, ABSOLUTE |
| `LT` | 小于 | SCORE, RATIO, ABSOLUTE |
| `LTE` | 小于等于 | SCORE, RATIO, ABSOLUTE |
| `EQ` | 等于 | 全部类型 |
| `NEQ` | 不等于 | 全部类型 |
| `BETWEEN` | 在区间内 | SCORE, RATIO, ABSOLUTE |

### 2.6 条件匹配模式

- **AND**：所有条件必须全部满足 → 规则匹配
- **OR**：任意一条条件满足 → 规则匹配

### 2.7 方向过滤

条件中的 `direction` 字段控制条件仅在指定开仓方向下生效：

- `BOTH`：做多/做空都生效
- `LONG`：仅做多生效
- `SHORT`：仅做空生效

## 3. 权重计算规则

### 3.1 scoreToWeight 映射

引擎计算所有匹配规则的 `totalScore`（VETO 规则的 `vetoWeight` + SCORING 规则的 `score`），然后映射到最终权重：

| totalScore 区间 | 最终权重 |
|---|---|
| `totalScore >= 3.5` | 2.0 |
| `2.5 <= totalScore < 3.5` | 1.5 |
| `1.5 <= totalScore < 2.5` | 1.0 |
| `0.5 <= totalScore < 1.5` | 0.5 |
| `totalScore < 0.5` | 0.0 |

### 3.2 否决规则示例

如果一条 VETO 规则的条件未满足，引擎**立即返回否决**，最终权重为 0。

如果所有 VETO 规则都通过，累加它们的 `vetoWeight` 到总分。

### 3.3 无规则匹配

如果没有任何规则匹配（包括 VETO 和 SCORING），引擎返回`否决`，信号被过滤。

## 5. 配置示例

### 5.1 基础评分规则

方向一致 + 趋势强度达到 1.5 以上 → 加 2 分：

```json
{
  "name": "方向一致强趋势",
  "type": "SCORING",
  "score": 2.0,
  "order": 1,
  "enabled": true,
  "conditionOperator": "AND",
  "conditions": [
    {
      "indicator": "SMC_DIRECTION_ALIGNED",
      "operator": "EQ",
      "value": "1",
      "direction": "BOTH",
      "params": {}
    },
    {
      "indicator": "SMC_TREND_STRENGTH",
      "operator": "GTE",
      "value": "1.5",
      "direction": "BOTH",
      "params": {}
    }
  ]
}
```

### 5.2 否决规则

在供给区做多 → 直接否决：

```json
{
  "name": "供给区不做多",
  "type": "VETO",
  "vetoWeight": 0.2,
  "order": 2,
  "enabled": true,
  "conditionOperator": "AND",
  "conditions": [
    {
      "indicator": "SMC_IN_SUPPLY_ZONE",
      "operator": "EQ",
      "value": "1",
      "direction": "BOTH",
      "params": {}
    }
  ]
}
```

> 说明：VETO 规则是**条件不匹配**时否决。以上配置表示：当 `SMC_IN_SUPPLY_ZONE = 1` 时条件匹配 → VETO 规则通过 → 不否决；当 `SMC_IN_SUPPLY_ZONE ≠ 1` 时条件不匹配 → VETO 未通过 → 信号被否决。

### 5.3 OR 条件评分

15m 或 1h 位置评分 ≥ 2.0 → 加分：

```json
{
  "name": "SMC 位置评分激励",
  "type": "SCORING",
  "score": 0.5,
  "order": 3,
  "enabled": true,
  "conditionOperator": "OR",
  "conditions": [
    {
      "indicator": "SMC_POSITION_SCORE_15M",
      "operator": "GTE",
      "value": "2.0",
      "direction": "BOTH",
      "params": {}
    },
    {
      "indicator": "SMC_POSITION_SCORE_1H",
      "operator": "GTE",
      "value": "1.5",
      "direction": "BOTH",
      "params": {}
    }
  ]
}
```

### 5.4 EMA 技术指标规则

EMA 多头排列 + 比值过滤：

```json
{
  "name": "EMA 趋势过滤",
  "type": "SCORING",
  "score": 1.0,
  "order": 4,
  "enabled": true,
  "conditionOperator": "AND",
  "conditions": [
    {
      "indicator": "EMA_TREND",
      "operator": "EQ",
      "value": "UP",
      "direction": "BOTH",
      "params": { "fast_period": "9", "slow_period": "21" }
    },
    {
      "indicator": "EMA_RATIO",
      "operator": "GT",
      "value": "1.0",
      "direction": "BOTH",
      "params": {}
    }
  ]
}
```

### 5.5 时间过滤规则

## 6. 完整配置示例

一个完整的权重规则配置（总分能达到 4.2 → 最终权重 2.0）：

```json
{
  "enabled": true,
  "rules": [
    {
      "name": "方向一致强趋势",
      "type": "SCORING",
      "score": 2.0,
      "order": 1,
      "enabled": true,
      "conditionOperator": "AND",
      "conditions": [
        { "indicator": "SMC_DIRECTION_ALIGNED", "operator": "EQ", "value": "1", "direction": "BOTH", "params": {} },
        { "indicator": "SMC_TREND_STRENGTH", "operator": "GTE", "value": "1.5", "direction": "BOTH", "params": {} }
      ]
    },
    {
      "name": "供给区不做多",
      "type": "VETO",
      "vetoWeight": 0.2,
      "order": 2,
      "enabled": true,
      "conditionOperator": "AND",
      "conditions": [
        { "indicator": "SMC_IN_SUPPLY_ZONE", "operator": "EQ", "value": "1", "direction": "SHORT", "params": {} }
      ]
    },
    {
      "name": "需求区不做空",
      "type": "VETO",
      "vetoWeight": 0.2,
      "order": 3,
      "enabled": true,
      "conditionOperator": "AND",
      "conditions": [
        { "indicator": "SMC_IN_DEMAND_ZONE", "operator": "EQ", "value": "1", "direction": "LONG", "params": {} }
      ]
    },
    {
      "name": "EMA 趋势过滤",
      "type": "SCORING",
      "score": 1.0,
      "order": 4,
      "enabled": true,
      "conditionOperator": "AND",
      "conditions": [
        { "indicator": "EMA_TREND", "operator": "EQ", "value": "UP", "direction": "BOTH", "params": { "fast_period": "9", "slow_period": "21" } }
      ]
    },
    {
      "name": "SMC 位置评分激励",
      "type": "SCORING",
      "score": 0.5,
      "order": 5,
      "enabled": true,
      "conditionOperator": "OR",
      "conditions": [
        { "indicator": "SMC_POSITION_SCORE_15M", "operator": "GTE", "value": "2.0", "direction": "BOTH", "params": {} },
        { "indicator": "SMC_POSITION_SCORE_1H", "operator": "GTE", "value": "1.5", "direction": "BOTH", "params": {} }
      ]
    },
    {
      "name": "盈亏比加分",
      "type": "SCORING",
      "score": 0.5,
      "order": 6,
      "enabled": true,
      "conditionOperator": "AND",
      "conditions": [
        { "indicator": "SMC_NET_RR", "operator": "GTE", "value": "2.0", "direction": "BOTH", "params": {} }
      ]
    }
  ]
}
```

> 评估过程：
> 1. VETO 规则 `供给区不做多`（做空方向，条件不匹配 → 通过）+0.2
> 2. VETO 规则 `需求区不做空`（做空方向，条件匹配 → 通过）+0.2
> 3. SCORING 规则 `方向一致强趋势` 匹配 +2.0
> 4. SCORING 规则 `EMA 趋势过滤` 匹配 +1.0
> 5. SCORING 规则 `SMC 位置评分激励`（OR）匹配 +0.5
> 6. SCORING 规则 `盈亏比加分` 匹配 +0.5
> **总分 = 4.4 → 最终权重 = 2.0**

## 8. 最佳实践

### 8.1 规则设计建议

1. **VETO 规则放前面**：order 1～10 留给否决规则，确保尽早拦截无效信号
2. **关键趋势用 AND**：核心条件使用 AND 模式，确保所有必要条件满足
3. **替代条件用 OR**：当多个条件中的任意一个满足即可时使用 OR
4. **评分值 0.5～2.0**：单条规则评分不宜过大，建议 0.5（轻微加分）～2.0（强烈加分）
5. **总分目标 3.5+**：高分信号需要多条规则同时命中

### 8.2 否决规则使用技巧

- **VETO 规则是门卫**：条件不匹配 → 否决。所以配置时要**反向思考**
- 例如"供给区不做多" → 当 `SMC_IN_SUPPLY_ZONE = 1` 时条件匹配 → VETO 通过 → 不否决；反之条件不匹配 → 否决
- 方向特异性否决用 `direction` 字段：做空时不检查供给区

### 8.3 调试建议

1. 先单独测试每条规则是否按预期匹配
2. 使用测试 API 查看完整的 trace 链路
3. 检查 `indicatorSnapshot` 确认指标实际值
4. 逐步增加规则，每次添加一条并验证结果
