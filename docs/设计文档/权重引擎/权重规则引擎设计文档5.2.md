## 1. 背景与目标

### 1.1 问题陈述

| 问题 | 描述 |
|------|------|
| **硬编码评分** | 信号权重计算采用硬编码逻辑，交易员无法动态调整 |
| **指标耦合** | 新增指标需前后端联动发版，灵活性极低 |
| **类型受限** | `EMA_TREND` 等非数值指标在引擎中硬编码特殊处理 |
| **语义混乱** | VETO 规则「条件不匹配才否决」与业务直觉相反 |
| **权重跳变** | 阶梯映射导致差 0.1 分权重从 1.5 跳到 2.0 |
| **无法惩罚** | 不支持负分，无法表达「逆势减分」逻辑 |
| **追踪困难** | 无法定位是哪个具体条件触发了否决 |
| **周期耦合** | 信号周期与指标计算周期绑定，无法跨周期判断 |
| **调用复杂** | 调用方需提前组装多周期 K 线数据，增加使用成本 |

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| **动态规则配置** | 通过前端界面自由组合指标条件，无需重启服务 |
| **指标可插拔** | 新增指标只需实现 SPI，前端自动获取元数据并渲染 |
| **通用类型系统** | 支持 NUMERIC/STRING/ENUM/BOOLEAN 任意类型 |
| **语义正确** | VETO = 条件匹配即否决（黑名单模式） |
| **灵活评分** | 双因素可配置：VETO 贡献开关 + 阶梯/线性映射；SCORING 原生支持负分 |
| **多周期支持** | 每个条件独立指定数据周期，懒加载 + 缓存，调用方只传信号周期 |
| **可观测性** | 完整 Trace + 命中条件明确记录 |
| **版本管理** | 规则版本保存、回滚、灰度发布 |

## 2. 核心概念与术语

| 术语 | 定义 |
|------|------|
| **规则引擎** | 核心评估组件，负责解析规则、计算指标、执行两阶段评估 |
| **指标** | 可计算的特征，如 `SMC_TREND_STRENGTH`、`EMA_TREND`、`PRICE_VS_EMA` |
| **条件** | 单条判断规则：指标 + 运算符 + 期望值 + 方向过滤 + 数据周期 |
| **SCORING 规则** | 条件匹配时累加 `score`（可为负数）到总分 |
| **VETO 规则** | 条件匹配时直接否决信号（黑名单模式） |
| **否决** | 信号因命中 VETO 规则被驳回，不产生交易信号 |
| **评估上下文** | `WeightRuleContext` 包含信号周期、K 线数据、SMC 评分等 |
| **执行轨迹** | 完整的规则执行链路，含逐规则/逐条件评估结果 |
| **指标快照** | 当前上下文中所有指标值快照，用于调试 |
| **线性斜率** | 总分→权重的放大系数：权重 = 总分 × 斜率 |
| **数据周期** | 条件中 `params.dataPeriod` 指定使用哪个周期的 K 线数据 |
| **信号周期** | `WeightRuleContext.signalPeriod` 标识当前信号触发周期 |
| **懒加载缓存** | Context 中按需查询并缓存多周期 K 线数据，避免重复查询 |
| **ParamDef** | 指标参数定义，描述用户配置规则时需要填写的表单字段 |
| **ValueRange** | 指标取值范围，描述指标计算结果的合法数值区间 |

4.1.2 WeightScoringConfig（评分配置 — 双因素版）
java
@Data
public class WeightScoringConfig {
    /**
     * 方案 A：VETO 规则通过时是否累加 vetoWeight 到总分
     * true（默认）：累加，给予安全基础分
     * false：VETO 纯否决，不参与评分
     */
    private Boolean vetoContributeScore = true;

    /**
     * 方案 B：权重映射模式
     * "STEP"（默认）：阶梯映射 (0.5/1.0/1.5/2.0)
     * "LINEAR"：线性映射 (权重 = 总分 × 斜率)
     */
    private String mappingMode = "STEP";

    /**
     * 线性映射斜率（仅 LINEAR 模式生效）
     * 含义：每得 1 分对应的权重增量
     * 默认 0.6，范围建议 0.1 ~ 1.5
     */
    private Double linearSlope = 0.6;

    /**
     * 线性映射最小权重（clamp 下限）
     * 默认 0.0
     */
    private Double linearMinWeight = 0.0;

    /**
     * 线性映射最大权重（clamp 上限）
     * 默认 2.0
     */
    private Double linearMaxWeight = 2.0;
}
⚠️ 重要说明：SCORING 规则的 score 字段始终允许负数，无需额外配置。这是原生能力，不设开关。总分可以为负，映射前统一 max(0, totalScore) 截断，确保权重非负。

        register("SMC_IN_SUPPLY_ZONE", "在供给区", "SMC",

        register("SMC_IN_DEMAND_ZONE", "在需求区", "SMC",

                Arrays.asList("EQ", "NEQ"),
                (ctx, p) -> IndicatorValue.of(ctx.getSmcInDemandZone() != null ? ctx.getSmcInDemandZone().doubleValue() : 0.0));

        // ==================== 枚举型指标 ====================

        // 1. EMA_TREND：EMA 趋势方向（支持多周期）
        register("EMA_TREND", "EMA趋势方向", "TECHNICAL",
                "快慢EMA比较结果", "ENUM", null,
                Arrays.asList("BULLISH", "BEARISH"),

    private double calcEma(List<WeightRuleContext.CandlestickSnapshot> kLines, int period) {
        if (kLines == null || kLines.size() < period) {
            return calcSma(kLines, period);
        }
        double multiplier = 2.0 / (period + 1);
        double ema = kLines.get(0).getClose();
        for (int i = 1; i < kLines.size(); i++) {
            ema = (kLines.get(i).getClose() - ema) * multiplier + ema;
        }
        return ema;
    }

    private double calcSma(List<WeightRuleContext.CandlestickSnapshot> kLines, int period) {
        if (kLines == null || kLines.isEmpty()) return 0;
        int count = Math.min(period, kLines.size());
        double sum = 0;
        for (int i = kLines.size() - count; i < kLines.size(); i++) {
            sum += kLines.get(i).getClose();
        }
        return sum / count;
    }

                          String valueType, ValueRange range, List<String> enumValues,
                          List<ParamDef> params, List<String> operators,

        meta.setId(id);
        meta.setName(name);
        meta.setCategory(category);
        meta.setDescription(desc);
        meta.setValueType(valueType);
        meta.setValueRange(range);
        meta.setEnumValues(enumValues);
        meta.setParams(params != null ? params : new ArrayList<>());
        meta.setOperators(operators);
        metadatas.put(id, meta);
        resolvers.put(id, resolver);
    }

    @FunctionalInterface
    private interface IndicatorResolver {
        IndicatorValue resolve(WeightRuleContext ctx, Map<String, String> params);
    }

     */

    // ==================== 核心方法：懒加载获取 K 线 ====================

    /**
     * 获取指定周期的 K 线数据（懒加载 + 缓存）
     */
    public List<CandlestickSnapshot> getKLinesForPeriod(String period, ICandlestickService service) {
        if (period == null || period.isEmpty() || period.equals(signalPeriod)) {
            return this.kLines;
        }

        List<CandlestickSnapshot> cached = periodKLineCache.get(period);
        if (cached != null) {
            return cached;
        }

        if (service == null || symbol == null || this.kLines == null || this.kLines.isEmpty()) {
            return null;
        }

        CandlestickIntervalEnum interval = parsePeriod(period);
        if (interval == null) {
            return null;
        }

        try {
            Long latestId = this.kLines.get(this.kLines.size() - 1).getId();
            long targetIntervalMs = interval.getMinNum() * 60L * 1000L;
            long alignedBoundary = (latestId / targetIntervalMs) * targetIntervalMs;
            long lastCompleteCandleId = alignedBoundary - targetIntervalMs;

            List<Candlestick> candlesticks = service.listByLeId(
                    lastCompleteCandleId, symbol, interval, 200);

            if (candlesticks == null || candlesticks.isEmpty()) {
                return null;
            }

            List<CandlestickSnapshot> result = candlesticks.stream()
                    .map(this::toSnapshot)
                    .collect(Collectors.toList());

            periodKLineCache.put(period, result);
            return result;

        } catch (Exception e) {
            log.warn("获取周期 {} K线数据失败: {}", period, e.getMessage());
            return null;
        }
    }

    /**
     * 预加载多周期 K 线数据（可选，提升首次评估性能）
     */
    public void preloadPeriodKLines(List<String> periods, ICandlestickService service) {
        for (String period : periods) {
            getKLinesForPeriod(period, service);
        }
    }

    private CandlestickIntervalEnum parsePeriod(String period) {
        for (CandlestickIntervalEnum interval : CandlestickIntervalEnum.values()) {
            if (interval.getCode().equalsIgnoreCase(period)) {

        snapshot.setLow(c.getLowPrice().doubleValue());
        snapshot.setClose(c.getClosePrice().doubleValue());
        return snapshot;
    }

4.2.5 WeightRuleEngine（核心引擎）
java
@Component
@Slf4j
public class WeightRuleEngine {

    @Autowired
    private IndicatorProviderRegistry registry;

    @Autowired
    private ICandlestickService candlestickService;

    // ==================== 公开方法 ====================

    public WeightRuleResult evaluate(WeightRuleConfig config, WeightRuleContext ctx) {
        RuleEvaluationResult fullResult = evaluateWithTrace(config, ctx);
        if (fullResult == null) return null;
        return new WeightRuleResult(
            fullResult.isVetoed(),
            fullResult.getFinalWeight(),
            fullResult.getTotalScore(),
            fullResult.getReason()
        );
    }

    public RuleEvaluationResult evaluateWithTrace(WeightRuleConfig config,
                                                   WeightRuleContext ctx) {
        if (config == null || !config.isEnabled() || 
            config.getRules() == null || config.getRules().isEmpty()) {
            return null;
        }

        List<WeightRule> sorted = config.getRules().stream()
                .filter(r -> r != null && r.isEnabled())
                .sorted(Comparator.comparingInt(WeightRule::getOrder))
                .collect(Collectors.toList());

        if (sorted.isEmpty()) return null;

        List<RuleEvaluationTrace> traces = new ArrayList<>();
        Map<String, Double> indicatorSnapshot = new LinkedHashMap<>();
        double totalScore = 0;
        int matchedRules = 0;
        StringBuilder reason = new StringBuilder();

        WeightScoringConfig scoringCfg = config.getScoringConfig();

        // ===== Pass 1: VETO 规则（黑名单模式） =====
        for (WeightRule rule : sorted) {
            if (!"VETO".equalsIgnoreCase(rule.getType())) continue;

            ConditionEvalResult evalResult = evaluateConditionsWithTrace(
                    rule.getConditions(), rule.getConditionOperator(), ctx, indicatorSnapshot);

            RuleEvaluationTrace trace = buildTrace(rule, evalResult);

            if (evalResult.matched) {
                trace.setMatched(true);
                trace.setContribution(0);

                String hitDetail = evalResult.conditionTraces.stream()
                        .filter(RuleEvaluationTrace.ConditionTrace::isMatched)
                        .findFirst()
                        .map(ct -> ct.getIndicator() + " " + ct.getOperator() + " " + ct.getExpectedValue())
                        .orElse("未知条件");

                trace.setReason("否决触发，命中条件: " + hitDetail);
                traces.add(trace);

                String msg = String.format("否决规则[%s]触发，命中条件: %s", rule.getName(), hitDetail);
                log.info("WeightRule veto: {}", msg);
                return RuleEvaluationResult.veto(msg, traces, indicatorSnapshot);
            }

            boolean shouldContribute = scoringCfg == null || scoringCfg.getVetoContributeScore() == null
                    || scoringCfg.getVetoContributeScore();

            double w = shouldContribute 
                    ? (rule.getVetoWeight() != null ? rule.getVetoWeight() : 0.2)
                    : 0.0;

            trace.setMatched(false);
            trace.setContribution(w);
            trace.setReason(shouldContribute 
                    ? String.format("否决规则通过，贡献权重 %.2f", w)
                    : "否决规则通过（不参与评分）");
            traces.add(trace);
            totalScore += w;
            matchedRules++;
            if (reason.length() > 0) reason.append(" + ");
            reason.append(rule.getName()).append("=").append(String.format("%.2f", w));
        }

        // ===== Pass 2: SCORING 规则（原生支持负分） =====
        for (WeightRule rule : sorted) {
            if ("VETO".equalsIgnoreCase(rule.getType())) continue;

            ConditionEvalResult evalResult = evaluateConditionsWithTrace(
                    rule.getConditions(), rule.getConditionOperator(), ctx, indicatorSnapshot);

            RuleEvaluationTrace trace = buildTrace(rule, evalResult);

            if (!evalResult.matched) {
                trace.setMatched(false);
                trace.setContribution(0);
                trace.setReason("条件未匹配");
                traces.add(trace);
                continue;
            }

            double s = rule.getScore() != null ? rule.getScore() : 0;
            trace.setMatched(true);
            trace.setContribution(s);
            trace.setReason(String.format("规则匹配，贡献评分 %.2f", s));
            traces.add(trace);
            totalScore += s;
            matchedRules++;
            if (reason.length() > 0) reason.append(" + ");
            reason.append(rule.getName()).append("=").append(String.format("%.2f", s));
        }

        // ===== 结果判定 =====
        if (matchedRules == 0) {
            return RuleEvaluationResult.veto("无规则匹配，信号被否决", traces, indicatorSnapshot);
        }

        double finalWeight = scoreToWeight(totalScore, scoringCfg);
        String rsn = String.format("评分: %.2f -> 权重: %.1f (%s)", totalScore, finalWeight, reason);
        return RuleEvaluationResult.scored(finalWeight, totalScore, rsn, traces, indicatorSnapshot);
    }

    // ==================== 双因素权重映射（原生支持负分） ====================

    /**
     * 总分 → 最终权重映射
     * 设计原则：
     * 1. 先截断负分到 0（总分可以为负，但权重不能为负）
     * 2. 再按 STEP 或 LINEAR 模式映射
     */
    private double scoreToWeight(double rawScore, WeightScoringConfig cfg) {
        // 核心：负分截断到 0（原生支持负分，但权重非负）
        double clampedScore = Math.max(rawScore, 0.0);

        // 方案 B：映射模式
        if (cfg != null && "LINEAR".equalsIgnoreCase(cfg.getMappingMode())) {
            double slope = cfg.getLinearSlope() != null ? cfg.getLinearSlope() : 0.6;
            double minWeight = cfg.getLinearMinWeight() != null ? cfg.getLinearMinWeight() : 0.0;
            double maxWeight = cfg.getLinearMaxWeight() != null ? cfg.getLinearMaxWeight() : 2.0;

            double weight = clampedScore * slope;
            return Math.max(minWeight, Math.min(maxWeight, weight));
        }

        // 默认：阶梯映射（v5.0 兼容）
        if (clampedScore >= 3.5) return 2.0;
        if (clampedScore >= 2.5) return 1.5;
        if (clampedScore >= 1.5) return 1.0;
        if (clampedScore >= 0.5) return 0.5;
        return clampedScore;
    }

    // ==================== 条件评估 ====================

    private ConditionEvalResult evaluateConditionsWithTrace(
            List<RuleCondition> conditions, String conditionOperator,
            WeightRuleContext ctx, Map<String, Double> indicatorSnapshot) {

        ConditionEvalResult result = new ConditionEvalResult();
        result.conditionTraces = new ArrayList<>();

        if (conditions == null || conditions.isEmpty()) {
            result.matched = true;
            return result;
        }

        boolean isAnd = conditionOperator == null || "AND".equalsIgnoreCase(conditionOperator);
        boolean anyEvaluated = false;

        for (RuleCondition cond : conditions) {
            if (isDirectionSkipped(cond, ctx)) continue;
            anyEvaluated = true;

            RuleEvaluationTrace.ConditionTrace ct = evaluateConditionWithTrace(
                    cond, ctx, indicatorSnapshot);
            result.conditionTraces.add(ct);

            if (isAnd && !ct.isMatched()) {
                result.matched = false;
                return result;
            }
            if (!isAnd && ct.isMatched()) {
                result.matched = true;
                return result;
            }
        }

        if (!anyEvaluated) {
            result.matched = false;
            return result;
        }
        result.matched = isAnd;
        return result;
    }

    private RuleEvaluationTrace.ConditionTrace evaluateConditionWithTrace(
            RuleCondition cond, WeightRuleContext ctx, 
            Map<String, Double> indicatorSnapshot) {

        RuleEvaluationTrace.ConditionTrace ct = new RuleEvaluationTrace.ConditionTrace();
        ct.setIndicator(cond.getIndicator());
        ct.setOperator(cond.getOperator());
        ct.setDirection(cond.getDirection());
        ct.setExpectedValue(cond.getValue());
        ct.setParams(cond.getParams());

        IndicatorValue actual = registry.resolve(cond.getIndicator(), ctx, cond.getParams());
        recordSnapshot(indicatorSnapshot, cond, actual);

        if (actual == null) {
            ct.setActualValue(null);
            ct.setValueType(null);
            ct.setMatched(false);
            return ct;
        }

        ct.setActualValue(actual.toString());
        ct.setValueType(actual.getType().name());

        switch (actual.getType()) {
            case NUMERIC:
                ct.setMatched(evaluateNumeric(actual.getNumericValue(), cond));
                break;
            case STRING:
            case ENUM:
                ct.setMatched(evaluateString(actual.getStringValue(), cond));
                break;
            case BOOLEAN:
                ct.setMatched(evaluateBoolean(actual.getBooleanValue(), cond));
                break;
            default:
                ct.setMatched(false);
        }
        return ct;
    }

    // ==================== 类型比较器 ====================

    private boolean evaluateNumeric(Double val, RuleCondition cond) {
        double expected = Double.parseDouble(cond.getValue());
        OperatorType op = OperatorType.valueOf(cond.getOperator().toUpperCase());
        switch (op) {
            case GT: return val > expected;
            case GTE: return val >= expected;
            case LT: return val < expected;
            case LTE: return val <= expected;
            case EQ: return Math.abs(val - expected) < 1e-8;
            case NEQ: return Math.abs(val - expected) >= 1e-8;
            case IN: return Arrays.stream(cond.getValue().split(","))
                    .anyMatch(v -> Math.abs(val - Double.parseDouble(v.trim())) < 1e-8);
            case NOT_IN: return Arrays.stream(cond.getValue().split(","))
                    .noneMatch(v -> Math.abs(val - Double.parseDouble(v.trim())) < 1e-8);
            default: return false;
        }
    }

    private boolean evaluateString(String val, RuleCondition cond) {
        OperatorType op = OperatorType.valueOf(cond.getOperator().toUpperCase());
        String expected = cond.getValue();
        switch (op) {
            case EQ: return val.equalsIgnoreCase(expected);
            case NEQ: return !val.equalsIgnoreCase(expected);
            case IN: return Arrays.stream(expected.split(","))
                    .anyMatch(v -> val.equalsIgnoreCase(v.trim()));
            case NOT_IN: return Arrays.stream(expected.split(","))
                    .noneMatch(v -> val.equalsIgnoreCase(v.trim()));
            default:
                log.warn("运算符 {} 不适用于字符串类型", op);
                return false;
        }
    }

    private boolean evaluateBoolean(Boolean val, RuleCondition cond) {
        boolean expected = Boolean.parseBoolean(cond.getValue());
        OperatorType op = OperatorType.valueOf(cond.getOperator().toUpperCase());
        switch (op) {
            case EQ: return val == expected;
            case NEQ: return val != expected;
            default:
                log.warn("运算符 {} 不适用于布尔类型", op);
                return false;
        }
    }

    // ==================== 工具方法 ====================

    private boolean isDirectionSkipped(RuleCondition cond, WeightRuleContext ctx) {
        if (cond.getDirection() == null || "BOTH".equalsIgnoreCase(cond.getDirection())) {
            return false;
        }
        return ("LONG".equalsIgnoreCase(cond.getDirection()) && !ctx.isBuy())
                || ("SHORT".equalsIgnoreCase(cond.getDirection()) && ctx.isBuy());
    }

    private void recordSnapshot(Map<String, Double> snapshot, RuleCondition cond, IndicatorValue value) {
        if (snapshot == null || cond == null || cond.getIndicator() == null || value == null) return;
        String key = cond.getIndicator();
        if (cond.getParams() != null && !cond.getParams().isEmpty()) {
            key += "(" + cond.getParams().entrySet().stream()
                    .map(e -> e.getKey() + "=" + e.getValue())
                    .collect(Collectors.joining(",")) + ")";
        }
        if (value.getType() == IndicatorValue.Type.NUMERIC && value.getNumericValue() != null) {
            snapshot.putIfAbsent(key, value.getNumericValue());
        }
    }

    private RuleEvaluationTrace buildTrace(WeightRule rule, ConditionEvalResult evalResult) {
        RuleEvaluationTrace trace = new RuleEvaluationTrace();
        trace.setRuleName(rule.getName());
        trace.setRuleType(rule.getType());
        trace.setConditionOperator(rule.getConditionOperator());
        trace.setConditionResults(evalResult.conditionTraces);
        return trace;
    }

    @Data
    private static class ConditionEvalResult {
        boolean matched;
        List<RuleEvaluationTrace.ConditionTrace> conditionTraces;
    }
}

    @Override
    public IndicatorValue resolve(WeightRuleContext ctx, Map<String, String> params) {
        int period = Integer.parseInt(params.getOrDefault("period", "14"));
        String dataPeriod = params.get("dataPeriod");

        List<WeightRuleContext.CandlestickSnapshot> kLines = 
                ctx.getKLinesForPeriod(dataPeriod, candlestickService);

        if (kLines == null || kLines.size() < period) {
            return IndicatorValue.of("NEUTRAL");
        }

        double rsi = calculateRSI(kLines, period);
        if (rsi > 70) return IndicatorValue.of("OVERBOUGHT");
        if (rsi < 30) return IndicatorValue.of("OVERSOLD");
        return IndicatorValue.of("NEUTRAL");
    }

    @Override
    public IndicatorMetadata getMetadata() {
        IndicatorMetadata meta = new IndicatorMetadata();
        meta.setId("RSI_SIGNAL");
        meta.setName("RSI超买超卖信号");
        meta.setCategory("TECHNICAL");
        meta.setValueType("ENUM");
        meta.setEnumValues(Arrays.asList("OVERBOUGHT", "OVERSOLD", "NEUTRAL"));
        meta.setOperators(Arrays.asList("EQ", "NEQ", "IN", "NOT_IN"));
        meta.setParams(Arrays.asList(
            new ParamDef("period", "RSI周期", "integer", 14, null, null, 1.0, null),
            new ParamDef("dataPeriod", "K线周期", "select", null, null, null, null,
                    Arrays.asList("1m", "5m", "15m", "30m", "1h", "4h", "1d"))
        ));
        return meta;
    }
}

4.4.2 条件评估（AND/OR）
模式	评估逻辑
AND	所有条件必须全部匹配 → true；任一条件不匹配 → false
OR	任一条件匹配 → true；所有条件都不匹配 → false
4.4.3 方向过滤
层级	字段	作用
规则级	WeightRule.direction	整条规则是否对当前信号方向生效
条件级	RuleCondition.direction	单条条件是否参与评估
4.5 否决规则语义裁定
最终裁定：VETO 规则 = 条件匹配时否决（黑名单模式）

场景	条件结果	方向是否适用	引擎行为
条件匹配（命中危险信号）	true	是	触发否决，信号驳回
条件不匹配（安全信号）	false	是	通过，根据配置决定是否累加分
方向不匹配	—	否	跳过（不否决不加分）
4.6 双因素权重评分系统
4.6.1 方案 A：VETO 评分贡献
配置值	行为
vetoContributeScore = true（默认）	VETO 通过时累加 vetoWeight 到总分
vetoContributeScore = false	VETO 纯否决开关，不参与评分
4.6.2 方案 B：权重映射模式
模式	公式	特点
STEP（默认）	阶梯分段映射 (0.5/1.0/1.5/2.0)	离散等级，适合分类策略
LINEAR	weight = clamp(clampedScore × slope, min, max)	连续变化，适合精细仓位管理
4.6.3 原生负分支持
特性	说明
SCORING 的 score	始终允许为负数，无开关控制
总分计算	累加所有匹配的 SCORING score（可正可负）+ VETO 贡献分
权重映射	映射前统一 max(0, totalScore) 截断，确保权重非负
业务语义	负分规则表达「逆势减分」、「规避信号」等惩罚逻辑
4.7 多周期 K 线支持（懒加载缓存）

8.3 ParamDef 与 ValueRange 说明
概念	作用	使用场景
ParamDef	描述用户配置规则时需要填写的参数（输入）	指标需要用户配参数时定义，如 EMA 周期、dataPeriod
ValueRange	描述指标计算结果的合法数值区间（输出）	数值型指标建议定义，用于前端校验和可视化
ParamDef 示例（EMA_TREND）：

java
new ParamDef("fast", "快线周期", "integer", 9, null, null, 1.0, null)
// 参数名=fast, 标签=快线周期, 类型=整数, 默认值=9
ValueRange 示例（SMC_POSITION_SCORE）：

java
new ValueRange(-5.0, 5.0)
// 指标输出范围：-5 ~ 5
