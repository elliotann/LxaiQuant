## 1. 项目概述

### 1.1 背景
现有系统中已支持单个机器人的资产曲线展示，用户需要在同一图表中对比多个机器人的权益（资产）走势，以便直观评估不同策略的表现优劣。

### 1.2 业务目标
- 提供多机器人权益对比图，支持折线图叠加展示
- 支持原始权益（绝对资产）和归一化净值（相对表现）两种模式
- 提供灵活的时间范围选择（预设快捷选项 + 自定义日期）
- 自动计算每个机器人的总收益、年化收益、最大回撤等关键绩效指标

### 1.3 技术目标
- 基于现有 Java + Vue 3 + Element Plus 技术栈
- 使用 ECharts 作为图表渲染引擎
- 后端提供 RESTful API，支持多机器人并发查询与日期对齐
- 前端组件化设计，可独立嵌入任何页面

## 3. 数据库设计

### 3.1 统一净值曲线表（改造已有表）

使用已有的 `backtest_equity_curve` 表，新增 `robot_id`、`robot_name` 字段以兼容实盘机器人数据：

- **回测数据**: `task_id` 非空，`robot_id` 为空，秒级精度
- **实盘数据**: `robot_id` 非空，`task_id` 为空，日级精度（`time` = 当日 00:00:00）

```sql
CREATE TABLE IF NOT EXISTS backtest_equity_curve (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    task_id VARCHAR(64) NULL COMMENT '回测任务ID（回测数据）',
    robot_id VARCHAR(32) NULL COMMENT '机器人ID（实盘数据）',
    robot_name VARCHAR(64) NULL COMMENT '机器人名称',
    time DATETIME NOT NULL COMMENT '时间（秒级精度）',

    -- 策略净值
    equity DECIMAL(18,4) NOT NULL COMMENT '净值',
    daily_return DECIMAL(10,6) COMMENT '日收益率',

    -- 回撤
    drawdown DECIMAL(10,6) COMMENT '回撤',

    -- 基准曲线
    benchmark_value DECIMAL(12,4) COMMENT '基准指数净值',
    benchmark_daily_return DECIMAL(10,6) COMMENT '基准日收益率',

    -- 索引
    UNIQUE KEY uk_task_time (task_id, time),
    UNIQUE KEY uk_robot_time (robot_id, time),
    INDEX idx_task_id (task_id),
    INDEX idx_robot_id (robot_id),
    INDEX idx_time (time),

    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间'
) COMMENT='净值曲线表（回测+实盘统一）';
```

### 3.2 数据示例

```sql
-- 实盘机器人日终权益
INSERT INTO backtest_equity_curve (robot_id, robot_name, time, equity) VALUES
('robot_1', '小市值增强', '2025-01-01 00:00:00', 100.00),
('robot_1', '小市值增强', '2025-01-02 00:00:00', 101.50),
('robot_1', '小市值增强', '2025-01-03 00:00:00', 102.30),
('robot_2', '北交所轮动', '2025-01-01 00:00:00', 200.00),
('robot_2', '北交所轮动', '2025-01-03 00:00:00', 205.00);  -- 缺少01-02，查询时需前向填充
```

### 3.3 索引说明

- `uk_task_time`: 防止回测数据重复
- `uk_robot_time`: 防止实盘机器人同一天重复入库
- `idx_robot_id`: 加速机器人维度查询
- `idx_time`: 加速时间范围查询

### 3.4 trading_bot 表变更

```sql
ALTER TABLE `trading_bot`
ADD COLUMN `peak_capital` decimal(20,4) DEFAULT NULL COMMENT '历史最高权益，用于计算最大回撤';
```

**说明**:
- `peak_capital` 仅在 `current_capital` 创历史新高时更新，无需每日刷新
- 衍生指标均不存储，查询时实时计算

### 3.5 衍生指标计算规则

| 指标 | 计算方式 | 来源 |
|------|----------|------|
| `today_pnl` | `current_capital` - 昨日权益 | `trading_bot.current_capital` - `backtest_equity_curve.equity`（昨日） |
| `total_return` | (`current_capital` - `allocated_capital`) / `allocated_capital` × 100% | `trading_bot` 两个字段实时计算 |
| `drawdown` | (`peak_capital` - `current_capital`) / `peak_capital` × 100% | `trading_bot.peak_capital` + `current_capital` 实时计算 |

## 4. 后端接口设计

### 4.1 多机器人权益对比

```
GET /api/robot/equity/compare
```

**请求参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| robotIds | String | 是 | 机器人ID列表，逗号分隔（前端限制最多3个） |
| startDate | String | 是 | 开始日期，格式 yyyy-MM-dd |
| endDate | String | 是 | 结束日期，格式 yyyy-MM-dd |
| alignType | String | 否 | absolute(默认) 返回原始权益；normalized 返回归一化净值 |

**响应结构**

```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "robotId": "robot_1",
      "robotName": "小市值增强",
      "dates": ["2025-01-01", "2025-01-02", "2025-01-03"],
      "equities": [100.00, 101.50, 102.30],
      "navs": [1.0000, 1.0150, 1.0230]
    },
    {
      "robotId": "robot_2",
      "robotName": "北交所轮动",
      "dates": ["2025-01-01", "2025-01-02", "2025-01-03"],
      "equities": [200.00, 200.00, 205.00],
      "navs": [1.0000, 1.0000, 1.0250]
    }
  ]
}
```

**核心逻辑**: 查询 `backtest_equity_curve` 表 → 按 `robot_id` 分组 → 逐日前向填充缺失值 → 可选归一化

### 4.2 所有机器人最新权益快照

```
GET /api/robot/equity/latest
```

**请求参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| robotIds | String | 否 | 机器人ID列表，逗号分隔，不传则返回所有 |

**响应结构**

```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "robotId": "robot_1",
      "robotName": "小市值增强",
      "currentCapital": 102.30,
      "allocatedCapital": 100.00,
      "peakCapital": 105.00,
```

**核心逻辑**: 查询 `trading_bot` → 获取 `currentCapital` / `peakCapital` → 查询 `backtest_equity_curve` 获取昨日权益 → 实时计算 `todayPnl`、`totalReturn`、`drawdown`

## 6. 定时任务设计

### 6.1 RobotEquityJob

- **调度**: XXL-Job，`robotEquityCollectJob`
- **执行时机**: 每日收盘后（如 16:00）
- **逻辑**:
  1. 遍历所有 `trading_bot`
  2. 检查当天的数据是否已存在（幂等）
  3. 写入 `backtest_equity_curve`（`robot_id` + `time` 为当日 00:00:00 + `equity` = `current_capital`）
  4. 若 `current_capital > peak_capital`，更新 `peak_capital`

## 7. 关键技术要点

### 7.1 日期对齐与前向填充

查询时后端生成完整日期序列 [startDate, endDate]，逐日扫描：

```
遍历日期序列:
  当前日期有权益 → 使用该值
  当前日期无权益 → 使用最近的前一个有效值（前向填充）
  序列开头无数据 → 从第一个有效值开始填充后续
```

### 7.2 归一化模式

当 `alignType=normalized` 时，每个机器人序列的第一个有效权益作为基准（=1.0），后续值除以基准得到净值序列。

### 7.3 绩效指标计算

前端基于权益/净值序列实时计算：总收益、年化收益、最大回撤。
