## 1. 引言

### 1.1 编写目的

当前系统基于 TA4J 扩展（ai-extension 模块），经过多轮迭代后暴露出以下架构问题：

| 问题 | 表现 | 根因 |
|------|------|------|
| **业务耦合严重** | 策略逻辑、规则判断、持仓管理全部与 TA4J 的 `TradingRecord`/`Position` 深度绑定 | 在 TA4J 框架内做扩展，而非在框架之上构建 |
| **改造阻力大** | 每次新增功能都需要理解 TA4J 内部机制，改动成本高 | TA4J 的 Strategy/Rule/TradingRecord 接口虽灵活，但扩展方向受限其设计哲学 |
| **回测性能瓶颈** | 回测循环与 TA4J 的 `BarSeriesManager` 绑定，无法定制执行模型 | 自定义执行模型需要在 TA4J 框架内做适配 |
| **双向持仓不自然** | 为了支持双向持仓需要 `CompositeTradingRecord` 等适配层 | TA4J 原生设计以单持仓为核心 |
| **回测/实盘代码不一致** | 回测走 TA4J 路径，实盘走自定义路径，两套代码需要分别维护 | 缺乏统一抽象层 |

**设计目标**：

- **完全自研核心引擎**：策略执行、回测循环、持仓管理全部自研，TA4J 仅作为指标计算库
- **回测/实盘双模归一**：同一套策略代码可运行于回测和实盘，仅执行引擎不同
- **高性能回测**：循环内零数据库 I/O，全部内存计算，批量写入
- **易于扩展**：策略、规则、执行模型均可通过 SPI/插件机制扩展
- **事件驱动**：借鉴 QuantDinger 的事件/钩子系统，引擎运行过程可监听、可干预

> **重构约束**：本文档为代码重构的设计基准，所有引擎模块需按文档规划的结构重构。业务逻辑必须与 `DefaultDealStrategyTrade` 保持一致——该类的逻辑是业务基线，任何偏差均需评审确认。

### 1.2 范围

| 模块 | 范围说明 | 是否新建 |
|------|---------|---------|
| **规则引擎模块** | TradingRule 接口体系，与 TA4J 完全解耦 | 新建（`engine2.rules`） |
| **交易引擎核心模块** | ScriptStrategy 策略接口、TradingContext、AbstractEngine 模板方法、BacktestEngine/PaperEngine/LiveEngine | 新建（`engine2.core`） |
| **持久化门面模块** | PersistenceGateway 接口、BacktestBatchGateway、PaperBatchGateway、LiveAsyncGateway、Converter | 新建（`engine2.persistence`） |
| **指标工具模块** | Ta4jIndicatorHelper 封装 TA4J 指标计算 | 新建（`engine2.indicator`） |
| **成本模型模块** | CostModel 接口及多种实现，支持多交易所多市场成本计算 | 新建（`engine2.core.cost`） |
| **风控集成** | 接入现有 `ai-risk` 模块 | 适配复用 |
| **恢复推送机制** | PendingOrderWorker 轮询实盘订单成交状态 | 新建（`engine2.lifecycle`） |
| **智能调参模块** | OptimizeFacade、ParameterOptimizer、LLMService | 新建（`engine2.optimize`） |

**不涉及**：旧引擎（ai-engine/ai-backtest/ai-extension）的修改，新旧引擎通过 Strangler Fig 模式共存。

### 1.3 术语

| 术语 | 术语定义 |
| :------------: | :------------ |
| 内存模型 | 引擎运行时使用的领域对象（MemoryPosition / EntryRecord / ActionRecord），不回测循环外不落库 |
| 持久化实体 | 系统中已有的 MyBatis-Plus 实体（TradeOrder / TradeOrderItem / TradeOrderClose / TradeOrderCloseItem） |
| PersistenceGateway | 持久化门面接口，隔离引擎与数据库，引擎只操作内存模型，Gateway 内部转换为持久化实体 |
| CostModel | 成本模型，计算手续费、资金费率等交易成本，支持多交易所多市场 |
| SignalType | 交易指令（LONG / SHORT / CLOSE_LONG / CLOSE_SHORT / HOLD） |
| TradingContext | 交易执行上下文，策略只读查询接口 |
| TA4J | 技术指标计算库（0.22.6），本系统仅用于指标计算 |
| QuantDinger | 参考的 Python 量化交易系统架构 |
| Optimizer | 参数优化器，Grid/Random/DE/TPE/LLM 等算法实现 |

### 2.3 关键业务时序图

#### 回测流程时序图
User → BacktestFacade: 发起回测请求
│
BacktestFacade → BacktestEngine: run(request)
│
BacktestEngine → DataLoader: loadData(symbol, dateRange)
DataLoader --> BacktestEngine: BarSeries (纯内存，无DB)
│
BacktestEngine → TradingContext: new Context(initCash, costModel)
BacktestEngine → StrategyRegistry: getStrategy(strategyId)
StrategyRegistry --> BacktestEngine: ScriptStrategy
BacktestEngine → ScriptStrategy: init(params)
│
│ ┌─── Loop: i=0 to N (逐Bar) ─────────────────────┐
│ │ │

public void markClosed(ExitType exitType, BigDecimal pnl) {
    if (exitType == null || exitType == ExitType.UNKNOWN) {
        this.status = pnl.compareTo(BigDecimal.ZERO) >= 0 ? "GAIN" : "LOSS";
    } else if (exitType == ExitType.TAKE_PROFIT) {
        this.status = "GAIN";
    } else if (exitType == ExitType.STOP_LOSS) {
        this.status = "LOSS";
    } else {
        this.status = pnl.compareTo(BigDecimal.ZERO) >= 0 ? "GAIN" : "LOSS";
    }
}

            .build();
}
重要原则：快照必须在 reduceQuantity() 之前生成，此时 entries 还是完整的。之后 reduceQuantity() 修改当前持仓，最后将 totalPnl 和 status 同步到快照。

成本模型（Cost Model）
设计背景
多交易所多市场环境下，手续费计算规则差异巨大：

维度	说明
交易所	OKX、币安、Bybit、IBKR、SSE 等费率各不相同
市场类型	永续合约、现货、美股、A股费率结构完全不同
订单类型	Maker（挂单）vs Taker（吃单）费率不同
计费方式	百分比、每股固定费用、每手固定费用、点差、复合计费
需要设计 可插拔、可配置、可扩展 的成本模型。

设计原则
原则	说明
适配自有模型	使用 MemoryPosition / EntryRecord / ClosedEntryDetail
可插拔	不同市场使用不同的成本计算实现
类型统一	使用 BigDecimal（与现有代码一致）
TA4J 思想借鉴	采用 CostModel 接口设计，可插拔可组合
滑点独立处理	滑点影响成交价，由 applySlippage() 独立处理

package com.chain.ai.trade.engine2.core.cost;

import com.chain.ai.trade.common.entity.dto.ContractSpec;
import com.chain.ai.trade.engine2.backtest.model.MemoryPosition;

import java.math.BigDecimal;

/**
 * 成本模型 — 计算交易过程中的所有成本。
 * <p>
 * 借鉴 TA4J CostModel 的设计思想，适配自有内存模型。
 * <p>
 * 成本包括但不限于：
 * <ul>
 *   <li>手续费（开仓/平仓）</li>
 *   <li>资金费率（持仓费）</li>
 *   <li>印花税、过户费（A股）</li>
 * </ul>
 * <p>
 * 注意：滑点成本不在此接口中，因为滑点是影响成交价的因素，
 * 而非显性成本，由 {@code BacktestContext.applySlippage()} 独立处理。
 */
public interface CostModel {

    /**
     * 计算开仓成本（手续费/税费等）
     *
     * @param price         成交价格
     * @param quantity      成交数量（张/股/手）
     * @param contractSpec  合约规格（面值/乘数）
     * @return 开仓成本金额（计价币种）
     */
    BigDecimal calcOpenCost(BigDecimal price, BigDecimal quantity, ContractSpec contractSpec);

    /**
     * 计算平仓成本（手续费/税费等）
     *
     * @param price         成交价格
     * @param quantity      成交数量（张/股/手）
     * @param contractSpec  合约规格（面值/乘数）
     * @return 平仓成本金额（计价币种）
     */
    BigDecimal calcCloseCost(BigDecimal price, BigDecimal quantity, ContractSpec contractSpec);

    /**
     * 计算持仓成本（资金费率等）
     *
     * @param position      内存持仓
     * @param currentPrice  当前市场价格
     * @param contractSpec  合约规格（面值/乘数）
     * @return 持仓成本金额（计价币种）
     */
    default BigDecimal calcHoldingCost(MemoryPosition position, BigDecimal currentPrice, ContractSpec contractSpec) {
        return BigDecimal.ZERO;
    }

    /**
     * 获取成本描述（用于日志）
     */
    String getDescription();
}

CompositeCostModel（复合成本）：

java
/**
 * 复合成本模型 — 支持 A 股等多费率叠加场景
 * <p>
 * 典型 A 股卖出成本：佣金 0.03% + 印花税 0.1% + 过户费 1元/笔
 */
public class CompositeCostModel implements CostModel {
    private final List<CostComponent> openComponents;
    private final List<CostComponent> closeComponents;

    public CompositeCostModel(List<CostComponent> openComponents, List<CostComponent> closeComponents) {
        this.openComponents = openComponents;
        this.closeComponents = closeComponents;
    }

    @Override
    public BigDecimal calcOpenCost(BigDecimal price, BigDecimal quantity, ContractSpec contractSpec) {
        return calcTotal(openComponents, price, quantity, contractSpec);
    }

    @Override
    public BigDecimal calcCloseCost(BigDecimal price, BigDecimal quantity, ContractSpec contractSpec) {
        return calcTotal(closeComponents, price, quantity, contractSpec);
    }

    private BigDecimal calcTotal(List<CostComponent> components, BigDecimal price,
                                  BigDecimal quantity, ContractSpec contractSpec) {
        BigDecimal total = BigDecimal.ZERO;
        for (CostComponent comp : components) {
            total = total.add(comp.calculate(price, quantity, contractSpec));
        }
        return total;
    }

    @Override
    public String getDescription() {
        return "COMPOSITE(open=" + openComponents.size() + " comps, close=" + closeComponents.size() + " comps)";
    }

    /**
     * 成本组件接口
     */
    public interface CostComponent {
        BigDecimal calculate(BigDecimal price, BigDecimal quantity, ContractSpec contractSpec);
    }

    /** 百分比组件 */
    public static class PercentageComponent implements CostComponent {
        private final BigDecimal rate;
        public PercentageComponent(BigDecimal rate) { this.rate = rate; }
        @Override
        public BigDecimal calculate(BigDecimal price, BigDecimal quantity, ContractSpec contractSpec) {
            return price.multiply(quantity).multiply(contractSpec.getContractSize())
                    .multiply(contractSpec.getContractMult()).multiply(rate);
        }
    }

    /** 固定费用组件 */
    public static class FixedComponent implements CostComponent {
        private final BigDecimal fixedAmount;
        public FixedComponent(BigDecimal fixedAmount) { this.fixedAmount = fixedAmount; }
        @Override
        public BigDecimal calculate(BigDecimal price, BigDecimal quantity, ContractSpec contractSpec) {
            return fixedAmount;
        }
    }
}

加减仓功能设计 (Scale-In / Scale-Out)
加减仓是量化交易中重要的资金管理手段。当前 MemoryPosition 已具备模型基础。

核心思路：信号驱动 + 引擎执行

操作	触发方式	引擎执行
加仓（Scale-In）	策略返回 LONG / SHORT 方向信号（方向与当前持仓一致）	增加 longPosition / shortPosition 的数量，新增 EntryRecord 明细，扣减可用资金
减仓（Scale-Out）	策略返回 ExitSignal 且携带 closePercent（部分平仓比例）	按比例减少持仓，计算部分平仓盈亏，记录 ActionRecord
全平（Close All）	策略返回 ExitSignal，无 closePercent 或 closePercent=100	当前已有逻辑

@FunctionalInterface
public interface ScaleInRule {
    ScaleInSignal shouldScaleIn(int index, Bar bar, BarSeries series, TradingContext context);

    default ScaleInRule and(ScaleInRule other) {
        return (i, b, s, c) -> {
            ScaleInSignal a = shouldScaleIn(i, b, s, c);
            if (a == null) return null;
            ScaleInSignal bSignal = other.shouldScaleIn(i, b, s, c);
            if (bSignal == null) return null;
            return merge(a, bSignal);
        };
    }
    default ScaleInRule or(ScaleInRule other) {
        return (i, b, s, c) -> {
            ScaleInSignal a = shouldScaleIn(i, b, s, c);
            return a != null ? a : other.shouldScaleIn(i, b, s, c);
        };
    }
    default ScaleInRule negate() {
        return (i, b, s, c) -> shouldScaleIn(i, b, s, c) == null
                ? new ScaleInSignal(null, null) : null;
    }
}

@Slf4j
public class SignalScriptStrategy implements ScriptStrategy {
    private final MultiDirectionEntryRule entryRule;
    private final TradingRule exitRule;
    private final ScaleInRule scaleInRule;

    @Override
    public SignalType shouldEntry(int index, Bar bar, TradingContext context) {
        Trade.TradeType direction = entryRule.getDirection(index, null);
        if (direction == null) return null;
        SignalType signalType = convertToSignalType(direction.name());
        if (signalType == SignalType.LONG && context.hasLongPosition()) return null;
        if (signalType == SignalType.SHORT && context.hasShortPosition()) return null;
        return signalType;
    }

    @Override
    public ExitSignal shouldExit(int index, Bar bar, TradingContext context) {
        if (exitRule == null) return null;
        return exitRule.evaluate(index, bar, series, context);
    }

    @Override
    public ScaleInSignal shouldScaleIn(int index, Bar bar, BarSeries series, TradingContext context) {
        if (scaleInRule != null) {
            return scaleInRule.shouldScaleIn(index, bar, series, context);
        }
        // 回退：信号驱动加仓
        Trade.TradeType direction = entryRule.getDirection(index, null);
        if (direction == null) return null;
        if (direction == Trade.TradeType.BUY && context.hasLongPosition()) {
            return new ScaleInSignal(SignalType.LONG, ScaleInReason.SIGNAL);
        }
        if (direction == Trade.TradeType.SELL && context.hasShortPosition()) {
            return new ScaleInSignal(SignalType.SHORT, ScaleInReason.SIGNAL);
        }
        return null;
    }

    private static SignalType convertToSignalType(String sigType) {
        if ("LONG".equalsIgnoreCase(sigType) || "BUY".equalsIgnoreCase(sigType)) return SignalType.LONG;
        if ("SHORT".equalsIgnoreCase(sigType) || "SELL".equalsIgnoreCase(sigType)) return SignalType.SHORT;
        return null;
    }
}

java
@Component
@Profile("backtest")
public class BacktestEngine extends AbstractEngine {
    @Autowired private BacktestConfig config;

    @Override
    protected void executeLoop(BarSeries series, TradingContext context, ScriptStrategy strategy) {
        int totalBars = series.getBarCount();
        int warmup = strategy.getWarmupPeriod();

        for (int i = warmup; i < totalBars; i++) {
            Bar bar = series.getBar(i);
            BigDecimal openPrice = BigDecimal.valueOf(bar.getOpenPrice().doubleValue());
            BigDecimal closePrice = BigDecimal.valueOf(bar.getClosePrice().doubleValue());

            boolean exitedThisBar = false;
            boolean enteredThisBar = false;

            // Step 1: 逐笔止盈/止损
            if (context.hasPosition()) {
                boolean hit = context.closeEntriesByTpSl(i, closePrice);
                if (hit && !context.hasPosition()) {
                    exitedThisBar = true;
                }
            }

            // Step 2: 出场检查（支持 closePercent 部分减仓）
            if (context.hasPosition()) {
                ExitSignal exitSignal;
                while ((exitSignal = strategy.shouldExit(i, bar, context)) != null) {
                    BigDecimal exitPrice = exitSignal.getPrice() != null ? exitSignal.getPrice() : openPrice;
                    context.closePosition(i, exitPrice, exitSignal.getDirection(),
                            exitSignal.getExitType(), exitSignal.getClosePercent());
                    if (!context.hasPosition()) {
                        exitedThisBar = true;
                        break;
                    }
                }
            }

            // Step 3: 入场检查
            if (exitedThisBar || !context.hasLongPosition() || !context.hasShortPosition()) {
                SignalType entrySignal = strategy.shouldEntry(i, bar, context);
                if (entrySignal == SignalType.LONG && !context.hasLongPosition()) {
                    BigDecimal contractCount = calcContractCount(openPrice);
                    context.openPosition(i, SignalType.LONG, openPrice, contractCount,
                            null, null, bar.getBeginTime());
                    enteredThisBar = true;
                } else if (entrySignal == SignalType.SHORT && !context.hasShortPosition()) {
                    BigDecimal contractCount = calcContractCount(openPrice);
                    context.openPosition(i, SignalType.SHORT, openPrice, contractCount,
                            null, null, bar.getBeginTime());
                    enteredThisBar = true;
                }
            }

            // Step 4: 加仓检查
            if (context.hasPosition() && !enteredThisBar) {
                ScaleInSignal scaleIn = strategy.shouldScaleIn(i, bar, series, context);
                if (scaleIn != null) {
                    SignalType direction = scaleIn.getDirection();
                    if ((direction == SignalType.LONG && context.hasLongPosition())
                            || (direction == SignalType.SHORT && context.hasShortPosition())) {
                        BigDecimal addPrice = scaleIn.getPrice() != null ? scaleIn.getPrice() : openPrice;
                        BigDecimal addQty = calcContractCount(addPrice);
                        addQty = applyPositionControl(addQty, addPrice, direction);
                        if (addQty.compareTo(BigDecimal.ZERO) > 0) {
                            context.addToPosition(i, direction, addPrice, addQty,
                                    scaleIn.getTakeProfitPrice(), scaleIn.getStopLossPrice(),
                                    bar.getBeginTime());
                        }
                    }
                }
            }

            // Step 5: 采样权益曲线
            context.sampleEquity(i, closePrice);
        }

        // Step 6: 强制平仓
        afterRun();
    }

    private BigDecimal calcContractCount(BigDecimal price) {
        return config.getPositionAmount()
                .multiply(BigDecimal.valueOf(config.getLeverage()))
                .divide(price.multiply(config.getContractSize()), 0, RoundingMode.DOWN);
    }

    private BigDecimal applyPositionControl(BigDecimal addQty, BigDecimal price, SignalType side) {
        // 最大持仓量限制
        // 可用资金限制
        return addQty;
    }
}

BacktestBatchGateway（v1.13 使用 closedPositions 快照落库）：

java
@Component
@Profile("backtest")
public class BacktestBatchGateway implements PersistenceGateway {
    private final TradeOrderMapper tradeOrderMapper;
    private final TradeOrderItemMapper tradeOrderItemMapper;
    private final TradeOrderCloseMapper tradeOrderCloseMapper;
    private final TradeOrderCloseItemMapper tradeOrderCloseItemMapper;
    private final BacktestTaskService backtestTaskService;

    @Override
    public void openBatch() {
        // 无需额外操作
    }

    @Override
    @Transactional
    public void flush(String taskId, String symbol, BacktestResult result, BarSeries series) {
        List<MemoryPosition> closedPositions = result.getClosedPositions();
        if (closedPositions == null || closedPositions.isEmpty()) {
            log.warn("flush 跳过：closedPositions 为空, taskId={}", taskId);
            return;
        }

        BacktestTask task = backtestTaskService.getById(taskId);
        if (task == null) return;

        String robotId = task.getRobotId() != null ? task.getRobotId() : "2001";
        String memberId = task.getMemberId() != null ? task.getMemberId() : "1665908516499693568";
        Long accountId = task.getAccountId() != null ? task.getAccountId() : 1768185450252304387L;
        Integer leverage = task.getLeverage() != null ? task.getLeverage() : 1;

        log.info("开始回测落库: taskId={}, symbol={}, closedPositionCount={}",
                taskId, symbol, closedPositions.size());

        for (MemoryPosition snapshot : closedPositions) {
            try {
                // 1. 创建 TradeOrder（仓位主表）
                TradeOrder order = buildTradeOrderFromSnapshot(snapshot, memberId, accountId, robotId, leverage);
                tradeOrderMapper.insert(order);

                // 2. 创建 TradeOrderClose（平仓批次汇总）
                TradeOrderClose close = buildTradeOrderCloseFromSnapshot(snapshot);
                tradeOrderCloseMapper.insert(close);

                // 3. 遍历 entries 生成 TradeOrderItem 和 TradeOrderCloseItem
                for (EntryRecord entry : snapshot.getEntries()) {
                    // 3.1 入场明细
                    TradeOrderItem item = buildTradeOrderItem(order.getOrderSn(), entry);
                    tradeOrderItemMapper.insert(item);

                    // 3.2 平仓明细（每个 ClosedEntryDetail 对应一条）
                    for (ClosedEntryDetail detail : entry.getClosedDetails()) {
                        TradeOrderCloseItem closeItem = buildTradeOrderCloseItem(
                                close.getOrderSn(),
                                order.getOrderSn(),
                                entry.getEntryId(),
                                detail
                        );
                        tradeOrderCloseItemMapper.insert(closeItem);
                    }
                }
            } catch (Exception e) {
                log.error("保存仓位失败: positionId={}, error={}", snapshot.getPositionId(), e.getMessage(), e);
                throw new RuntimeException("保存回测仓位失败: " + e.getMessage(), e);
            }
        }

        // 4. 保存绩效指标（backtest_result）
        saveResultMetrics(taskId, result);
    }

    private TradeOrder buildTradeOrderFromSnapshot(MemoryPosition snapshot,
                                                   String memberId, Long accountId,
                                                   String robotId, Integer leverage) {
        TradeOrder order = new TradeOrder();
        order.setOrderSn(snapshot.getPositionId());
        order.setSymbol(snapshot.getSymbol());
        order.setOrderSideEnum(snapshot.getDirection() == SignalType.LONG ? OrderSideEnum.BUY : OrderSideEnum.SELL);
        order.setBuyPrice(snapshot.getAvgPrice());
        order.setVolume(snapshot.getTotalEntryQuantity());
        order.setIncome(snapshot.getTotalPnl());
        order.setCharge(snapshot.getOpenFee());
        order.setLeverRate(leverage);
        order.setTradeOrderStatus(TradeOrder.TradeOrderStatus.valueOf(snapshot.getStatus()));
        order.setMemberId(memberId);
        order.setAccountId(accountId.toString());
        order.setRobotId(robotId);
        order.setGainPrice(snapshot.getTakeProfitPrice());
        order.setLossPrice(snapshot.getStopLossPrice());

        if (snapshot.getEntryTime() != null) {
            Date entryDate = Date.from(snapshot.getEntryTime().atZone(ZoneId.systemDefault()).toInstant());
            order.setOrderTime(entryDate);
            order.setBuyTime(entryDate);
        }
        order.setCreateTime(new Date());
        order.setUpdateTime(new Date());
        return order;
    }

    private TradeOrderClose buildTradeOrderCloseFromSnapshot(MemoryPosition snapshot) {
        TradeOrderClose close = new TradeOrderClose();
        close.setOrderSn(UUID.randomUUID().toString());
        close.setPositionId(snapshot.getPositionId());
        close.setClosedVolume(snapshot.getTotalQuantity());
        close.setSellPrice(snapshot.getExitPrice());
        close.setIncome(snapshot.getTotalPnl());
        if (snapshot.getExitTime() != null) {
            close.setSellTime(Date.from(snapshot.getExitTime().atZone(ZoneId.systemDefault()).toInstant()));
        } else {
            close.setSellTime(new Date());
        }
        close.setCloseMethod(snapshot.getExitType() != null ? snapshot.getExitType().name() : "AUTO");
        close.setStatus("DEAL");
        return close;
    }

    private TradeOrderItem buildTradeOrderItem(String orderSn, EntryRecord record) {
        OrderSideEnum orderSide = "LONG".equals(record.getSide()) ? OrderSideEnum.BUY : OrderSideEnum.SELL;

        TradeOrderItem item = new TradeOrderItem();
        item.setOrderItemSn(record.getEntryId());
        item.setOrderSn(orderSn);
        item.setSymbol(record.getSymbol());
        item.setOrderSideEnum(orderSide);
        item.setBuyPrice(record.getPrice());
        item.setVolume(record.getInitialQuantity());
        item.setCharge(record.getFee());
        item.setTradeOrderItemStatus(TradeOrder.TradeOrderStatus.DEAL);
        item.setGainPrice(record.getTakeProfitPrice());
        item.setLossPrice(record.getStopLossPrice());
        if (record.getTime() != null) {
            item.setOrderTime(Date.from(record.getTime().atZone(ZoneId.systemDefault()).toInstant()));
        }
        item.setCreateTime(new Date());
        item.setUpdateTime(new Date());
        return item;
    }

    private TradeOrderCloseItem buildTradeOrderCloseItem(String batchId, String positionId,
                                                         String entryId, ClosedEntryDetail detail) {
        TradeOrderCloseItem item = new TradeOrderCloseItem();
        item.setBatchId(batchId);
        item.setEntrySn(entryId);
        item.setPositionId(positionId);
        item.setClosedVolume(detail.getQuantity());
        item.setExitPrice(detail.getExitPrice());
        item.setIncome(detail.getPnl());
        item.setExitTime(new Date());
        item.setCloseMethod(detail.getCloseReason() != null ? detail.getCloseReason() : "AUTO");
        return item;
    }

    private void saveResultMetrics(String taskId, BacktestResult result) {
        BigDecimal initialCapital = result.getEquityCurve() != null && !result.getEquityCurve().isEmpty()
                ? result.getEquityCurve().get(0).getEquity()
                : BigDecimal.ZERO;

        BacktestResultDTO dto = BacktestResultDTO.builder()
                .taskId(taskId)
                .totalReturn(calcTotalReturn(result.getFinalEquity(), initialCapital))
                .maxDrawdown(result.getMaxDrawdown())
                .winRate(BigDecimal.valueOf(result.getWinRate()))
                .totalTrades(result.getTotalTrades())
                .winningTrades(result.getProfitableTrades())
                .profitFactor(BigDecimal.valueOf(result.getProfitLossRatio()))
                .finalValue(result.getFinalEquity())
                .sharpeRatio(BigDecimal.valueOf(result.getSharpeRatio()))
                .calmarRatio(calcCalmarRatio(result))
                .totalCost(result.getTotalCommission())
                .annualReturn(BigDecimal.valueOf(result.getAnnualReturn()))
                .volatility(BigDecimal.valueOf(result.getVolatility()))
                .sortinoRatio(BigDecimal.valueOf(result.getSortinoRatio()))
                .averageWin(BigDecimal.valueOf(result.getAverageWin()))
                .averageLoss(BigDecimal.valueOf(result.getAverageLoss()))
                .largestWinTrade(BigDecimal.valueOf(result.getLargestWinTrade()))
                .largestLossTrade(BigDecimal.valueOf(result.getLargestLossTrade()))
                .equityCurve(serializeEquityCurve(result))
                .calculatedAt(LocalDateTime.now())
                .build();

        backtestTaskService.saveBacktestResult(dto);
    }

    private BigDecimal calcTotalReturn(BigDecimal finalEquity, BigDecimal initialCapital) {
        if (initialCapital.compareTo(BigDecimal.ZERO) <= 0) return BigDecimal.ZERO;
        return finalEquity.subtract(initialCapital)
                .divide(initialCapital, 6, RoundingMode.HALF_UP);
    }

    private BigDecimal calcCalmarRatio(BacktestResult result) {
        double maxDd = result.getMaxDrawdown().doubleValue();
        double annualRet = result.getAnnualReturn();
        if (maxDd <= 0 || Double.isNaN(maxDd) || Double.isInfinite(maxDd)) return BigDecimal.ZERO;
        return BigDecimal.valueOf(annualRet / maxDd);
    }

    private String serializeEquityCurve(BacktestResult result) {
        List<BacktestResult.EquityPoint> curve = result.getEquityCurve();
        if (curve == null || curve.isEmpty()) return "[]";
        StringBuilder sb = new StringBuilder("[");
        for (int i = 0; i < curve.size(); i++) {
            if (i > 0) sb.append(",");
            sb.append("{\"barIndex\":").append(curve.get(i).getIndex())
                    .append(",\"equity\":").append(curve.get(i).getEquity())
                    .append("}");
        }
        sb.append("]");
        return sb.toString();
    }
}

BacktestEngine 主循环流程（含加减仓）
java
@Override
protected void executeLoop() {
    int totalBars = series.getBarCount();
    int warmup = config.getWarmupPeriod();

    for (int i = warmup; i < totalBars; i++) {
        Bar bar = series.getBar(i);
        BigDecimal openPrice = BigDecimal.valueOf(bar.getOpenPrice().doubleValue());
        BigDecimal closePrice = BigDecimal.valueOf(bar.getClosePrice().doubleValue());

        boolean exitedThisBar = false;
        boolean enteredThisBar = false;

        // ═══ Step 1: 逐笔止盈/止损 ═══
        if (context.hasPosition()) {
            boolean hit = context.closeEntriesByTpSl(i, closePrice);
            if (hit && !context.hasPosition()) {
                exitedThisBar = true;
            }
        }

        // ═══ Step 2: 出场检查（支持 closePercent 部分减仓） ═══
        if (context.hasPosition()) {
            ExitSignal exitSignal;
            while ((exitSignal = strategy.shouldExit(i, bar, context)) != null) {
                BigDecimal exitPrice = exitSignal.getPrice() != null ? exitSignal.getPrice() : openPrice;
                context.closePosition(i, exitPrice, exitSignal.getDirection(),
                        exitSignal.getExitType(), exitSignal.getClosePercent());
                if (!context.hasPosition()) {
                    exitedThisBar = true;
                    break;
                }
            }
        }

        // ═══ Step 3: 入场检查 ═══
        if (exitedThisBar || !context.hasLongPosition() || !context.hasShortPosition()) {
            SignalType entrySignal = strategy.shouldEntry(i, bar, context);
            if (entrySignal == SignalType.LONG && !context.hasLongPosition()) {
                BigDecimal contractCount = calcContractCount(openPrice);
                context.openPosition(i, SignalType.LONG, openPrice, contractCount,
                        null, null, bar.getBeginTime());
                enteredThisBar = true;
            } else if (entrySignal == SignalType.SHORT && !context.hasShortPosition()) {
                BigDecimal contractCount = calcContractCount(openPrice);
                context.openPosition(i, SignalType.SHORT, openPrice, contractCount,
                        null, null, bar.getBeginTime());
                enteredThisBar = true;
            }
        }

        // ═══ Step 4: 加仓检查 ═══
        if (context.hasPosition() && !enteredThisBar) {
            ScaleInSignal scaleIn = strategy.shouldScaleIn(i, bar, series, context);
            if (scaleIn != null) {
                SignalType direction = scaleIn.getDirection();
                if ((direction == SignalType.LONG && context.hasLongPosition())
                        || (direction == SignalType.SHORT && context.hasShortPosition())) {
                    BigDecimal addPrice = scaleIn.getPrice() != null ? scaleIn.getPrice() : openPrice;
                    BigDecimal addQty = calcContractCount(addPrice);
                    addQty = applyPositionControl(addQty, addPrice, direction);
                    if (addQty.compareTo(BigDecimal.ZERO) > 0) {
                        context.addToPosition(i, direction, addPrice, addQty,
                                scaleIn.getTakeProfitPrice(), scaleIn.getStopLossPrice(),
                                bar.getBeginTime());
                    }
                }
            }
        }

        // ═══ Step 5: 采样权益曲线 ═══
        context.sampleEquity(i, closePrice);
    }

    // Step 6: 强制平仓
    afterRun();
}
核心规则：

出场优先：每根 Bar 先检查出场信号（支持部分减仓），再检查入场/加仓

入场无条件执行：移除 exitedThisBar 守卫，开仓条件由策略内部判断

加仓独立判断：shouldScaleIn() 在持仓状态下返回 ADD_LONG/ADD_SHORT

加仓风控：引擎执行 canAddPosition() 前置检查（最大持仓量、可用资金、加仓次数）

双向持仓：longPosition / shortPosition 独立管理，互不干扰

强制平仓：循环结束后用最后收盘价平掉剩余持仓

4.3.8 杠杆、滑点与初始资金设计
4.3.8.1 设计背景与原则
V2 回测引擎的回测参数基于机器人配置驱动，与实盘机器人的 DefaultDealStrategyTrade 逻辑保持一致。关键的资金概念有两个：

回测配置项	对应机器人配置	说明
initialCapital	TradingBot.currentCapital	初始总资产（USDT）
positionAmount	TradingStrategyParams.amount	分配资金（USDT）
leverage	TradingStrategyParams.leverage	杠杆倍数
slippage	TradingStrategyParams.slippage	滑点百分比
核心设计原则：

基于机器人配置：回测使用与机器人一致的参数，确保回测结果可复现

信号级覆盖：杠杆支持由 TechnicalSignal.extraParams 中的 leverage 字段覆盖

滑点单向偏移：开仓价/平仓价百分比偏移，买入上浮（更贵），卖出下浮（更便宜）

强平检查设计阶段规划，回测阶段暂不实现

涨跌幅百分比类指标需去杠杆化，避免杠杆放大指标阈值导致失真

BacktestConfig buildConfig(BacktestRequest request) {
    // 1. 查机器人配置
    TradingBot bot = tradingBotService.getById(request.getRobotId());
    TradingStrategyParams params = tradingStrategyService.getParams(bot.getStrategyId());

    // 2. 初始总资产
    BigDecimal initialCapital = firstOf(
        request.getInitialCapital(),
        bot != null ? bot.getCurrentCapital() : null,
        BigDecimal.valueOf(10000)
    );

    // 3. 分配资金
    BigDecimal positionAmount = firstOf(
        request.getPositionAmount(),
        params != null ? params.getAmount() : null,
        BigDecimal.valueOf(1000)
    );

    // 4. 杠杆
    int leverage = firstOf(
        request.getLeverage(),
        params != null ? params.getLeverage() : null,
        1
    );

    // 5. 滑点
    double slippage = firstOf(request.getSlippage(), 0.0);

    // 6. 合约面值从品种配置获取
    double contractSize = contractSpecUtils.getContractSize(symbol);

    return BacktestConfig.builder()
        .initialCapital(initialCapital)
        .positionAmount(positionAmount)
        .leverage(leverage)
        .slippage(slippage)
        .contractSize(contractSize)
        .warmupPeriod(50)
        .build();
}

说明：contractSize 不由机器人配置，而是从 ContractSpec 品种规格表查询获取，在 BacktestService 构建 BacktestConfig 时查询注入。

4.3.8.3 初始资金（Initial Capital）
初始资金分为两个独立概念，对应机器人的两个资金字段：

概念	配置字段	对应机器人字段	作用
初始总资产	initialCapital	TradingBot.currentCapital	回测开始时分配给机器人的总资金（USDT），作为权益曲线和绩效指标的基准
分配资金（基础仓位资金）	positionAmount	TradingStrategyParams.amount	每笔开仓时用于计算合约张数的金额（USDT），决定开仓头寸大小
为什么需要两个资金：

text
总资产 = currentCapital（累计充值+盈利，随交易变化）
分配资金 = amount（固定值，每笔开仓都按此金额计算头寸）

例如：机器人总资产 50000 USDT，但每笔开仓只投入 1000 USDT（分配资金）
→ 开仓合约张数 = (1000 × 杠杆) / (价格 × 合约面值)
→ 最大可用开仓次数 = 50000 / 1000 = 50 次（不考虑浮动盈亏）
使用规则：

操作	initialCapital（总资产）	positionAmount（分配资金）
初始化	context.availableBalance = initialCapital	—
开仓合约张数计算	—	contractCount = positionAmount × leverage / (price × contractSize)
扣减保证金	availableBalance -= requiredMargin	—
平仓释放保证金+盈亏	availableBalance += realizedPnl + returnMargin	—
绩效指标基准	totalReturn = (finalEquity - initialCapital) / initialCapital	—
资金单位：USDT（保证金货币）。回测引擎以 USDT 为唯一计价单位，所有资金操作（开仓保证金、盈亏、权益）均以 USDT 计量。

4.3.8.4 杠杆（Leverage）
数据来源与覆盖优先级：

text
第1优先级：TechnicalSignal.extraParams 中的 leverage（信号级覆盖）
第2优先级：BacktestConfig.leverage（机器人配置级）
逻辑参考 DefaultDealStrategyTrade.calculateOrderAmount() 和 TradingUtil.convertUsdtToContractSize()：

java
// 1. 信号中指定了 leverage，优先使用
BigDecimal signalLeverage = extractLeverageFromSignal(technicalSignal);
if (signalLeverage != null) {
    leverage = signalLeverage.doubleValue();
}

// 2. 计算头寸（合约张数）
//    公式：合约张数 = (USDT金额 × 杠杆) / (当前价格 × 合约面值)
double contractQuantity = (usdtAmount * leverage) / (currentPrice * contractSize);
头寸计算流程：

text
USDT金额 (positionAmount，分配资金)
    → × leverage → 名义本金(USDT)
    → ÷ currentPrice → 等值基础币数量 (如 2.0 BTC)
    → ÷ contractSize → 合约张数 (如 0.001 BTC/张，则 2.0 / 0.001 = 2000 张)
回测引擎中的杠杆作用：

维度	作用方式	计算公式
名义本金	放大	nominalCapital = positionAmount × leverage（USDT）
合约张数	转换	contractCount = positionAmount × leverage / (entryPrice × contractSize)（张）
已实现盈亏	放大	pnl = (exitPrice - entryPrice) × contractCount × contractSize × direction（USDT）
未实现盈亏	放大	unrealizedPnl = (currentPrice - avgOpenPrice) × contractCount × contractSize × direction（USDT）
杠杆仅在开仓时生效，持仓期间不改变。盈亏放大是头寸数量放大带来的自然结果。

去杠杆化规则（涨跌幅百分比类指标）：

所有基于价格的百分比指标（如 ATR%、波动率%、通道宽度% 等）在计算时需除以杠杆倍数，避免杠杆错误放大阈值：

java
// 原始 ATR% = ATR / closePrice × 100
// 去杠杆化后：
double deLevAtrPct = atrPct / leverage;
说明：绝对数值指标（如 SMA、EMA）天然不受杠杆影响，无需去杠杆化。

4.3.8.5 滑点（Slippage）
模式：开仓价/平仓价百分比偏移（与 QuantDinger 一致）。

计算公式：

方向	开仓执行价	平仓执行价
多头（LONG）	basePrice × (1 + slippage) 买入更贵	basePrice × (1 - slippage) 卖出更少
空头（SHORT）	basePrice × (1 - slippage) 卖出更便宜	basePrice × (1 + slippage) 买入更贵
滑点应用于 BacktestExecutionHandler：

java
public BigDecimal applySlippage(BigDecimal basePrice, OrderSideEnum direction,
                                boolean isEntry, double slippage) {
    return switch (direction) {
        case BUY  -> isEntry
                ? basePrice.multiply(BigDecimal.ONE.add(BigDecimal.valueOf(slippage)))
                : basePrice.multiply(BigDecimal.ONE.subtract(BigDecimal.valueOf(slippage)));
        case SELL -> isEntry
                ? basePrice.multiply(BigDecimal.ONE.subtract(BigDecimal.valueOf(slippage)))
                : basePrice.multiply(BigDecimal.ONE.add(BigDecimal.valueOf(slippage)));
    };
}
成交价确定流程：

text
成交模型确定 basePrice（Close/HL/NextOpen）
        ↓
applySlippage(basePrice, direction, isEntry, slippage)
        ↓
最终执行价 execPrice
        ↓
BacktestExecutionHandler 使用 execPrice 计算盈亏
滑点默认值：由 BacktestConfig.slippage 配置（如 0.001 = 0.1%），可在回测请求参数中设置，默认 0（无滑点）。

4.3.8.7 综合示例
场景：机器人总资产 initialCapital = 50000 USDT，每笔开仓分配资金 positionAmount = 1000 USDT，杠杆 5 倍，滑点 0.05%（0.0005），多头开仓信号。交易品种：BTC-USDT-SWAP（合约面值 contractSize = 0.001 BTC/张）。

text
Step 1: 开仓 - 分配资金 → 合约张数
  basePrice = 50000 (开盘价)
  execPrice = 50000 × (1 + 0.0005) = 50025 ← 滑点上浮

  // 公式：合约张数 = (分配资金 × 杠杆) / (价格 × 合约面值)
  contractCount = (1000 × 5) / (50025 × 0.001)
                = 5000 / 50.025
                ≈ 99 张

  // 验证：每张 0.001 BTC，共 99 张
  //       名义本金 = 99 × 0.001 × 50025 ≈ 4952.5 USDT
  //       保证金 = 4952.5 / 5 ≈ 990.5 USDT（≈ 1000，合理）
  //       剩余可用资金 = 50000 - 990.5 ≈ 49009.5 USDT

Step 2: 持仓期间指标计算
  ATR% = 2.5% → 去杠杆化后 ATR% = 2.5% / 5 = 0.5%

Step 3: 平仓 - 合约张数 → USDT 盈亏
  basePrice = 51000 (开盘价)
  execPrice = 51000 × (1 - 0.0005) = 50974.5 ← 滑点下浮

  // 盈亏 = (平仓价 - 开仓价) × 张数 × 合约面值
  pnl = (50974.5 - 50025) × 99 × 0.001
      = 949.5 × 0.099
      ≈ 94.0 USDT

  // 平仓后 totalEquity = 50000 + 94.0 = 50094 USDT
  // 总资产收益率 = 94.0 / 50000 × 100% ≈ 0.188%
  // （未加杠杆 benchmark = (51000 - 50000) / 50000 × 100% = 2.0%，
  //  按分配资金计算的收益率为 94.0 / 1000 × 100% ≈ 9.4% ≈ 2.0% × 5 - 滑点损耗）

4.4 统一 K 线数据获取与多周期(MTF)提供模块
4.4.1 模块需求说明
设计原则：对外统一，对内适配。调用方只关心"给我数据"，不关心数据从哪来、是单周期还是多周期、是回测还是实盘。

核心设计约束：

交易所是必传参数：K 线数据必须绑定交易所，同一交易对在不同交易所的数据完全独立。所有查询接口的最前两个参数固定为 Exchange exchange, String symbol

回测/实盘切换透明：策略和规则不感知数据来源，通过引擎初始化时注入不同的 Provider 实现自动切换

保留业务层接口：ICandlestickService 作为业务层接口保留，服务于订单/持仓/风控等模块，不被 TA4J 技术细节污染

需求列表：

统一数据入口：消除当前 ~30 处散落的 candlestickService.getLastKlines() + IndicatorWrapHelper.buildSeries() 调用，全部收敛到 KlineDataService 一个入口

统一单周期/多周期访问：调用方通过 KlineDataService 获取数据，不区分单周期还是多周期

回测模式：从主周期 BarSeries 通过聚合派生高周期数据，不依赖外部数据库

实盘模式：按需从 DB 加载各周期数据，支持懒加载 + 缓存

策略按需声明跨周期需求：无跨周期需求的策略不受影响

交易所隔离：所有数据查询必须携带交易所参数，缓存 Key 包含交易所维度

ResampleMultiTimeFrameProvider（统一实现，支持聚合/直查两种模式，由调用方决定）：

java
/**
 * 多周期 K 线提供者，支持聚合/直查两种模式，由调用方决定。
 *
 * 聚合模式（默认）   ：基于主周期 BarSeries 通过 aggregateBars 聚合生成其他周期。
 * 直查模式           ：支持两种查询方式：
 *     1. 时间范围（startTime + endTime）
 *     2. 结束时间+条数（endTime + barCount）
 */
public class ResampleMultiTimeFrameProvider implements MultiTimeFrameProvider {

    private final BarSeries mainSeries;
    private final CandlestickIntervalEnum mainInterval;
    private final boolean resample;

    // 直查模式共用
    private final ICandlestickService candlestickService;
    private final Exchange exchange;
    private final String symbol;

    // 直查模式-时间范围
    private final long startTime;
    private final long endTime;

    // 直查模式-结束时间+条数
    private final boolean tailCountMode;
    private final int barCount;

    private final Map<CandlestickIntervalEnum, BarSeries> cache = new ConcurrentHashMap<>();

    /** 聚合模式构造 */
    public ResampleMultiTimeFrameProvider(BarSeries mainSeries, CandlestickIntervalEnum mainInterval) {
        this(mainSeries, mainInterval, null, null, null, 0, 0);
    }

    /** 直查模式构造-时间范围 */
    public ResampleMultiTimeFrameProvider(BarSeries mainSeries, CandlestickIntervalEnum mainInterval,
                                          ICandlestickService candlestickService, Exchange exchange,
                                          String symbol, long startTime, long endTime) {
        // ... 完整实现
    }

    /** 直查模式构造-结束时间+条数 */
    public ResampleMultiTimeFrameProvider(BarSeries mainSeries, CandlestickIntervalEnum mainInterval,
                                          ICandlestickService candlestickService, Exchange exchange,
                                          String symbol, long endTime, int barCount) {
        // ... 完整实现
    }

    @Override
    public BarSeries getSeries(CandlestickIntervalEnum interval) {
        if (interval.getMinNum().equals(mainInterval.getMinNum())) {
            return mainSeries;
        }
        return cache.computeIfAbsent(interval, this::load);
    }

    private BarSeries load(CandlestickIntervalEnum target) {
        if (resample) {
            // 聚合模式
            Duration d = Duration.ofMinutes(target.getMinNum());
            return BarSeriesUtils.aggregateBars(mainSeries, d, target.getCode());
        } else if (tailCountMode) {
            // 直查-结束时间+条数
            KlineParam param = KlineParam.builder()
                    .exchange(exchange).symbol(symbol)
                    .klineInterval(target)
                    .endTime(endTime).size(barCount)
                    .build();
            return IndicatorWrapHelper.buildSeries(candlestickService.getKlines(param));
        } else {
            // 直查-时间范围
            KlineParam param = KlineParam.builder()
                    .exchange(exchange).symbol(symbol)
                    .klineInterval(target)
                    .startTime(startTime).endTime(endTime)
                    .build();
            return IndicatorWrapHelper.buildSeries(candlestickService.getKlines(param));
        }
    }
}
4.4.4.4 ResampleEngine（聚合规则工具）
java
public class ResampleEngine {

    /** 计算合并倍数（如 15m → 1H = 60/15 = 4） */
    public static int mergeFactor(CandlestickIntervalEnum main,
                                   CandlestickIntervalEnum target) {
        return target.getMinNum() / main.getMinNum();
    }

    /** 执行聚合，利用 ta4j BarSeriesUtils.aggregateBars() */
    public static BarSeries resample(BarSeries source,
                                      CandlestickIntervalEnum sourceInterval,
                                      CandlestickIntervalEnum targetInterval) {
        Duration targetDuration = Duration.ofMinutes(targetInterval.getMinNum());
        return BarSeriesUtils.aggregateBars(
                source, targetDuration, targetInterval.getCode());
    }
}

4.5 模拟/实盘引擎模块设计文档

4.5.1 模块需求说明

需求列表：

- 模拟引擎（PaperEngine）与实盘引擎（LiveEngine）共享同一套 AbstractEngine 模板和 ScriptStrategy 接口
- 两者唯一的差异在于订单执行层：Paper 模拟成交，Live 走交易所真实下单
- 事件驱动模式：K 线到达 → 阻塞队列唤醒 → processBar() 决策 → ExecutionHandler 执行
- 支持从数据库恢复已有持仓（重启容灾），启动时加载未平仓 MemoryPosition
- 订单生命周期管理：SUBMITTED → PENDING → FILLED/REJECTED → CLOSE
- 挂单轮询（PendingOrderWorker）：Paper 检查价格触及 → 模拟成交；Live 调用交易所 API → 更新成交
- 风控前置：下单前经 RiskCheckHandler 检查，超过阈值拒绝执行
- @Profile 隔离：@Profile("paper") / @Profile("live") 严格隔离，防止误操作
- 持久化方式：@Async 实时逐笔写入（区别于回测的批量 flush）

4.5.4.4 PaperExecutionHandler（模拟撮合）

java
@Component
@Profile("paper")
public class PaperExecutionHandler implements ExecutionHandler {

    /** 模拟订单簿：Key = clientOrderId, Value = OrderIntent */
    private final ConcurrentHashMap<String, OrderIntent> pendingOrders = new ConcurrentHashMap<>();

    /** 模拟成交回调监听 */
    private final List<Consumer<FillResult>> fillListeners = new CopyOnWriteArrayList<>();

    @Override
    public OrderIntentResult submitOrder(OrderIntent intent, RealtimeContext context) {
        // 1. 市价单 → 立即模拟成交（以当前K线开盘价 + 滑点成交）
        if (intent.getOrderType() == OrderType.MARKET) {
            BigDecimal fillPrice = applySlippage(intent.getSymbol(), intent.getPrice());
            FillResult fill = FillResult.builder()
                    .clientOrderId(intent.getClientOrderId())
                    .filled(true)
                    .fillPrice(fillPrice)
                    .filledQuantity(intent.getQuantity())
                    .fillTime(intent.getSubmitTime())
                    .build();
            // 通知 PositionBook 更新持仓
            notifyFilled(fill);
            return OrderIntentResult.success(intent.getClientOrderId(), fillPrice);
        }

        // 2. 限价单 → 挂单到订单簿
        pendingOrders.put(intent.getClientOrderId(), intent);
        return OrderIntentResult.pending(intent.getClientOrderId());
    }

    @Override
    public FillResult checkFill(String clientOrderId) {
        // Paper 模式不主动轮询，由 PendingOrderWorker 在 onBar 时触发
        // 检查当前价格是否触及挂单价 → 模拟成交
        OrderIntent intent = pendingOrders.get(clientOrderId);
        if (intent == null) return null;
        // 实际成交检查逻辑在 processBar 中通过 currentPrice 比较实现
        return null;
    }

    /**
     * 每根 K 线到达时调用：检查挂单是否触及限价
     */
    public List<FillResult> processFills(BigDecimal currentHigh, BigDecimal currentLow, BigDecimal currentPrice) {
        List<FillResult> fills = new ArrayList<>();
        Iterator<Map.Entry<String, OrderIntent>> it = pendingOrders.entrySet().iterator();
        while (it.hasNext()) {
            Map.Entry<String, OrderIntent> entry = it.next();
            OrderIntent intent = entry.getValue();
            boolean reached = isLongBuy(intent)
                    ? currentLow.compareTo(intent.getPrice()) <= 0
                    : currentHigh.compareTo(intent.getPrice()) >= 0;
            if (reached) {
                it.remove();
                FillResult fill = FillResult.builder()
                        .clientOrderId(intent.getClientOrderId())
                        .filled(true)
                        .fillPrice(intent.getPrice())
                        .filledQuantity(intent.getQuantity())
                        .fillTime(LocalDateTime.now())
                        .build();
                fills.add(fill);
                notifyFilled(fill);
            }
        }
        return fills;
    }

    private boolean isLongBuy(OrderIntent intent) {
        return intent.getSide() == SignalType.LONG;
    }
}

4.5.4.5 LiveExecutionHandler（交易所下单）

java
@Component
@Profile("live")
public class LiveExecutionHandler implements ExecutionHandler {

    @Autowired private TradeOrderServiceAdapter tradeOrderAdapter;
    @Autowired private RiskCheckHandler riskCheckHandler;

    @Override
    public OrderIntentResult submitOrder(OrderIntent intent, RealtimeContext context) {
        // 1. 风控前置检查
        RiskResult riskResult = riskCheckHandler.checkBeforeAction(intent, context);
        if (riskResult.isRejected()) {
            log.warn("风控拒绝开仓: clientOrderId={}, reason={}", intent.getClientOrderId(), riskResult.getReason());
            return OrderIntentResult.rejected(intent.getClientOrderId(), riskResult.getReason());
        }

        // 2. 调用 TradeOrderServiceAdapter 创建订单（内部 → TradeOrderServiceImpl → OkxDirectTradeService）
        TradeOrderDto orderDto = TradeOrderDto.builder()
                .symbol(intent.getSymbol())
                .orderSide(intent.getSide())
                .orderType(intent.getOrderType())
                .price(intent.getPrice())
                .volume(intent.getQuantity())
                .leverage(intent.getLeverage())
                .gainPrice(intent.getTakeProfitPrice())
                .lossPrice(intent.getStopLossPrice())
                .clientOrderId(intent.getClientOrderId())
                .positionId(intent.getPositionId())
                .build();

        TradeOrderDto result = tradeOrderAdapter.createOrder(orderDto);

        // 3. 市价单通常立即成交，限价单挂单等待
        if (result.isFilled()) {
            return OrderIntentResult.filled(intent.getClientOrderId(), result.getFillPrice(), result.getFilledVolume());
        }
        return OrderIntentResult.pending(intent.getClientOrderId());
    }

    @Override
    public FillResult checkFill(String clientOrderId) {
        // 调用交易所查单接口
        TradeOrderDto orderDto = tradeOrderAdapter.getOrderByOrderSn(clientOrderId);
        if (orderDto == null) return null;
        if ("DEAL".equals(orderDto.getStatus()) || "FILLED".equals(orderDto.getStatus())) {
            return FillResult.builder()
                    .clientOrderId(clientOrderId)
                    .filled(true)
                    .fillPrice(orderDto.getFillPrice())
                    .filledQuantity(orderDto.getFilledVolume())
                    .fillTime(orderDto.getUpdateTime())
                    .build();
        }
        if ("REJECTED".equals(orderDto.getStatus()) || "CANCELED".equals(orderDto.getStatus())) {
            return FillResult.builder()
                    .clientOrderId(clientOrderId)
                    .filled(false)
                    .rejected(true)
                    .rejectReason(orderDto.getStatus())
                    .build();
        }
        return null; // 仍在 PENDING
    }
}

4.5.4.6 RealtimeContext（事件驱动上下文）

RealtimeContext 实现 TradingContext 接口，与 BacktestContext 的核心区别：
- 持仓管理：内存 MemoryPosition + 数据库 TradeOrder 双写同步
- 订单执行：委托给 ExecutionHandler（不自己做内存撮合）
- 启动恢复：beforeRun() 时从 DB 加载未平仓 TradeOrder → 重建 MemoryPosition

java
@Component
@Scope("prototype")
public class RealtimeContext implements TradingContext {

    private final String symbol;
    private final BigDecimal initialCapital;
    private final ExecutionHandler executionHandler;
    private final RealtimeGateway gateway;
    private final ContractSpec contractSpec;
    private final CostModel costModel;
    private final int leverage;

    /** 内存持仓（与 DB 保持同步） */
    private MemoryPosition longPosition;
    private MemoryPosition shortPosition;

    /** 可用余额 */
    private BigDecimal availableBalance;
    private BigDecimal realizedPnl = BigDecimal.ZERO;
    private BigDecimal totalCommissionPaid = BigDecimal.ZERO;

    /** 权益曲线采样 */
    private final List<BacktestResult.EquityPoint> equityCurve = new ArrayList<>();

    /** 已平仓快照 */
    private final List<MemoryPosition> closedPositions = new ArrayList<>();

    /** 持仓恢复标志 */
    private boolean positionRecovered = false;

    /**
     * 从 DB 恢复已有持仓（beforeRun 时调用）
     */
    public void recoverFromOrders(List<TradeOrder> openOrders) {
        for (TradeOrder order : openOrders) {
            MemoryPosition pos = MemoryPosition.fromTradeOrder(order);
            if (order.getOrderSideEnum() == OrderSideEnum.BUY) {
                longPosition = pos;
            } else {
                shortPosition = pos;
            }
            // 同步开仓明细
            List<TradeOrderItem> items = tradeOrderAdapter.getOrderItems(order.getOrderSn());
            for (TradeOrderItem item : items) {
                EntryRecord entry = EntryRecord.fromTradeOrderItem(item, order.getOrderSn());
                pos.addEntry(entry);
            }
        }
        positionRecovered = true;
        log.info("持仓恢复完成: symbol={}, longQty={}, shortQty={}", symbol,
                longPosition != null ? longPosition.getTotalQuantity() : 0,
                shortPosition != null ? shortPosition.getTotalQuantity() : 0);
    }

    /**
     * 开仓：生成 OrderIntent → 提交 ExecutionHandler → 等待成交回调
     */
    public OrderIntentResult openPosition(SignalType side, BigDecimal price, BigDecimal quantity,
                                           BigDecimal takeProfitPrice, BigDecimal stopLossPrice,
                                           LocalDateTime barTime) {
        OrderIntent intent = OrderIntent.builder()
                .clientOrderId(generateClientOrderId())
                .symbol(symbol)
                .side(side)
                .orderType(OrderType.MARKET)  // 默认市价单，可扩展
                .price(price)
                .quantity(quantity)
                .leverage(leverage)
                .takeProfitPrice(takeProfitPrice)
                .stopLossPrice(stopLossPrice)
                .barTime(barTime)
                .build();

        OrderIntentResult result = executionHandler.submitOrder(intent, this);

        if (result.isFilled()) {
            // 立即成交 → 创建内存持仓
            createMemoryPosition(intent, result.getFillPrice(), result.getFilledQuantity());
            // 异步持久化
            gateway.onOrderSubmitted(intent);
            gateway.onOrderFilled(intent, result);
        } else if (result.isPending()) {
            // 挂单 → 只记录，等 PendingOrderWorker 回调
            gateway.onOrderSubmitted(intent);
        }

        return result;
    }

    /**
     * 平仓：生成 OrderIntent → 提交 ExecutionHandler
     */
    public CloseOrderResult closePosition(ExitSignal signal, LocalDateTime barTime) {
        MemoryPosition pos = signal.getDirection() == SignalType.CLOSE_LONG ? longPosition : shortPosition;
        if (pos == null) return CloseOrderResult.noPosition();

        BigDecimal closeQty = signal.getClosePercent() != null && signal.getClosePercent() < 100
                ? pos.getTotalQuantity().multiply(BigDecimal.valueOf(signal.getClosePercent() / 100.0))
                : pos.getTotalQuantity();

        OrderIntent intent = OrderIntent.builder()
                .clientOrderId(generateClientOrderId())
                .symbol(symbol)
                .side(signal.getDirection())
                .orderType(OrderType.MARKET)
                .quantity(closeQty)
                .positionId(pos.getPositionId())
                .barTime(barTime)
                .build();

        return executionHandler.closeOrder(intent, signal.getExitType(), this);
    }

    /**
     * 成交回调（由 PendingOrderWorker 触发）
     */
    public void onOrderFilled(OrderIntent intent, FillResult fill) {
        if (intent.getPositionId() != null) {
            // 平仓成交
            handleCloseFill(intent, fill);
        } else {
            // 开仓成交
            createMemoryPosition(intent, fill.getFillPrice(), fill.getFilledQuantity());
        }
        gateway.onOrderFilled(intent, fill);
        sampleEquity(fill.getFillPrice(), fill.getFillTime());
    }

    /**
     * 挂单被拒绝或被取消
     */
    public void onOrderRejected(OrderIntent intent, String reason) {
        log.warn("订单被拒绝/取消: clientOrderId={}, reason={}", intent.getClientOrderId(), reason);
        // 释放冻结资金（如果有）
    }

    // === TradingContext 接口实现（同 BacktestContext） ===
    @Override public boolean hasPosition() { return hasLongPosition() || hasShortPosition(); }
    @Override public boolean hasLongPosition() { return longPosition != null && longPosition.getTotalQuantity().signum() > 0; }
    @Override public boolean hasShortPosition() { return shortPosition != null && shortPosition.getTotalQuantity().signum() > 0; }
    // ... 其余 getter 省略，与 BacktestContext 一致
}

4.5.4.8 引擎层设计

PaperEngine 与 LiveEngine 的区别仅在于注入的 ExecutionHandler 不同，引擎代码完全一致：

java
/**
 * 模拟/实盘引擎 — 事件驱动，继承 AbstractEngine。
 * <p>
 * K 线到达时通过 onBar(bar) 推入阻塞队列，executeLoop() 阻塞等待。
 */
public abstract class RealtimeEngine extends AbstractEngine {

    protected final BlockingQueue<Bar> barQueue = new LinkedBlockingQueue<>();
    protected volatile boolean running = true;

    /**
     * K 线到达回调（由 KLineRealTimeUpdateTask 调用）
     */
    public void onBar(Bar bar) {
        barQueue.offer(bar);
    }

    /**
     * 事件驱动主循环 — 阻塞等待 barQueue，替代 BacktestEngine 的 for 循环。
     */
    @Override
    protected void executeLoop() {
        while (running) {
            try {
                Bar bar = barQueue.poll(30, TimeUnit.SECONDS);
                if (bar == null) continue;

                processBar(bar);

            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                break;
            } catch (Exception e) {
                log.error("processBar 异常", e);
            }
        }
    }

    /**
     * 单根 K 线处理 — 逻辑与 BacktestEngine.executeLoop 单次迭代一致。
     */
    protected void processBar(Bar bar) {
        // 与 BacktestEngine 完全一致的 5 步流程：
        // Step 1: 逐笔止盈/止损检查
        // Step 2: 出场规则检查（while 循环直到无exitSignal）
        // Step 3: 入场检查（shouldEntry → openPosition）
        // Step 4: 加仓检查（shouldScaleIn → addToPosition）
        // Step 5: 权益曲线采样
        // — 差异仅在于 openPosition/closePosition 走 RealtimeContext.executionHandler
    }

    /**
     * 停止引擎（不强制平仓）
     */
    public void stop() {
        running = false;
        barQueue.offer(new Bar(ZonedDateTime.now(), 0, 0, 0, 0, 0)); // 唤醒阻塞
    }
}

6. 性能
性能指标需求
指标	回测模式要求	实盘模式要求
延迟	不适用（离线计算）	K线级别延迟 < 500ms（含交易所下单）
QPS	回测循环速度 > 100,000 bars/s	不适用（事件驱动）
TPS	批量写入吞吐 > 1,000 条/s	单笔写入延迟 < 200ms（@Async）
性能保障措施
循环内零 I/O：回测主循环绝对禁止任何数据库或网络 I/O，所有操作纯内存

批量持久化：回测结果在 afterRun() 中一次性批量写入（insertBatch），而非逐条插入

内存 buffer 暂存：BacktestBatchGateway 使用 ArrayList 暂存开平仓记录，避免频繁 GC

@Async 异步写入：实盘模式使用 @Async("tradeExecutor") 线程池异步落库，不阻塞主循环

避免对象拷贝：回测循环中 MemoryPosition 原地修改，不创建不必要的中间对象

成本计算轻量化：CostModel 实现无状态，可复用，不产生额外对象开销

并行评估：优化实验室使用 ForkJoinPool 并行执行回测，充分利用多核 CPU

package com.chain.ai.trade.engine2.core.cost;

import com.chain.ai.trade.common.entity.dto.ContractSpec;

import java.math.BigDecimal;
import java.util.List;

/**
 * 复合成本模型 — 支持 A 股等多费率叠加场景
 * <p>
 * 典型 A 股卖出成本：佣金 0.03% + 印花税 0.1% + 过户费 1元/笔
 */
public class CompositeCostModel implements CostModel {
    private final List<CostComponent> openComponents;
    private final List<CostComponent> closeComponents;

    public CompositeCostModel(List<CostComponent> openComponents, List<CostComponent> closeComponents) {
        this.openComponents = openComponents;
        this.closeComponents = closeComponents;
    }

    @Override
    public BigDecimal calcOpenCost(BigDecimal price, BigDecimal quantity, ContractSpec contractSpec) {
        return calcTotal(openComponents, price, quantity, contractSpec);
    }

    @Override
    public BigDecimal calcCloseCost(BigDecimal price, BigDecimal quantity, ContractSpec contractSpec) {
        return calcTotal(closeComponents, price, quantity, contractSpec);
    }

    private BigDecimal calcTotal(List<CostComponent> components, BigDecimal price,
                                  BigDecimal quantity, ContractSpec contractSpec) {
        BigDecimal total = BigDecimal.ZERO;
        for (CostComponent comp : components) {
            total = total.add(comp.calculate(price, quantity, contractSpec));
        }
        return total;
    }

    @Override
    public String getDescription() {
        return "COMPOSITE(open=" + openComponents.size() + " comps, close=" + closeComponents.size() + " comps)";
    }

    public interface CostComponent {
        BigDecimal calculate(BigDecimal price, BigDecimal quantity, ContractSpec contractSpec);
    }

    public static class PercentageComponent implements CostComponent {
        private final BigDecimal rate;
        public PercentageComponent(BigDecimal rate) { this.rate = rate; }
        @Override
        public BigDecimal calculate(BigDecimal price, BigDecimal quantity, ContractSpec contractSpec) {
            return price.multiply(quantity).multiply(contractSpec.getContractSize())
                    .multiply(contractSpec.getContractMult()).multiply(rate);
        }
    }

    public static class FixedComponent implements CostComponent {
        private final BigDecimal fixedAmount;
        public FixedComponent(BigDecimal fixedAmount) { this.fixedAmount = fixedAmount; }
        @Override
        public BigDecimal calculate(BigDecimal price, BigDecimal quantity, ContractSpec contractSpec) {
            return fixedAmount;
        }
    }
}

@Component
public class OptimizeFacade {
    private final BacktestEngineV2 backtestEngine;
    private final ParameterOptimizer optimizer;
    private final ObjectiveScorer scorer;
    private final LLMService llmService;
    private final OptimizationExperimentRepo repo;

    public OptimizationRound tuneRound(TuneRequest request) {
        // 1. 基准回测
        BacktestReport baseline = backtestEngine.run(request.toBacktestRequest());
        // 2. LLM 分析
        List<ParameterSuggestion> suggestions = llmService.analyze(
            request.getParamDefs(), baseline, request.getStrategyCode());
        // 3. 应用建议，生成新参数
        Map<String, Object> newParams = applySuggestions(request.getCurrentParams(), suggestions);
        // 4. 再回测
        BacktestReport newReport = backtestEngine.run(request.toBacktestRequest().withParams(newParams));
        // 5. 对比打分
        ComparisonReport comparison = ComparisonReport.between(baseline, newReport);
        // 6. 持久化
        return repo.saveRound(request.getExperimentId(), newParams, newReport, suggestions, comparison);
    }

    public OptimizationExperiment runExperiment(ExperimentRequest request) {
        // 1. 基准回测
        BacktestReport baseline = backtestEngine.run(request.toBacktestRequest());
        // 2. 生成候选参数
        List<ParamCandidate> candidates = optimizer.suggestCandidates(
            request.getParamDefs(), request.getCandidateCount(), request.getObjective());
        // 3. 并行回测所有候选
        List<ScoredCandidate> results = parallelEvaluate(candidates, request);
        // 4. 排序取 TopN
        List<ScoredCandidate> topResults = results.stream()
            .sorted(Comparator.comparing(ScoredCandidate::getScore).reversed())
            .limit(request.getTopN()).toList();
        // 5. 持久化
        return repo.save(request.getExperimentId(), baseline, topResults);
    }

    private List<ScoredCandidate> parallelEvaluate(List<ParamCandidate> candidates, ExperimentRequest request) {
        return ForkJoinPool.commonPool().submit(() ->
            candidates.parallelStream().map(candidate -> {
                BacktestReport report = backtestEngine.run(request.toBacktestRequest().withParams(candidate.getParams()));
                double score = scorer.score(report, request.getObjective());
                return new ScoredCandidate(candidate, report, score);
            }).collect(Collectors.toList())
        ).join();
    }
}
