# 执行清单

> 基于 `V2-自研交易引擎系统设计文档.md` 目标架构，**原地重构**（不新建 ai-engine2 模块，不存两套引擎）

**核心原则**：
1. 每步必须可独立编译 → 测试 → 验证 → 更新状态，不做大范围一次性改动
2. **蚂蚁搬家**：先提取内部类（Phase 1）→ 提取方法到独立类（Phase 2~3）→ 新建概念类并逐步植入（Phase 4~5）→ 替换核心逻辑（Phase 6~7）
3. 每步完成后执行 `mvn compile -DskipTests`，编译通过后才做下一步
4. 不改 ta4j 源码，不改 XChange 代码，不改第三方库
