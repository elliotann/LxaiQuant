## Phase 2：后端接口改造

> 目标：`getRobotOrderReport` 接口返回 `equityCurve` 字段。

### 2.1 实体/VO 层

- [ ] **2.1.1 新增 `EquityCurvePoint` VO 类**
  - 字段：`date` (String)、`equity` (BigDecimal)、`drawdown` (BigDecimal)、`actualDate` (String, 月粒度用)

- [ ] **2.1.2 修改 `RobotOrderReportVO`**
  - 新增 `List<EquityCurvePoint> equityCurve` 字段

### 2.2 Mapper 层

- [ ] **2.2.1 `BacktestEquityCurveMapper` 新增查询方法**
  - `selectByRobotIdAndTimeRange(robotId, startTime, endTime)` → `List<BacktestEquityCurve>`
  - SQL 条件：`robot_id = #{robotId} AND task_id IS NULL AND time BETWEEN ... ORDER BY time ASC`

- [ ] **2.2.2 若模块依赖解耦，Mapper 需迁移到共用模块（见 Phase 4.1）**

### 2.3 Service 层

- [ ] **2.3.1 `TradeOrderServiceImpl.getRobotOrderReport()` 改造**
  - 注入 `BacktestEquityCurveMapper`
  - 查询权益曲线：`mapper.selectByRobotIdAndTimeRange(robotId, startTime, endTime)`
  - 回撤计算（后端统一算，返回正数表示回撤幅度）

- [ ] **2.3.2 回撤计算方法实现**

```java
BigDecimal peak = null;
for (EquityCurvePoint point : equityCurve) {
    if (point.getEquity() == null) continue;
    if (peak == null || point.getEquity().compareTo(peak) > 0) peak = point.getEquity();
    if (peak != null && peak.compareTo(BigDecimal.ZERO) > 0) {
        BigDecimal drawdown = peak.subtract(point.getEquity())
                .divide(peak, 6, RoundingMode.HALF_UP)
                .multiply(new BigDecimal("100"));
        point.setDrawdown(drawdown);
    } else {
        point.setDrawdown(BigDecimal.ZERO);
    }
}
```

- [ ] **2.3.3 月粒度聚合逻辑**
  - 月维度：取该月最后一个有权益记录的日子
  - 返回 `actualDate` 字段标识实际取值日期

- [ ] **2.3.4 缺失日期填充实现**
  - 按天填充：无数据的日期 equity 取前值，drawdown 置 null
  - 按月填充：无数据的月份跳过（月粒度间隔大，缺失正常）

- [ ] **2.3.5 权益数据不存在时返回空列表（不报错）**

### 2.4 单元测试

- [ ] **2.4.1 回撤计算测试**
  - 连续上涨 → drawdown = 0
  - 先涨后跌 → drawdown > 0，且等于 (peak - current) / peak × 100

- [ ] **2.4.2 月聚合测试**
  - 同月内多个采样点 → 取最后一个

- [ ] **2.4.3 缺失填充测试**
  - 不连续日期 → 正确填充前值

- [ ] **2.4.4 权益数据为空测试**
  - 空数据场景 → equityCurve 返回空 List，不抛异常
