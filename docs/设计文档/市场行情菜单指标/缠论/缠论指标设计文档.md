2. 核心概念精确定义（按计算层级排列）
   2.1 K线与包含关系处理
   原始K线数据结构：包含时间戳、开盘价（O）、最高价（H）、最低价（L）、收盘价（C）、成交量（V）。

包含关系判定：两根K线存在包含，当且仅当其中一根的最高价 ≥ 另一根的最高价，且其最低价 ≤ 另一根的最低价。

包含关系处理规则：

方向判别：判断当前K线序列的总体方向（上升或下降）。比较前一根K线到当前K线的收盘价变化，若 close_current > close_prev 则为上升方向，反之为下降方向。

向上升方向：合并后新K线取两K线较高者的最高价和较低者的最低价，即 high = max(high1, high2)，low = max(low1, low2)（注意：上升方向取价格区间的并集，但缠论原文要求上升时取高点中较高者和低点中较高者，下降时取高点中较低者和低点中较低者。这里严格按标准定义：上升时 high = max(high1, high2)，low = max(low1, low2)；下降时 high = min(high1, high2)，low = min(low1, low2)）。

向下降方向：合并后新K线取两K线较低者的最高价和较低者的最低价，即 high = min(high1, high2)，low = min(low1, low2)。

顺序性原则：按时间顺序处理，先从第1、2根K线合并，得到的新K线与第3根比较并决定是否合并，依次类推。合并后的K线时间戳取较新的一根。

输出：标准化K线序列 StandardKLine，消除因停牌、除权除息、ST处理等事件造成的虚假价格缺口。

Java 表示：

```java
public class StandardKLine {
private LocalDateTime time;
private double open;
private double high;
private double low;
private double close;
private long volume;
private double atr;   // 可选，用于噪声过滤
}
```

包含关系处理算法伪代码：

```java
List<StandardKLine> processContainment(List<RawBar> rawBars) {
List<StandardKLine> result = new ArrayList<>();
StandardKLine prev = convert(rawBars.get(0));
result.add(prev);
for (int i = 1; i < rawBars.size(); i++) {
StandardKLine curr = convert(rawBars.get(i));
boolean isContained = (curr.high <= prev.high && curr.low >= prev.low) ||
(curr.high >= prev.high && curr.low <= prev.low);
if (!isContained) {
result.add(curr);
prev = curr;
} else {
// 合并
boolean isUp = curr.close > prev.close;
if (isUp) {
prev.high = Math.max(prev.high, curr.high);
prev.low = Math.max(prev.low, curr.low);
} else {
prev.high = Math.min(prev.high, curr.high);
prev.low = Math.min(prev.low, curr.low);
}
prev.close = curr.close;
prev.time = curr.time;
// 更新 result 中最后一个元素
result.set(result.size() - 1, prev);
}
}
return result;
}
```

2.2 分型（FenXing）
顶分型：连续三根标准化K线 S[i-1]、S[i]、S[i+1]，满足 S[i].high > S[i-1].high 且 S[i].high > S[i+1].high，同时 S[i].low > S[i-1].low 且 S[i].low > S[i+1].low（即中间K线最高价和最低价均为三者之最）。

底分型：连续三根标准化K线 S[i-1]、S[i]、S[i+1]，满足 S[i].low < S[i-1].low 且 S[i].low < S[i+1].low，同时 S[i].high < S[i-1].high 且 S[i].high < S[i+1].high（即中间K线最高价和最低价均为三者之最）。

分型有效性验证：

| 验证项 | 规则 | 失败处理 |
|--------|------|----------|
| 中间K线非包含 | 与左右K线无包含关系（在标准化序列中已保证） | 视为无效分型，跳过 |
| 价格极值 | 最高/最低严格大于/小于两侧 | 相等时无效 |
| 强度过滤 | 可选：价格差绝对值 > ATR × 阈值 | 弱分型可选标记但不参与后续构建 |

数据结构：

```java
public class FenXing {
private int index;          // 在标准化K线序列中的索引
private String type;        // "TOP" / "BOTTOM"
private double high;        // 顶分型最高价 / 底分型最高价
private double low;         // 顶分型最低价 / 底分型最低价
private double powerScore;  // 强度评分（价格差/ATR）
}
```

识别算法：在标准化K线序列上滑动窗口（窗口大小=3），对每个中间位置判断是否满足顶或底分型条件。

2.3 笔（Bi）
笔的定义：相邻的一个顶分型和一个底分型连接而成，代表一个最小价格波动单元。

笔的构成条件：

类型交替：必须是顶分型与底分型配对（上升笔 = 底分型 → 顶分型，下降笔 = 顶分型 → 底分型）

无共用K线：顶底分型之间必须至少有一根独立的非共用标准化K线（即二者不能共用K线）。根据"新笔"规则，这一条件可放宽：一顶一底即可构成最简单的一笔，但顶底不能互相包含。

价格方向：上升笔中顶分型的最高价必须高于底分型的最高价；下降笔中底分型的最低价必须低于顶分型的最低价。

最小K线数：新笔不要求顶底分型之间有独立K线，老笔要求至少间隔1根K线。

笔的动态延伸策略：

扫描分型序列，用窗口滑动方式配对相邻分型。

按"路径延伸"规则：当新分型出现时，若与当前扫描笔末端的分型类型相同且价格处于对当前方向更有利的位置（上升笔中遇到更高的顶分型，或下降笔中遇到更低的底分型），则用新分型取代该端，形成延伸。

否则，完成当前笔，以新分型为起点启动下一笔。

数据结构：

```java
public class Bi {
private FenXing start;
private FenXing end;
private String direction;   // "UP" / "DOWN"
private double high;
private double low;
private int klineCount;
}
```

识别算法：

```java
List<Bi> recognizeBi(List<FenXing> fenXings, boolean useNewBiRule, int minKlineBetween) {
List<Bi> bis = new ArrayList<>();
FenXing pendingStart = null;
for (int i = 0; i < fenXings.size() - 1; i++) {
FenXing fx = fenXings.get(i);
if (pendingStart == null) {
pendingStart = fx;
continue;
}
// 检查类型交替
if (pendingStart.type.equals(fx.type)) {
// 延伸：如果新分型更有利，则替换pendingStart
if ((pendingStart.type.equals("BOTTOM") && fx.low < pendingStart.low) ||
(pendingStart.type.equals("TOP") && fx.high > pendingStart.high)) {
pendingStart = fx;
}
continue;
}
// 检查成笔条件
boolean isValid = false;
if (useNewBiRule) {
// 新笔：只需价格方向正确
isValid = (pendingStart.type.equals("BOTTOM") && fx.high > pendingStart.high) ||
(pendingStart.type.equals("TOP") && fx.low < pendingStart.low);
} else {
// 老笔：需要间隔K线数 >= minKlineBetween
int gap = Math.abs(fx.index - pendingStart.index) - 1;
isValid = gap >= minKlineBetween &&
((pendingStart.type.equals("BOTTOM") && fx.high > pendingStart.high) ||
(pendingStart.type.equals("TOP") && fx.low < pendingStart.low));
}
if (isValid) {
Bi bi = new Bi();
bi.setStart(pendingStart);
bi.setEnd(fx);
bi.setDirection(pendingStart.type.equals("BOTTOM") ? "UP" : "DOWN");
bi.setHigh(Math.max(pendingStart.high, fx.high));
bi.setLow(Math.min(pendingStart.low, fx.low));
bi.setKlineCount(Math.abs(fx.index - pendingStart.index) + 1);
bis.add(bi);
pendingStart = fx;
} else {
// 不成笔，尝试将当前分型作为新的起点
pendingStart = fx;
}
}
return bis;
}
```

2.4 线段（Duan）
线段的定义：由至少三笔组成，前三笔必须具有价格重叠区域，代表更高层级的趋势波动。

线段构建规则：

最小笔数：至少由3笔组成，且必须是奇数笔。

前三笔重叠：前三笔的价格区间必须存在重叠区域（即三者高低点的交集不为空）。

方向确定：上升线段由上升笔开始且由上升笔结束；下降线段由下降笔开始且由下降笔结束。

特征序列法（标准画法）：通过笔的"特征序列"判断线段是否终结——将笔按奇偶位置提取，当出现连续的顶分型或底分型特征元素时，线段在该特征元素处分界。

算法实现要点：

对笔序列进行滑动窗口分析。

递归地判断前三笔重叠：overlapLow = max(bi1.low, bi2.low, bi3.low), overlapHigh = min(bi1.high, bi2.high, bi3.high), 有效性要求 overlapLow < overlapHigh。

采用多轮迭代：先构建粗线段，再做线段合并与方向确认。

数据结构：

```java
public class Duan {
private List<Bi> biList;
private int startBiIndex;
private int endBiIndex;
private String direction;   // "UP" / "DOWN"
private double high;
private double low;
private double atrAverage;   // 线段内ATR平均值（辅助背驰判断）
}
```

识别算法（简化版特征序列法）：

```java
List<Duan> recognizeDuan(List<Bi> bis) {
List<Duan> duans = new ArrayList<>();
if (bis.size() < 3) return duans;
int start = 0;
while (start + 2 < bis.size()) {
// 检查前三笔重叠
Bi b1 = bis.get(start), b2 = bis.get(start+1), b3 = bis.get(start+2);
double overlapLow = Math.max(Math.max(b1.low, b2.low), b3.low);
double overlapHigh = Math.min(Math.min(b1.high, b2.high), b3.high);
if (overlapLow < overlapHigh) {
// 确定线段方向：第一笔方向
String direction = b1.direction;
// 寻找线段结束点（特征序列分型）
int end = findSegmentEnd(bis, start, direction);
Duan duan = new Duan();
duan.setBiList(bis.subList(start, end+1));
duan.setStartBiIndex(start);
duan.setEndBiIndex(end);
duan.setDirection(direction);
duan.setHigh(calculateMaxHigh(bis, start, end));
duan.setLow(calculateMinLow(bis, start, end));
duans.add(duan);
start = end; // 线段连续，下一线段起点为当前结束点
} else {
start++;
}
}
return duans;
}
```

其中 findSegmentEnd 使用特征序列顶底分型判断。

2.5 中枢（ZhongShu）
中枢定义：由至少三个连续线段（标准中枢）的价格重叠区域构成，代表多空双方激烈博弈的平衡区域。

中枢分类：

| 类型 | 构成构件 | 使用场景 | 说明 |
|------|----------|----------|------|
| 笔中枢 | 由严格笔构成 | 快速判断、小级别分析 | 至少由三笔构成，随着笔数量增多，中枢区间逐渐收敛 |
| 标准中枢 | 由线段构成 | 正式分析、多级别递归 | 至少由三个线段构成，是中枢分析的正式构件 |

中枢识别步骤：

滑动窗口：在段序列（或笔序列）上滑动长度为3的窗口。

重叠判断：窗口内三段的价格区间必须存在公共交集：

zs_high = min(segment1.high, segment2.high, segment3.high)

zs_low = max(segment1.low, segment2.low, segment3.low)

有效性要求 zs_high > zs_low

区间扩展与合并：当新增段仍与当前中枢区间重叠时，扩展中枢；当出现无法纳入当前中枢的新段时，完成当前中枢，新段作为下一中枢的起始。

方向判定：根据构成中枢的三段中第一段与最后一段的方向关系判定。

ATR 噪声过滤：当高低点间的价格波动小于 ATR × 阈值 时，视为无效波动，不计入中枢。

数据结构（参考 ChanlunX 实现）：

```java
public class ZhongShu {
private String id;
private String type;                // "BI" / "DUAN"
private List<Integer> componentIndices;  // 构成段或笔的索引列表
private int startIndex;             // 在原始K线上的起始索引
private int endIndex;               // 在原始K线上的结束索引
private double high;                // 中枢高点
private double low;                 // 中枢低点
private int direction;              // 1上升 / -1下降 / 0未知
private String growthType;          // "EXTEND" / "NEW" / "EXPAND"
}
```

中枢的三种生长方式：

| 生长方式 | 判定条件 | 输出 |
|----------|----------|------|
| 延伸 | 新增段仍在中枢区间内震荡 | 扩展现有中枢区间 |
| 新生 | 突破原中枢区间形成新中枢 | 创建新中枢，原中枢完结 |
| 扩展 | 波动区间重叠但中枢本身未重叠 | 升级为更高级别中枢，合并两个中枢 |

识别算法（段中枢）：

```java
List<ZhongShu> recognizeZhongShu(List<Duan> duans, double atrThreshold) {
List<ZhongShu> zsList = new ArrayList<>();
if (duans.size() < 3) return zsList;
int i = 0;
while (i + 2 < duans.size()) {
Duan d1 = duans.get(i), d2 = duans.get(i+1), d3 = duans.get(i+2);
double high = Math.min(Math.min(d1.high, d2.high), d3.high);
double low = Math.max(Math.max(d1.low, d2.low), d3.low);
if (high > low) {
ZhongShu zs = new ZhongShu();
zs.setType("DUAN");
zs.setHigh(high);
zs.setLow(low);
zs.setStartIndex(d1.startBiIndex);
zs.setEndIndex(d3.endBiIndex);
List<Integer> comp = new ArrayList<>();
comp.add(i); comp.add(i+1); comp.add(i+2);
zs.setComponentIndices(comp);
// 扩张合并：继续向后检查是否有段与当前中枢重叠
int j = i + 3;
while (j < duans.size()) {
Duan dn = duans.get(j);
if (dn.low < zs.getHigh() && dn.high > zs.getLow()) {
// 重叠，扩展中枢区间
zs.setHigh(Math.min(zs.getHigh(), dn.high));
zs.setLow(Math.max(zs.getLow(), dn.low));
zs.getComponentIndices().add(j);
zs.setEndIndex(dn.endBiIndex);
j++;
} else {
break;
}
}
zsList.add(zs);
i = j; // 从下一个未处理的位置开始
} else {
i++;
}
}
return zsList;
}
```

2.6 背驰（BeiChi）
趋势背驰：比较的是围绕趋势最后一个中枢的前后两个次级别波动的力度。

盘整背驰：比较的是围绕任意一个中枢的前后两个次级别波动的力度，或者两段连续同向走势的力度。

背驰判断参数：

| 参数 | 方法 | 说明 |
|------|------|------|
| MACD 柱状面积 | 计算两段对应 MACD 的面积并比较 | 常用方案，需要集成 ta4j MACD 指标 |
| 价格-力度变化率 | Δprice / Δbars | 价格变化速度与同期耗时之比 |
| 斜率比较 | 上升下降笔斜率 | 斜率减低表示动能减弱 |

判断规则：价格创新高/新低，但力度指标未创新高/新低 → 背驰确认。

实现示例（MACD面积比较）：

```java
public boolean isTrendBeiChi(List<Bi> bis, ZhongShu lastZS, MACDIndicator macd) {
// 获取中枢前后两段（离开段）
Bi entryBi = bis.get(lastZS.getComponentIndices().get(0) - 1);
Bi exitBi = bis.get(lastZS.getComponentIndices().get(lastZS.getComponentIndices().size() - 1) + 1);
double area1 = calculateMACDArea(entryBi, macd);
double area2 = calculateMACDArea(exitBi, macd);
// 价格创新高/新低，但面积减小
if (exitBi.direction.equals("UP") && exitBi.high > entryBi.high && area2 < area1) {
return true;
}
if (exitBi.direction.equals("DOWN") && exitBi.low < entryBi.low && area2 < area1) {
return true;
}
return false;
}
```

2.7 三类买卖点
第一类买/卖点：由趋势背驰产生，终结原走势。第一类买点出现在下跌末端，即股价跌破最后一个下跌中枢后出现背驰信号时。

第二类买/卖点：出现在第一类买卖点之后，如果走势不创新低/新高，或创新低/新高后出现盘整背驰，皆构成第二类买卖点。

第二类买点可分为三种形态：

| 形态 | 位置 | 操作建议 |
|------|------|----------|
| 强势形态 | 位于前下跌中枢上方 | 首选介入，资金效率最高 |
| 中性形态 | 位于前下跌中枢区间内 | 谨慎介入，进一步观察 |
| 弱势形态 | 位于前下跌中枢下方 | 果断规避，下跌风险大 |

第三类买/卖点：出现在最近一个同级别中枢之上/之下，要求次级别离开后的次级别回抽回不到最近的同级别中枢中，意味着中枢新生或中枢级别扩展。第三类买点是上涨趋势延续中最经典的、最安全的机会。

数据结构：

```java
public class Signal {
private String id;                 // 信号唯一标识
private String type;               // "BUY" / "SELL"
private int level;                 // 1 / 2 / 3
private int barIndex;              // 触发K线索引
```

2.8 周期与级别

   3.3 多周期递归关系（扩展）
   为实现更符合缠论原意的级别递进，可引入递归计算：

向上递归：低周期（如 M3）的笔，按时间对齐合并为高周期（如 M15）的笔或线段。

规则：高周期的一笔必须由低周期至少三笔构成，且高低点由低周期笔的极值决定。

实现方式：为每个周期单独配置 basePeriod 字段，指明其数据来源是原始K线还是低周期笔。

初期实现可先独立计算各周期（即直接使用对应周期的K线数据），后续再升级为递归模式。

```java
package com.chain.ai.trade.extension.ta4j.indicator.chanlun.algorithm;

import com.chain.ai.trade.extension.ta4j.indicator.chanlun.model.*;
import java.util.ArrayList;
import java.util.List;

/** 包含关系处理 */
public class ContainmentProcessor {
    public static List<StdKLine> process(List<StdKLine> rawBars) {
        if (rawBars == null || rawBars.isEmpty()) return new ArrayList<>();
        List<StdKLine> result = new ArrayList<>();
        StdKLine prev = rawBars.get(0);
        result.add(prev);
        for (int i = 1; i < rawBars.size(); i++) {
            StdKLine curr = rawBars.get(i);
            boolean isContained = (curr.high <= prev.high && curr.low >= prev.low) ||
                                  (curr.high >= prev.high && curr.low <= prev.low);
            if (!isContained) {
                result.add(curr);
                prev = curr;
            } else {
                boolean isUp = curr.close > prev.close;
                if (isUp) {
                    prev.setHigh(Math.max(prev.high, curr.high));
                    prev.setLow(Math.max(prev.low, curr.low));
                } else {
                    prev.setHigh(Math.min(prev.high, curr.high));
                    prev.setLow(Math.min(prev.low, curr.low));
                }
                prev.setClose(curr.close);
                prev.setTime(curr.time);
            }
        }
        return result;
    }
}

/** 分型识别 */
public class FenXingRecognizer {
    public static List<FenXing> recognize(List<StdKLine> stdKlines, ChanLunConfig config) {
        List<FenXing> result = new ArrayList<>();
        if (stdKlines.size() < 3) return result;
        for (int i = 1; i < stdKlines.size() - 1; i++) {
            StdKLine prev = stdKlines.get(i - 1);
            StdKLine curr = stdKlines.get(i);
            StdKLine next = stdKlines.get(i + 1);
            if (curr.high > prev.high && curr.high > next.high &&
                curr.low > prev.low && curr.low > next.low) {
                FenXing fx = new FenXing();
                fx.setIndex(i);
                fx.setType("TOP");
                fx.setHigh(curr.high);
                fx.setLow(curr.low);
                fx.setPowerScore(calcPower(curr, stdKlines));
                result.add(fx);
            } else if (curr.low < prev.low && curr.low < next.low &&
                       curr.high < prev.high && curr.high < next.high) {
                FenXing fx = new FenXing();
                fx.setIndex(i);
                fx.setType("BOTTOM");
                fx.setHigh(curr.high);
                fx.setLow(curr.low);
                fx.setPowerScore(calcPower(curr, stdKlines));
                result.add(fx);
            }
        }
        return result;
    }

    private static double calcPower(StdKLine curr, List<StdKLine> klines) {
        double priceDiff = Math.abs(curr.high - curr.low);
        double atr = curr.getAtr();
        return atr > 0 ? priceDiff / atr : 0;
    }
}

/** 笔识别 */
public class BiRecognizer {
    public static List<Bi> recognize(List<FenXing> fenXings, ChanLunConfig config) {
        List<Bi> bis = new ArrayList<>();
        FenXing pendingStart = null;
        for (FenXing fx : fenXings) {
            if (pendingStart == null) {
                pendingStart = fx;
                continue;
            }
            if (pendingStart.type.equals(fx.type)) {
                if ((pendingStart.type.equals("BOTTOM") && fx.low < pendingStart.low) ||
                    (pendingStart.type.equals("TOP") && fx.high > pendingStart.high)) {
                    pendingStart = fx;
                }
                continue;
            }
            boolean isValid = config.isUseNewBiRule()
                ? (pendingStart.type.equals("BOTTOM") && fx.high > pendingStart.high) ||
                  (pendingStart.type.equals("TOP") && fx.low < pendingStart.low)
                : (Math.abs(fx.index - pendingStart.index) - 1 >= config.getMinKlineBetween()) &&
                  ((pendingStart.type.equals("BOTTOM") && fx.high > pendingStart.high) ||
                   (pendingStart.type.equals("TOP") && fx.low < pendingStart.low));
            if (isValid) {
                Bi bi = new Bi();
                bi.setStart(pendingStart);
                bi.setEnd(fx);
                bi.setDirection(pendingStart.type.equals("BOTTOM") ? "UP" : "DOWN");
                bi.setHigh(Math.max(pendingStart.high, fx.high));
                bi.setLow(Math.min(pendingStart.low, fx.low));
                bi.setKlineCount(Math.abs(fx.index - pendingStart.index) + 1);
                bis.add(bi);
            }
            pendingStart = fx;
        }
        return bis;
    }
}

/** 线段识别 */
public class DuanRecognizer {
    public static List<Duan> recognize(List<Bi> bis, ChanLunConfig config) {
        List<Duan> duans = new ArrayList<>();
        if (bis.size() < 3) return duans;
        int start = 0;
        while (start + 2 < bis.size()) {
            Bi b1 = bis.get(start), b2 = bis.get(start + 1), b3 = bis.get(start + 2);
            double overlapLow = Math.max(Math.max(b1.low, b2.low), b3.low);
            double overlapHigh = Math.min(Math.min(b1.high, b2.high), b3.high);
            if (overlapLow < overlapHigh) {
                String direction = b1.direction;
                int end = findSegmentEnd(bis, start, direction);
                Duan duan = new Duan();
                duan.setBiList(bis.subList(start, end + 1));
                duan.setStartBiIndex(start);
                duan.setEndBiIndex(end);
                duan.setDirection(direction);
                duan.setHigh(calcMaxHigh(bis, start, end));
                duan.setLow(calcMinLow(bis, start, end));
                duans.add(duan);
                start = end;
            } else {
                start++;
            }
        }
        return duans;
    }

    private static int findSegmentEnd(List<Bi> bis, int start, String direction) {
        for (int i = start + 2; i < bis.size(); i++) {
            if (!bis.get(i).direction.equals(direction)) continue;
            if (i >= 2) {
                Bi b0 = bis.get(i - 2), b1 = bis.get(i - 1), b2 = bis.get(i);
                if (direction.equals("UP") && b1.high > b0.high && b1.high > b2.high) return i - 1;
                if (direction.equals("DOWN") && b1.low < b0.low && b1.low < b2.low) return i - 1;
            }
        }
        return bis.size() - 1;
    }

    private static double calcMaxHigh(List<Bi> bis, int start, int end) {
        double max = Double.MIN_VALUE;
        for (int i = start; i <= end; i++) max = Math.max(max, bis.get(i).high);
        return max;
    }

    private static double calcMinLow(List<Bi> bis, int start, int end) {
        double min = Double.MAX_VALUE;
        for (int i = start; i <= end; i++) min = Math.min(min, bis.get(i).low);
        return min;
    }
}

/** 中枢识别 */
public class ZhongShuRecognizer {
    public static List<ZhongShu> recognize(List<Duan> duans, ChanLunConfig config) {
        List<ZhongShu> zsList = new ArrayList<>();
        if (duans.size() < 3) return zsList;
        int i = 0;
        while (i + 2 < duans.size()) {
            Duan d1 = duans.get(i), d2 = duans.get(i + 1), d3 = duans.get(i + 2);
            double high = Math.min(Math.min(d1.high, d2.high), d3.high);
            double low = Math.max(Math.max(d1.low, d2.low), d3.low);
            if (high > low) {
                ZhongShu zs = new ZhongShu();
                zs.setType("DUAN");
                zs.setHigh(high);
                zs.setLow(low);
                zs.setStartIndex(d1.getStartBiIndex());
                zs.setEndIndex(d3.getEndBiIndex());
                List<Integer> comp = new ArrayList<>();
                comp.add(i); comp.add(i + 1); comp.add(i + 2);
                zs.setComponentIndices(comp);
                int j = i + 3;
                while (j < duans.size()) {
                    Duan dn = duans.get(j);
                    if (dn.low < zs.getHigh() && dn.high > zs.getLow()) {
                        zs.setHigh(Math.min(zs.getHigh(), dn.high));
                        zs.setLow(Math.max(zs.getLow(), dn.low));
                        zs.getComponentIndices().add(j);
                        zs.setEndIndex(dn.getEndBiIndex());
                        j++;
                    } else {
                        break;
                    }
                }
                zsList.add(zs);
                i = j;
            } else {
                i++;
            }
        }
        return zsList;
    }
}

/** 信号生成 */
public class SignalGenerator {
    public static List<Signal> generate(List<Bi> bis, List<ZhongShu> zsList,
                                         List<StdKLine> klines, ChanLunConfig config) {
        List<Signal> signals = new ArrayList<>();
        if (zsList.isEmpty() || bis.isEmpty()) return signals;
        if (config.isEnableFirstPoint()) {
            Signal s = generateFirstPoint(bis, zsList);
            if (s != null) signals.add(s);
        }
        if (config.isEnableThirdPoint()) {
            Signal s = generateThirdPoint(bis, zsList);
            if (s != null) signals.add(s);
        }
        return signals;
    }

    private static Signal generateFirstPoint(List<Bi> bis, List<ZhongShu> zsList) {
        ZhongShu lastZS = zsList.get(zsList.size() - 1);
        List<Integer> ci = lastZS.getComponentIndices();
        int lastCompIdx = ci.get(ci.size() - 1);
        if (lastCompIdx + 1 >= bis.size()) return null;
        Bi exitBi = bis.get(lastCompIdx + 1);
        if (exitBi.getDirection().equals("DOWN")) {
            Signal s = new Signal();
            s.setType("BUY");
            s.setLevel(1);
            s.setBarIndex(exitBi.getEnd().getIndex());
            s.setPrice(exitBi.getEnd().getLow());
            s.setStrength("STRONG");
            return s;
        }
        return null;
    }

    private static Signal generateThirdPoint(List<Bi> bis, List<ZhongShu> zsList) {
        ZhongShu lastZS = zsList.get(zsList.size() - 1);
        List<Integer> ci = lastZS.getComponentIndices();
        int lastCompIdx = ci.get(ci.size() - 1);
        if (lastCompIdx + 2 >= bis.size()) return null;
        Bi exitBi = bis.get(lastCompIdx + 1);
        Bi pullbackBi = bis.get(lastCompIdx + 2);
        if (exitBi.getDirection().equals("UP") && pullbackBi.getDirection().equals("DOWN")) {
            if (pullbackBi.getLow() > lastZS.getHigh()) {
                Signal s = new Signal();
                s.setType("BUY");
                s.setLevel(3);
                s.setBarIndex(pullbackBi.getEnd().getIndex());
                s.setPrice(pullbackBi.getEnd().getLow());
                s.setStrength("STRONG");
                return s;
            }
        }
        if (exitBi.getDirection().equals("DOWN") && pullbackBi.getDirection().equals("UP")) {
            if (pullbackBi.getHigh() < lastZS.getLow()) {
                Signal s = new Signal();
                s.setType("SELL");
                s.setLevel(3);
                s.setBarIndex(pullbackBi.getEnd().getIndex());
                s.setPrice(pullbackBi.getEnd().getHigh());
                s.setStrength("STRONG");
                return s;
            }
        }
        return null;
    }
```

```java
public class ChanLunMultiPeriodEngine {
    private final Map<Period, ChanLunEngine> engines = new ConcurrentHashMap<>();
    private final ChanLunConfig globalConfig;
    private final ExecutorService executor = Executors.newFixedThreadPool(7);

    public ChanLunMultiPeriodEngine(ChanLunConfig config) {
        this.globalConfig = config;
        for (Period period : Period.values()) {
            engines.put(period, new ChanLunEngine(period, config));
        }
    }

    public ChanLunResult compute(Period period, List<StdKLine> klines) {
        return engines.get(period).compute(klines);
    }

    public Map<Period, ChanLunResult> computeAll(Map<Period, List<StdKLine>> periodKlines) {
        Map<Period, ChanLunResult> results = new ConcurrentHashMap<>();
        List<CompletableFuture<Void>> futures = new ArrayList<>();
        for (Map.Entry<Period, List<StdKLine>> entry : periodKlines.entrySet()) {
            Period period = entry.getKey();
            List<StdKLine> klines = entry.getValue();
            futures.add(CompletableFuture.runAsync(() -> {
                results.put(period, engines.get(period).compute(klines));
            }, executor));
        }
        CompletableFuture.allOf(futures.toArray(new CompletableFuture[0])).join();
        return results;
    }

    public ChanLunEngine getEngine(Period period) { return engines.get(period); }
}
```

```java
package com.chain.ai.trade.extension.ta4j.indicator.chanlun.adapter;

import com.chain.ai.trade.extension.ta4j.indicator.chanlun.model.*;
import com.chain.ai.trade.extension.ta4j.indicator.chanlun.engine.ChanLunEngine;
```

```java
import org.ta4j.core.BarSeries;
import org.ta4j.core.indicators.CachedIndicator;
import java.util.List;
import java.util.stream.Collectors;

/**
 * 缠论指标适配器：将 ChanLunEngine 包装为 ta4j CachedIndicator
 * 策略层通过 getValue(index) 获取 ChanLunResult 进行交易判断
 */
public class ChanLunIndicator extends CachedIndicator<ChanLunResult> {
    private final ChanLunEngine engine;
    private final BarSeries series;
    private int lastBarCount = 0;

    public ChanLunIndicator(BarSeries series, ChanLunEngine engine) {
        super(series);
        this.series = series;
        this.engine = engine;
    }

    @Override
    protected ChanLunResult calculate(int index) {
        int currentBarCount = series.getBarCount();
        if (currentBarCount > lastBarCount) {
            List<StdKLine> klines = series.getBarData().stream()
                .map(this::toStdKLine)
                .collect(Collectors.toList());
            if (lastBarCount == 0) {
                engine.compute(klines);
            } else {
                engine.incrementalCompute(klines.subList(lastBarCount, klines.size()));
            }
            lastBarCount = currentBarCount;
        }
        return engine.getLastResult();
    }

    private StdKLine toStdKLine(Bar bar) {
        StdKLine k = new StdKLine();
        k.setTime(bar.getTime().toLocalDateTime());
        k.setOpen(bar.getOpenPrice().doubleValue());
        k.setHigh(bar.getHighPrice().doubleValue());
        k.setLow(bar.getLowPrice().doubleValue());
        k.setClose(bar.getClosePrice().doubleValue());
        k.setVolume(bar.getVolume().longValue());
        return k;
    }
}
```

7.5 ATR 噪声提前过滤
在进入中枢识别前，用 ATR × 阈值判断价格波动是否为有效波动。当高低点间的价格波动小于 ATR × 阈值 时，视为无效波动，不计入中枢。这能显著减少无效的窗口遍历。

```java
double atr = getATR(barIndex);
double minMove = atr * atrFilterThreshold;
if (Math.abs(high - low) < minMove) {
// 忽略该段/笔
continue;
}
```

|------|----------|------|
| atrFilterThreshold | 增大（如 0.5 → 0.8） | 过滤更多噪声，中枢更平滑 |
| useNewBiRule | true → false | 笔的确认条件更严格，笔数量减少 |
| minKlineBetween | 增大（如 1 → 3） | 要求分型之间K线数更多，噪声过滤更强 |

| method: MACD | 改为 "Slope" | 更适合高频周期使用 |
| recursiveMode | false → true | 更符合缠论级别定义，但计算量增大 |

    10.1 REST API

后端提供 RESTful API 用于前端数据获取和参数配置。

| 端点 | 方法 | 参数 | 说明 |
|------|------|------|------|
| `/api/chanlun/data` | GET | period, from, to | 获取指定周期的缠论数据 |
| `/api/chanlun/config` | GET | - | 获取当前配置 |
| `/api/chanlun/config` | PUT | JSON body | 更新配置并触发重算 |
| `/api/chanlun/periods` | GET | - | 获取可用周期列表 |

请求示例：
```
GET /api/chanlun/data?period=M15&from=2026-06-01T00:00:00Z&to=2026-06-15T00:00:00Z
```

```java
@RestController
@RequestMapping("/api/chanlun")
public class ChanLunController {
    private final ChanLunMultiPeriodEngine multiEngine;
    private final ChanLunConfig config;

    @GetMapping("/data")
    public ResponseEntity<ChanLunResult> getData(
            @RequestParam String period,
            @RequestParam(required = false) String from,
            @RequestParam(required = false) String to) {
        Period p = Period.valueOf(period);
        // 按时间范围过滤
        ChanLunResult result = multiEngine.getResult(p);
        // 如果提供了时间范围，过滤K线数据
        if (from != null && to != null) {
            result = filterByTimeRange(result, from, to);
        }
        return ResponseEntity.ok(result);
    }

    @GetMapping("/config")
    public ResponseEntity<ChanLunConfig> getConfig() {
        return ResponseEntity.ok(config);
    }

    @PutMapping("/config")
    public ResponseEntity<Void> updateConfig(@RequestBody ChanLunConfig newConfig) {
        // 更新配置并触发所有周期的重算
        BeanUtils.copyProperties(newConfig, config);
        multiEngine.recomputeAll();
        return ResponseEntity.ok().build();
    }

    @GetMapping("/periods")
    public ResponseEntity<List<String>> getPeriods() {
        return ResponseEntity.ok(
            Arrays.stream(Period.values()).map(Enum::name).collect(Collectors.toList())
        );
    }

    private ChanLunResult filterByTimeRange(ChanLunResult result, String from, String to) {
        // 按时间范围过滤K线数据
        ChanLunResult filtered = new ChanLunResult();
        filtered.setPeriod(result.getPeriod());
        filtered.setKlines(result.getKlines().stream()
            .filter(k -> k.getTime().isAfter(LocalDateTime.parse(from)) && 
                         k.getTime().isBefore(LocalDateTime.parse(to)))
            .collect(Collectors.toList()));
        // 其余数据暂不过滤（前端可自行处理可见区域）
        filtered.setFenXings(result.getFenXings());
        filtered.setBis(result.getBis());
        filtered.setDuans(result.getDuans());
        filtered.setZhongShus(result.getZhongShus());
        filtered.setSignals(result.getSignals());
        return filtered;
    }
}
```

    10.2 WebSocket 实时推送

用于实时行情更新时自动推送最新的缠论计算结果。

```java
@Component
public class ChanLunWebSocketHandler extends TextWebSocketHandler {
    private final ChanLunMultiPeriodEngine multiEngine;
    private final Set<WebSocketSession> sessions = ConcurrentHashMap.newKeySet();

    @EventListener
    public void onNewKLine(NewKLineEvent event) {
        // 收到新K线事件 → 增量计算 → 推送结果
        Period period = Period.valueOf(event.getPeriod());
        ChanLunResult result = multiEngine.incrementalCompute(period, event.getNewKlines());
        String payload = toJson(result);
        broadcast(payload);
    }

    private void broadcast(String message) {
        String finalMsg = message;
        sessions.parallelStream().forEach(session -> {
            try {
                synchronized (session) {
                    if (session.isOpen()) session.sendMessage(new TextMessage(finalMsg));
                }
            } catch (IOException e) {
                sessions.remove(session);
            }
        });
    }

    @Override
    public void afterConnectionEstablished(WebSocketSession session) {
        sessions.add(session);
    }

    @Override
    public void afterConnectionClosed(WebSocketSession session, CloseStatus status) {
        sessions.remove(session);
    }
}
```

11. 风险说明与注意事项

| 风险项 | 说明 | 缓解措施 |
|--------|------|----------|
| 过拟合风险 | 参数调整可能导致指标在历史数据表现良好，但实盘失效 | 定期回测验证，参数不宜过度优化 |
| 分型误判 | 极端行情下分型可能被误识别 | 结合 ATR 滤波，增大最小K线间隔 |
| 中枢漂移 | 新K线加入后，已识别中枢可能发生变化 | 使用增量算法限制回溯范围，前端提示"待确认"区域 |
| 线段识别复杂 | 特征序列法在处理复杂走势时可能递归复杂度高 | 线段识别默认关闭，仅在需要时开启 |
| 多周期不一致 | 不同周期可能给出矛盾的买卖信号 | 以高周期趋势为主导，低周期信号需确认 |
| 性能瓶颈 | 7个周期全量计算在数据量大时可能耗时较长 | 增量计算 + 多线程并行 + 数据时间范围限制 |
| 前端性能 | 大量图形标记可能导致浏览器卡顿 | 虚拟化渲染 + 可视区域裁剪 + 标记数量上限 |
| 升级兼容性 | ta4j 版本升级可能导致 API 变更 | 适配层隔离，核心引擎不依赖 ta4j API |
