# 三阶段前端验证操作手册（纯浏览器操作）

> 本手册所有操作均在浏览器中完成，无需使用命令行。
> 只需保证后端服务（`localhost:8080`）和前端服务（`localhost:3000`）已启动。

---

## 阶段一：注册登录与 JWT 认证

### TC-01：注册一个新账号
**验证目标**：从浏览器注册页面创建账号

**操作步骤**：
1. 打开浏览器，访问 `http://localhost:5173`
2. 点击登录页底部的「立即注册」链接
3. 在注册页面填写：
   - **用户名**：输入 `testuser`
   - **邮箱**：输入 `testuser@example.com`
   - **密码**：输入 `Test123456`
   - **确认密码**：再次输入 `Test123456`
   - **角色**：选择「普通用户」
   - **勾选**：同意服务条款和隐私政策
4. 点击「注册」按钮

**预期结果**：
- 页面提示「注册成功」
- **自动跳转**到系统首页仪表板
- 导航栏右上角显示用户名 `testuser`

---

### TC-02：退出登录
**验证目标**：点击退出按钮登出

**操作步骤**：
1. 点击导航栏右上角的用户头像/用户名区域
2. 在下拉菜单中点击「退出登录」
3. 确认退出

**预期结果**：
- 页面提示「已退出登录」
- **跳转回登录页**
- 地址栏变为 `http://localhost:5173/login`

---

### TC-03：用已注册账号登录
**验证目标**：登录功能正常

**操作步骤**：
1. 在登录页输入：
   - **邮箱**：`testuser@example.com`
   - **密码**：`Test123456`
2. 勾选「记住我」
3. 点击「登录」按钮

**预期结果**：
- 页面提示「登录成功」
- **跳转**到首页仪表板
- 导航栏右上角显示 `testuser`

---

### TC-04：登录失败 - 错误密码
**验证目标**：错误密码登录被拒绝

**操作步骤**：
1. 退出当前登录
2. 在登录页输入邮箱 `testuser@example.com`、密码 `wrongpassword`
3. 点击「登录」

**预期结果**：
- 页面提示错误信息（"用户名/邮箱或密码错误"）
- **停留在登录页**，不会跳转

---

### TC-05：登录失败 - 空字段校验
**验证目标**：前端表单校验正常工作

**操作步骤**：
1. 在登录页不填任何内容，直接点击「登录」
2. 观察表单校验

**预期结果**：
- 邮箱输入框下方显示「请输入邮箱地址」
- 密码输入框下方显示「请输入密码」
- **不发送请求**到后端

---

### TC-06：未登录访问受保护页面被拦截
**验证目标**：未登录状态无法进入需要登录的页面

**操作步骤**：
1. 确保已退出登录（在登录页状态）
2. 直接在浏览器地址栏输入 `http://localhost:5173/strategies`
3. 按回车

**预期结果**：
- 页面提示「请先登录」
- **被重定向**到登录页 `/login`

## 阶段二：RBAC 权限管理

### 准备工作：注册管理员账号

**操作步骤**：
1. 访问 `http://localhost:5173/register`
2. 填写：
   - **用户名**：`admin`
   - **邮箱**：`admin@example.com`
   - **密码**：`Admin123456`
   - **确认密码**：`Admin123456`
   - **角色**：选择「管理员」
3. 勾选服务条款，点击「注册」

**预期结果**：
- 注册成功后自动以 admin 身份登录，跳转至首页

---

### TC-07：管理员查看用户列表
**验证目标**：admin 角色可以看到「用户管理」菜单并能正常使用

**操作步骤**：
1. 以 admin 身份登录后，观察左侧导航菜单
2. 找到并点击「用户管理」菜单项
3. 查看用户列表页面

**预期结果**：
- 左侧菜单「用户管理」**可见**
- 进入后显示用户列表表格
- 表格中至少包含刚注册的 `admin` 和 `testuser` 两条记录
- 每行显示：ID、用户名、邮箱、角色、状态、创建时间
- 每行有「编辑」「禁用」「删除」按钮

**验证目标**：通过用户管理页面的「添加用户」功能创建新用户

- 用户列表中新增一条 `newuser` 的记录

### TC-32：完整业务流程验证
**验证目标**：注册 → 登录 → 购买积分 → 积分到账 → 使用功能

**前端操作流程**（从头到尾走一遍）：

**第 1 步：注册新用户**
1. 退出当前登录
2. 访问注册页面
3. 创建一个新用户 `fulluser`，密码 `Full123456`，角色选「普通用户」
4. 注册成功后自动登录

**第 2 步：查看初始状态**
1. 进入「会员方案」页面 → 看到三档会员方案
