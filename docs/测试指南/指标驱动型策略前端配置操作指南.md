# 指标驱动型策略前端配置操作指南

> **适用版本**：阶段一改造完成后
> **测试目的**：通过前端界面配置并运行指标驱动型策略，端到端验证 `indicator_driven` 路由链路

---

## 数据流转概览

```
策略管理 → 创建策略（className = "indicator_driven"）
       ↓
编辑策略 → 入场规则（配置做多/做空条件 + 指标 + 操作符 + 阈值）
       ↓                          （保存到 strategy_entry_rule + entry_rule_condition 专用表）
机器人管理 → 创建机器人（关联该策略 + 交易对 + 资金）
       ↓
TradingBotLiveTradingTaskExecute（XXL-JOB 定时触发）
       ↓
LiveTradingServiceImpl.startLiveTrading()
  → strategy.getClassName() = "indicator_driven"  → strategyBeanName
  → params.setStrategyId(strategy.getId())
       ↓
DefaultDealStrategyTrade.buildStrategy()
  → strategyBeanName = "indicator_driven"
  → strategyEntryRuleService.loadEntryRulesByStrategyId(strategyId)
  → 解析 LONG/SHORT 方向条件列表
  → IndicatorDrivenDirectionRule.buildFromConditions()
  → 返回 IndicatorDrivenStrategy
       ↓
processEntrySignals() / processPositionExits() 指标实时计算
```

## 第一步：创建指标驱动型策略

### 界面路径
**策略管理 → 创建策略**

### 操作步骤
1. 点击顶部导航 **"策略管理"** → 进入策略列表页
2. 点击 **"创建策略"** 按钮
3. 填写表单字段：

| 字段 | 值 | 说明 |
|------|----|------|
| 策略名称 | 例：`RSI指标驱动策略` | 自定义名称 |
| 策略类型 | 选 **均值回归** 或其他 | 仅用于前端分类 |
| **策略类** | **`indicator_driven`** | **关键字段！对应后端路由** |
| 时间框架 | 选 `1h` 或 `5m` | 与K线周期一致 |
| 策略描述 | 例：`基于RSI指标的入场出场策略` | 可选 |

4. 点击 **"创建策略"** 提交

### 验证
- 策略列表中出现新创建的策略
- 状态为正常

---

## 第二步：配置入场规则（关键步骤）

> **入场规则是在策略编辑页面配置的，不是机器人上。这里的配置决定了策略的开仓条件。**

### 界面路径
**策略管理 → 编辑策略 → 入场规则**

### 入场规则 UI 说明

入场规则分为 **做多入场条件** 和 **做空入场条件** 两个独立区块，每个区块可独立配置条件和禁用。

#### 做多/做空每个条件的字段

| 字段 | 说明 | 示例值 |
|------|------|--------|
| 指标选择 | 选择技术指标类型 | `RSI`, `MACD`, `成交量` |
| 参数 | 指标的计算周期/参数 | `14`（RSI周期） |
| 操作符 | 条件判断方式 | `小于`, `大于`, `金叉`, `死叉` |
| 阈值 | 比较的数值（部分操作符不需要） | `30` |
| 连接符 | 与前一个条件的逻辑关系（首个条件没有） | `AND`, `OR` |

#### 操作步骤

1. 在策略列表中找到刚创建的策略，点击 **"编辑"**
2. 找到 **"入场规则"** 区域（在出场规则下方）

##### 配置做多条件（做多入场）

```
┌─ 入场规则 ──────────────────────────────────────────────┐
│ ── 做多入场条件 ── [无条件，不入场]                     │
│ □ 禁用做多                                              │
│                                                          │
│ [RSI ▼] [周期: 14] [小于 ▼] [30]             [🗑删除]   │
│       [AND ▼]  ← 行间连接符                              │
│ [成交量 ▼] [周期: 20] [大于 ▼] [10000]       [🗑删除]   │
│       [OR ▼]   ← 行间连接符                              │
│ [+ 添加条件]                                             │
│                                                          │
│ ── 做空入场条件 ── [无条件，不入场]                     │
│ □ 禁用做空                                              │
│ [+ 添加条件]                                             │
└──────────────────────────────────────────────────────────┘
```

3. **添加做多条件**：点击做多区块的 **"+ 添加条件"**
4. 选择指标类型（RSI / MACD / 成交量）
5. 输入周期参数
6. 选择操作符和阈值
7. **添加多个条件**：再次点击 **"+ 添加条件"**，每行之间可独立选择 `AND` 或 `OR`
8. **配置做空条件**（可选）：在 **做空入场条件** 区块重复以上步骤
9. 如需临时关闭某方向，勾选 **"禁用做多"** 或 **"禁用做空"**
10. 所有规则配置完毕，点击页面底部 **"保存"** 提交

### 条件配置示例

#### 示例 1：简单 RSI 超卖策略（仅做多）

| 方向 | 指标 | 参数 | 操作符 | 阈值 | 作用 |
|------|------|------|--------|------|------|
| 做多 | RSI | 周期14 | 小于 | 30 | RSI < 30 时入场做多 |
| 做空 | （禁用） | - | - | - | 不做空 |

#### 示例 2：RSI + 成交量确认（做多）+ RSI 超买（做空）

**做多条件（两个条件，AND 组合）**：

| # | 指标 | 参数 | 操作符 | 阈值 | 连接符 |
|---|------|------|--------|------|--------|
| 1 | RSI | 周期14 | 小于 | 30 | - |
| 2 | 成交量 | 周期20 | 大于 | 10000 | AND |

**做空条件（单个条件）**：

| # | 指标 | 参数 | 操作符 | 阈值 | 连接符 |
|---|------|------|--------|------|--------|
| 1 | RSI | 周期14 | 大于 | 70 | - |

#### 示例 3：MACD 金叉死叉策略

**做多条件**：

| # | 指标 | 参数 | 操作符 | 阈值 | 连接符 |
|---|------|------|--------|------|--------|
| 1 | MACD | 12,26,9 | 金叉 | - | - |

**做空条件**：

| # | 指标 | 参数 | 操作符 | 阈值 | 连接符 |
|---|------|------|--------|------|--------|
| 1 | MACD | 12,26,9 | 死叉 | - | - |

### 前端保存格式（自动生成，无需手动填写）

配置保存后，前端提交如下 JSON，后端解析后写入 `strategy_entry_rule` 和 `entry_rule_condition` 专用表：

```json
{
  "long": {
    "disabled": false,
    "conditions": [
      { "indicator": "rsi", "period": "14", "operator": "lt", "threshold": "30", "connector": "and" },
      { "indicator": "volume", "period": "20", "operator": "gt", "threshold": "10000", "connector": null }
    ]
  },
  "short": {
    "disabled": true,
    "conditions": []
  }
}
```

> **注意**：保存后，后端会同步将规则写入 `strategy_entry_rule` 和 `entry_rule_condition` 两张专用表，用于引擎运行时构建指标入场规则。

## 第三步：创建交易机器人

### 界面路径
**机器人管理 → 创建机器人**

### 操作步骤
1. 点击顶部导航 **"机器人管理"** → 进入机器人列表页
2. 点击 **"创建机器人"** 按钮
3. 填写表单字段：

| 字段 | 值 | 说明 |
|------|----|------|
| 机器人名称 | 例：`RSI指标测试机器人` | 自定义名称 |
| 用户ID | 输入有效用户ID | 必填 |
| 账户ID | 选择一个交易账户 | 下拉选择 |
| **策略** | **选择第一步创建的 "RSI指标驱动策略"** | 关键！关联 indicator_driven |
| 交易对 | 选择 `ETH-USDT-SWAP` 或其他 | 建议选有足够K线数据的交易对 |
| 杠杆倍数 | `1` （测试用不加杠杆） | |
| 分配资金 | `100` （测试用小资金） | |
| 当前资金 | `100` | |
| 日盈利目标 | `0` | 暂不设 |
| 日亏损目标 | `0` | 暂不设 |
| 是否启用 | ✅ 启用 | |

4. 点击 **"保存"** 提交

> **注意**：入场规则已经在第二步配到策略上了，机器人只需选择策略即可。

---

## 第四步：启动机器人

### 界面操作

1. 在 **机器人管理** 列表中找到刚创建的机器人
2. 确保状态为 **"已创建"**（CREATED）
3. 点击 **"启动"** 按钮
4. 确认后状态变为 **"运行中"**（RUNNING）

### 调度触发说明

机器人启动后，**XXL-JOB 调度中心** 会定时触发 `tradingBotLiveTradingExecute` 任务：

- 默认调度频率取决于 XXL-JOB 配置（通常每分钟或每5分钟）
- 也可在 XXL-JOB 控制台 **手动触发一次** 立即验证

## 第五步：验证执行结果

### 后端日志检查

在应用日志中搜索以下关键词确认链路正确：

| 日志内容 | 含义 | 预期结果 |
|---------|------|---------|
| `buildStrategy: strategyBeanName=indicator_driven` | buildStrategy 收到路由指令 | ✅ |
| `buildStrategy: 使用 IndicatorDrivenStrategy` | 成功构建指标驱动策略 | ✅ |
| `loadEntryRulesByStrategyId` | 从专用表加载入场规则 | ✅ |
| `buildFromConditions` | 根据条件构建 IntPredicate 规则 | ✅ |
| `[processEntrySignals] 多方向策略入场检查` | 入场逻辑正常执行 | ✅ |
| `shouldEnterDirection: BUY` 或 `SELL` | 入场方向计算结果 | ✅ |
| `[processPositionExits] 多方向策略出场检查` | 出场逻辑正常执行 | ✅ |
| `shouldExitSignal: EXIT` | 出场信号触发 | ✅ |
| `创建订单成功` | 信号转化为实际订单 | ✅ |

### 持仓验证

1. 在 **机器人管理** 列表中查看机器人状态
2. 点击机器人 **"查看详情"** → 查看当前持仓
3. 如有订单成交，应能看到开仓记录

### 错误排查

| 错误日志 | 原因 | 解决 |
|---------|------|------|
| `indicator_driven 策略缺少入场规则配置` | 入场规则未配置或全部禁用 | 到策略编辑页的入场规则中配置条件 |
| `Unsupported indicator type` | 不支持的指标类型 | 检查前端传入的 indicator 值是否在支持列表（rsi, macd, volume） |
| `Unsupported combination` | 指标与操作符组合不支持 | 检查操作符是否在该指标支持范围内 |
| `Unknown operator` | 操作符拼写错误 | 检查 operator 值（lt, gt, eq, cross_up, cross_down） |
| `策略未找到` | className 未正确设置 | 检查策略的 className 字段是否为 `indicator_driven` |

## 附录：支持的指标与操作符对照

| 指标类型 | 参数 | 支持的操作符 | 阈值 | 说明 |
|---------|------|-------------|------|------|
| RSI | period (默认14) | lt, gt, eq, cross_up, cross_down | 需要 | 相对强弱指标 |
| MACD | fastPeriod(12), slowPeriod(26), signalPeriod(9) | cross_up（金叉）, cross_down（死叉） | 不需要 | 指数平滑异同移动平均线 |
| 成交量 | period (默认20) | lt, gt, eq, cross_up, cross_down | 需要 | 成交量指标 |

### 操作符含义

| 操作符 | 含义 | 示例 |
|--------|------|------|
| `lt` | 小于 | RSI(14) < 30 |
| `gt` | 大于 | RSI(14) > 70 |
| `eq` | 等于 | RSI(14) = 50 |
| `cross_up` | 上穿（金叉） | MACD 上穿信号线 |
| `cross_down` | 下穿（死叉） | MACD 下穿信号线 |

### 条件组合逻辑

多个条件通过行间连接符组合：
- **AND**：所有条件必须同时满足才触发入场
- **OR**：任一条件满足即触发入场

示例：`RSI(14) < 30 AND 成交量(20) > 10000` → 两个条件都满足才开仓
示例：`RSI(14) < 30 OR RSI(14) > 70` → 任一条件满足即开仓

## 附录：开关策略类型对比

通过界面修改策略的 **"策略类"（className）** 字段即可切换策略类型：

| className 值 | 路由到 | 适用场景 | 入场规则配置位置 |
|-------------|--------|---------|----------------|
| `indicator_driven` | `IndicatorDrivenStrategy` | 纯技术指标计算，不入信号库 | **策略编辑 → 入场规则** |
| `signal_multi_direction` | `SignalMultiDirectionStrategy` | 基于信号库的双向策略 | 信号数据源配置 |
| 其他值（如 `RSI`） | `StrategyFactory` 构建 | 传统单/双向策略（legacy） | 策略参数配置 |
