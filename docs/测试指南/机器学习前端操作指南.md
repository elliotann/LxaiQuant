# 机器学习前端操作指南

## 导航入口

侧边栏包含两个 ML 相关导航项：

- **机器学习**：方向预测模型训练、模型管理、在线预测
- **因子挖掘**：遗传规划因子自动发现

---

## 一、机器学习实验室

### 1.1 模型训练

**操作步骤：**

1. 点击侧边栏 **机器学习**
2. 默认进入 **模型训练** Tab
3. 选择 **交易对**（BTC/USDT、ETH/USDT、ETH永续、SOL/USDT）
4. 选择 **模型类型**（目前仅支持 方向预测）
5. （可选）展开 **高级参数** 面板，调整：
   - 决策树数量（默认 500）
   - 最大深度（默认 4）
   - 最小样本数（默认 40）
6. 点击 **开始训练**（同步，等待返回结果）
7. 或点击 **异步训练**（后台运行，支持查看进度）

**训练结果展示：**

- 训练完成后显示结果卡片，包含：
  - 交易对、状态（SUCCESS/FAILED）
  - 准确率
  - 开始/结束时间
  - 错误信息（失败时）
- 异步训练时显示 **进度条卡片**，实时展示：
  - 已完成树数 / 总树数
  - 当前准确率
  - 轮询间隔 2 秒

**注意事项：**

- 同步训练可能耗时较久（500 棵树约 10-30 秒），请耐心等待
- 异步训练可关闭页面，训练完成后在模型管理查看
- 训练失败常见原因：样本不足（需至少 100 个有效样本）、K 线数据不足

### 1.2 模型管理

**操作步骤：**

1. 进入 **模型管理** Tab
2. 选择交易对筛选（默认全部）
3. 点击 **刷新** 加载模型列表

**表格列说明：**

| 列 | 说明 |
|----|------|
| 交易对 | 模型对应的交易品种 |
| 类型 | 模型类型（目前仅 DIRECTION） |
| 版本 | 版本号（v1 开始递增） |
| 准确率 | 训练集测试准确率 |
| F1 Score | 精确率和召回率的调和平均 |
| 状态 | 活跃（当前使用）/ 未激活 |
| 训练时间 | 模型训练完成时间 |

**操作按钮：**

- **激活**：将指定版本设为活跃模型（后续预测使用此版本）
- **详情**：查看模型详细信息弹窗（特征重要性、混淆矩阵等）
- **删除**：删除指定版本（无法恢复）
- 最大保留 5 个版本，超出自动清理最旧版本

### 1.3 在线预测

#### 方向预测

**操作步骤：**

1. 进入 **在线预测** Tab
2. 选择 **交易对**
3. （可选）选择 **模型版本**（默认使用活跃模型）
4. 点击 **预测方向**

**结果解读：**

- **预测方向**：上涨 / 下跌 / --
- **置信度**：模型对预测结果的信心（0%~100%）
- **上涨概率**：模型计算的上涨概率（0%~100%）
- **概率条**：可视化上涨/下跌概率对比
- **仪表盘**：上涨概率可视化仪表盘

**判断依据：**

- 上涨概率 > 65% → 预测上涨
- 上涨概率 < 35% → 预测下跌
- 35% ~ 65% → 无法判断（--）

#### 波动率预测

1. 选择交易对
2. 点击 **波动率预测**

**结果字段：**

| 字段 | 说明 |
|------|------|
| 年化波动率 | 基于历史数据的年化标准差 |
| ATR | 平均真实波幅 |
| 波动率制度 | 高波动(HIGH) / 中波动(MEDIUM) / 低波动(LOW) |
| 建仓建议 | 根据波动率给出的交易建议 |

**波动率分级：**

- HIGH：ATR 百分比 > 2.0% → 适合趋势策略，注意降低仓位
- MEDIUM：ATR 百分比 > 0.8% → 正常交易
- LOW：ATR 百分比 ≤ 0.8% → 适合网格/震荡策略

#### 市场状态

1. 选择交易对
2. 点击 **市场状态**

**返回说明：**

| 状态 | 描述 |
|------|------|
| 趋势上涨 | 涨幅较大，波动中等 |
| 震荡整理 | 涨跌幅小，波动低 |
| 趋势下跌 | 跌幅较大，波动高 |

#### 查看特征

1. 选择交易对
2. 点击 **查看特征**

展示当前 K 线的最新 4 维基础特征值（RSI、MACD、MACD_Signal、EMADiff），用于辅助判断当前市场状态。

## 二、因子自动挖掘

### 2.1 任务创建

**操作步骤：**

1. 点击侧边栏 **因子挖掘**
2. 默认进入 **任务创建** Tab
3. **加载终端池**：选择交易对和 K 线周期，点击"加载终端池"

**选择终端池：**

- 终端池展示所有可用基础特征变体（RSI_14、MACD_12_26、ATR_14 等 40+ 个）
- 点击特征卡片切换选中/取消
- 支持 **全选** / **反选** 快捷操作
- 切换交易对或周期后需重新加载

**选择算子集：**

- 算术：ADD(+)、SUB(-)、MUL(*)、DIV(/)、NEG(neg)
- 数学函数：SQRT(sqrt)、LOG(log)、ABS(abs)、SIGN(sign)
- 比较函数：MAX(max)、MIN(min)
- 时间序列：TS_SUM、TS_MEAN、TS_STD、TS_MAX、TS_MIN、TS_MEDIAN
- 点击算子卡片切换选中/取消
- 建议至少选择算术 + 时间序列算子保证因子多样性

**配置 GP 参数：**

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 种群大小 | 500 | 每代个体数，越大越慢但搜索更充分 |
| 进化代数 | 20 | 总迭代次数 |
| 锦标赛大小 | 5 | 选择压力，越大收敛越快 |
| 适应度指标 | Rank IC | RANK_IC/SHARPE/IC_SHARPE_COMBO |
| 交叉概率 | 0.8 | 子树交叉比率 |
| 变异概率 | 0.1 | 点变异比率 |
| 简约系数 | 0.001 | 惩罚大树，防止过拟合 |

**创建并启动：**

1. 填写 **任务名称**
2. 点击 **创建并启动**
3. 系统自动创建任务并开始异步执行

### 2.2 任务列表

**操作步骤：**

1. 进入 **任务列表** Tab
2. 自动展示历史任务表格

**表格列说明：**

| 列 | 说明 |
|----|------|
| ID | 任务编号 |
| 任务名称 | 自定义名称 |
| 标的 | BTCUSDT 等 |
| 周期 | 1H / 4H 等 |
| 状态 | PENDING(待执行) / RUNNING(执行中) / SUCCESS(完成) / FAILED(失败) / CANCELLED(已取消) |
| 进度 | 百分比进度条 |
| 最佳适应度 | 当前最优适应度值 |
| 最佳表达式 | 最优因子表达式（截断显示） |
| 创建时间 | 任务创建时间 |
| 操作 | 查看详情 / 取消任务 |

**运行中任务：**

- 页面顶部展示 **进度卡片**
- 自动 2 秒轮询更新进度
- 实时显示当前代数和最优适应度

**取消任务：**

- 仅 RUNNING 状态的任务可取消
- 取消后任务状态变为 CANCELLED

### 2.3 候选因子管理

**操作步骤：**

1. 进入 **候选因子管理** Tab
2. 选择目标任务（下拉框选择已完成的挖掘任务）
3. 自动加载该任务的候选因子列表

**表格列说明：**

| 列 | 说明 |
|----|------|
| 表达式 | 因子数学表达式 |
| 适应度 | 根据 FitnessMetric 计算的适应度 |
| Rank IC | Spearman 秩相关系数 |
| 夏普比率 | 因子值夏普比率 |
| 换手率 | 因子信号换手率 |
| 深度 | 表达式树深度 |
| 节点数 | 表达式树节点数量 |
| 与标签相关性 | 因子与未来收益的线性相关性 |
| 分组收益 | 按因子值分组的 Top 分组收益 |
| 操作 | 选中因子 |

**选中因子（保存为自定义特征）：**

1. 在候选因子行点击 **选中**
2. 弹窗中输入 **自定义特征名**（如 "GP_Factor_1"）
3. 确认后因子被保存为可用特征
4. 保存成功后可在 **已选特征** 区域查看

**已选特征卡片区：**

- 展示所有已选中的因子卡片
- 每张卡片显示：自定义特征名、表达式、适应度
- 支持 **取消选中**（deselect）

### 2.4 与策略的集成

选中因子自动注册为 `DynamicFeature`，在以下场景自动生效：

- **方向预测模型训练**：4 维基础特征 + 已选因子
- **在线预测**：自动计算已选因子值参与推理

无需额外配置，选中即生效。

## 三、常见操作问题

| 问题 | 解决方法 |
|------|----------|
| 加载终端池为空白 | 确认选择了正确的交易对和周期，后端服务正常运行 |
| 任务创建后状态一直 PENDING | 检查 XXL-JOB 调度是否启用，或手动调用 API 启动任务 |
| 训练进度长时间不动 | 树数多、样本大时属于正常，可刷新页面查看最新状态 |
| 候选因子全为 NaN | 检查 K 线数据是否足够（至少 lookbackBars + 100 根），周期是否正确 |
| 选中因子后预测无变化 | 确认因子表达式无错误，重新进行预测（无需重新训练模型） |
| 预测结果与预期不符 | 检查活跃模型版本是否正确，可切换不同版本对比 |
