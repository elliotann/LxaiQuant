在双向策略引擎中，您希望所有出场规则（包括基础信号反转规则）都通过后端配置来控制是否启用，而不是硬编码。这样可以使策略的行为完全由配置驱动，更灵活地适应不同的交易需求。下面给出具体的实现方案。

1. 扩展配置类 ExitRulesConfig
   在原有的 ExitRulesConfig 中添加一个字段 signalReversalExitEnabled，用于控制是否启用信号反转规则（基于信号缓存的 MultiDirectionExitRule）。

java
private static class ExitRulesConfig {
boolean fixedPercentStopLossEnabled;
Double fixedPercentStopLossPercent;
boolean takeProfitEnabled;
String takeProfitType;
Double takeProfitPercent;
boolean technicalTakeProfitEnabled;
String technicalTakeProfitMode;
boolean technicalTakeProfitMustWin;
boolean batchTakeProfitEnabled;
List<Double> batchTakeProfitPercents = new ArrayList<>();

    // 新增：信号反转规则启用标志
    boolean signalReversalExitEnabled; // 默认为 true 或从配置读取
}
2. 在解析配置时读取该字段
   在 parseExitRulesConfig 方法中，从 StrategyParameter 列表中读取名为 signalReversalExitEnabled 的参数值（例如 JSON 或简单字符串），并设置到 config 中。您可以在 exit_rules 组中增加一个参数，例如：

json
{
"signalReversalExitEnabled": true
}
解析时，从参数列表中获取该值：

java
private ExitRulesConfig parseExitRulesConfig(List<StrategyParameter> exitParams) {
ExitRulesConfig config = new ExitRulesConfig();
if (exitParams == null || exitParams.isEmpty()) return config;
String stopLossJson = null;
String takeProfitJson = null;
String batchEnabledValue = null;
String batchPlansJson = null;
String signalReversalEnabledValue = null; // 新增
for (StrategyParameter p : exitParams) {
if ("stopLoss".equals(p.getName()) && p.getDefaultValue() != null) stopLossJson = p.getDefaultValue();
if ("takeProfit".equals(p.getName()) && p.getDefaultValue() != null) takeProfitJson = p.getDefaultValue();
if ("batchTakeProfitEnabled".equals(p.getName()) && p.getDefaultValue() != null) batchEnabledValue = p.getDefaultValue();
if ("batchTakeProfitPlans".equals(p.getName()) && p.getDefaultValue() != null) batchPlansJson = p.getDefaultValue();
if ("signalReversalExitEnabled".equals(p.getName()) && p.getDefaultValue() != null) signalReversalEnabledValue = p.getDefaultValue(); // 新增
}
// 解析其他配置...
// 解析信号反转启用标志
if (signalReversalEnabledValue != null) {
config.signalReversalExitEnabled = "true".equalsIgnoreCase(signalReversalEnabledValue);
} else {
config.signalReversalExitEnabled = true; // 默认启用（可根据需要调整）
}
// ... 其余解析
return config;
}
3. 在 buildStrategy 中根据配置构建规则列表
   在 DefaultDealStrategyTrade.buildStrategy 的双向模式分支中，加载配置后，根据 config.signalReversalExitEnabled 决定是否将 MultiDirectionExitRule 加入组合规则列表。

java
@Override
public Strategy buildStrategy(BarSeries series, TradingStrategyParams params) {
if (isBidirectionalMode()) {
// ... 加载信号缓存等前置操作 ...

        // 加载出场规则配置（从数据库或参数）
        ExitRulesConfig config = loadExitRulesConfig(params.getStrategyId()); // 需要实现此方法

        // 构建方向性出场规则列表
        List<DirectionalRule> exitRules = new ArrayList<>();

        // 1. 基础信号反转规则（如果启用）
        if (config.signalReversalExitEnabled) {
            exitRules.add(new MultiDirectionExitRule(series, signalCache));
        }

        // 2. 固定止损规则（为多头和空头分别添加）
        if (config.fixedPercentStopLossEnabled && config.fixedPercentStopLossPercent != null) {
            Num lossPct = series.numFactory().numOf(config.fixedPercentStopLossPercent);
            Rule stopLossRule = new StopLossRule(new ClosePriceIndicator(series), lossPct);
            exitRules.add(new ExitRuleAdapter(stopLossRule, Trade.TradeType.BUY));  // 平多
            exitRules.add(new ExitRuleAdapter(stopLossRule, Trade.TradeType.SELL)); // 平空
        }

        // 3. 固定止盈规则
        if (config.takeProfitEnabled && "fixed_percent".equals(config.takeProfitType) && config.takeProfitPercent != null) {
            Num gainPct = series.numFactory().numOf(config.takeProfitPercent);
            Rule takeProfitRule = new StopGainRule(new ClosePriceIndicator(series), gainPct);
            exitRules.add(new ExitRuleAdapter(takeProfitRule, Trade.TradeType.BUY));
            exitRules.add(new ExitRuleAdapter(takeProfitRule, Trade.TradeType.SELL));
        }

        // 4. MACD 规则
        if (config.technicalTakeProfitEnabled && "macd_cross".equals(config.technicalTakeProfitMode)) {
            double commissionRate = params.getCommissionRate() != null ? params.getCommissionRate() : 0.0;
            DirectionalRule macdLong = new DirectionalRule() {
                MacdCrossExitRule rule = new MacdCrossExitRule(series, OrderSideEnum.BUY, config.technicalTakeProfitMustWin, commissionRate);
                @Override
                public Trade.TradeType getDirection(int index, TradingRecord record) {
                    return rule.isSatisfied(index, record) ? Trade.TradeType.BUY : null;
                }
            };
            DirectionalRule macdShort = new DirectionalRule() {
                MacdCrossExitRule rule = new MacdCrossExitRule(series, OrderSideEnum.SELL, config.technicalTakeProfitMustWin, commissionRate);
                @Override
                public Trade.TradeType getDirection(int index, TradingRecord record) {
                    return rule.isSatisfied(index, record) ? Trade.TradeType.SELL : null;
                }
            };
            exitRules.add(macdLong);
            exitRules.add(macdShort);
        }

        // 5. 分批止盈规则
        if (config.batchTakeProfitEnabled && !config.batchTakeProfitPercents.isEmpty()) {
            Rule batchRule = new BatchTakeProfitExitRule(series, new ClosePriceIndicator(series), config.batchTakeProfitPercents);
            exitRules.add(new ExitRuleAdapter(batchRule, Trade.TradeType.BUY));
            exitRules.add(new ExitRuleAdapter(batchRule, Trade.TradeType.SELL));
        }

        // 组合所有规则
        DirectionalRule combinedExitRule = new OrDirectionalRule(exitRules.toArray(new DirectionalRule[0]));

        String name = params.getRobotId() + "_" + params.getSymbol();
        return new SignalMultiDirectionStrategy(series, signalCache, combinedExitRule, name);
    }
    return IDealStrategyBasic.super.buildStrategy(series, params);
}
4. 实现 loadExitRulesConfig 方法
   您需要从数据库或 params 中加载配置，可参考 SignalBasedStrategyImpl 中的逻辑。以下是一个简化示例：

java
private ExitRulesConfig loadExitRulesConfig(String strategyId) {
ExitRulesConfig config = new ExitRulesConfig();
if (strategyId == null || strategyParameterService == null) return config;
List<StrategyParameter> params = strategyParameterService.listByStrategyIdAndGroup(strategyId, "exit_rules");
return parseExitRulesConfig(params); // 使用上面的解析方法
}
5. 注意事项
   默认启用：如果配置中未指定 signalReversalExitEnabled，您可以设置默认值为 true，以保持与现有行为一致。

规则顺序：OrDirectionalRule 会按列表顺序依次检查，一旦某个规则返回非空方向，即停止。您可以根据需要调整规则的优先级（例如将信号反转放在最后）。

配置存储：在后端数据库中，为 exit_rules 组增加一个参数 signalReversalExitEnabled，类型为布尔或字符串，用于控制该规则的启用状态。

通过以上修改，所有出场规则（包括信号反转）都完全由后端配置控制，您可以根据需要灵活开启或关闭任意规则，无需修改代码。
