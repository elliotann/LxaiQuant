# 交易机器人前端管理功能

## 概述

在实盘交易菜单的实时交易子菜单下新增了交易机器人管理功能，实现了完整的机器人分页查询和管理界面。

## 功能特性

### 🖥️ 用户界面

**菜单位置**：
- 实盘交易 → 实时交易 → 交易机器人

**主要功能**：
- 📊 **分页查询**：支持多条件筛选的分页机器人列表
- 📈 **统计概览**：显示各状态机器人的统计信息
- 🔍 **高级筛选**：按机器人名称、用户ID、交易对、状态等条件筛选
- ⚡ **状态管理**：启动、停止、暂停、恢复机器人操作
- 🛠️ **批量操作**：批量更新机器人状态
- 📱 **响应式设计**：支持移动端访问

### 🎨 界面组件

**统计卡片**：
- 总机器人数量
- 运行中机器人
- 已暂停机器人
- 已停止机器人
- 已创建机器人
- 错误状态机器人

**数据表格**：
- 机器人ID（可点击查看详情）
- 机器人名称
- 用户ID、账户ID、策略ID
- 交易对信息
- 资金分配情况
- 机器人状态（带颜色标识）
- 时间信息（创建时间、启动时间、最后信号时间）
- 操作按钮（启动/停止/暂停/恢复/编辑/更多）

**筛选表单**：
- 机器人名称输入框
- 用户ID输入框
- 交易对下拉选择
- 状态下拉选择
- 策略ID输入框
- 账户ID输入框

### 🔧 技术实现

**前端技术栈**：
- Vue 3 + Composition API
- Element Plus UI框架
- TypeScript
- Axios HTTP客户端

**核心文件**：

```
ai-frontend-web/
├── src/
│   ├── components/layout/
│   │   ├── SidebarNav.vue          # 侧边栏导航（新增交易机器人菜单）
│   │   └── V3Layout.vue            # 主布局（添加路由配置）
│   ├── views/trading/
│   │   └── TradingBots.vue         # 交易机器人管理页面
│   ├── api/
│   │   └── robot.ts                # API接口定义
│   └── router/
│       └── index.ts                # 路由配置
```

**API接口**：
```typescript
// 分页查询
getTradingBots(params?: any)

// 状态管理
startBot(botId: string)
stopBot(botId: string)
pauseBot(botId: string)
resumeBot(botId: string)

// 统计信息
getBotStatusStats()
```

### 🎯 交互流程

1. **进入页面**：
   - 自动加载机器人列表和统计信息
   - 显示默认分页（第1页，15条/页）

2. **筛选查询**：
   - 输入筛选条件
   - 点击"筛选"按钮重新查询
   - 点击"重置"按钮清除所有筛选条件

3. **状态操作**：
   - 根据机器人当前状态显示相应操作按钮
   - 点击操作按钮后实时更新状态
   - 成功后刷新列表显示最新状态

4. **分页浏览**：
   - 支持页码跳转和每页条数调整
   - 实时更新数据列表

5. **批量操作**：
   - 选择多个机器人
   - 执行批量状态更新

### 📊 数据展示

**表格列说明**：
- **机器人ID**：唯一标识，点击可查看详情
- **名称**：机器人显示名称
- **用户ID**：所属用户标识
- **账户ID**：使用的交易账户
- **策略ID**：执行的交易策略
- **交易对**：交易品种（如BTC-USDT）
- **资金**：分配资金/当前资金
- **状态**：运行状态（带颜色标识）
- **时间信息**：各种时间戳
- **操作**：状态控制按钮

**状态颜色标识**：
- 🟢 **运行中** (RUNNING) - 绿色
- 🟡 **已暂停** (PAUSED) - 黄色
- 🔴 **已停止** (STOPPED) - 红色
- 🔵 **已创建** (CREATED) - 蓝色
- ⚫ **错误状态** (ERROR) - 红色

### 🔄 状态机

**状态转换规则**：
```
CREATED ──启动──→ RUNNING
RUNNING ──暂停──→ PAUSED
RUNNING ──停止──→ STOPPED
PAUSED ──恢复──→ RUNNING
PAUSED ──停止──→ STOPPED
STOPPED ──启动──→ RUNNING
ERROR ──启动──→ RUNNING
```

## 使用说明

### 1. 访问方式
1. 登录量化交易系统
2. 点击左侧导航："实盘交易" → "实时交易" → "交易机器人"

### 2. 基本操作
1. **查看列表**：页面自动加载机器人列表
2. **筛选查询**：使用顶部筛选表单进行条件查询
3. **状态管理**：点击操作按钮控制机器人状态
4. **分页浏览**：使用底部分页控件浏览数据

### 3. 高级功能
1. **统计概览**：查看各状态机器人数量统计
2. **批量操作**：选择多个机器人进行批量状态更新
3. **详情查看**：点击机器人ID查看详细信息
