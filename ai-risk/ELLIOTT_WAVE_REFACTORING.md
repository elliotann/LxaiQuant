### 2. 延迟初始化模式
```java
private volatile ElliottAnalysisService analysisService;

private ElliottAnalysisService getAnalysisService() {
    if (analysisService == null) {
        synchronized (this) {
            if (analysisService == null) {
                analysisService = new ElliottAnalysisService();
            }
        }
    }
    return analysisService;
}
```
